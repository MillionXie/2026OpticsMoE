## 为什么待提交列表会这么大

原 119,129 个未跟踪文件中有 92,595 个 PNG，另有 15,588 个 `node_modules` 文件。
最重的目录是几份 T12 交付/导出包和旧展示材料，并非新写了十万份模型代码。
忽略规则只排除安装依赖、私有临时区、handoff 中的二进制交付产物。

规则不隐藏 handoff 内 Python/YAML/Markdown/JSON/CSV，不会让已经被 Git 跟踪的
证据消失，也没有删除任何文件。剩下仍有两千多份 Python 文件，包括交付包里的
源码快照和本地独有实现，不能继续一把忽略来追求数字好看。
旧测速/功耗资料仍保留，正式报告与源代码须继续按任务审计纳入主线。
