# LGVQ Spatial 严格双支路架构与优化记录

更新日期：2026-09-08

## 先回答最容易误解的问题

当前 Spatial 模型的主视觉输入确实来自冻结的 Qwen3-VL 前端。14 通道
质量特征不是 Qwen 输出，也没有替换 Qwen；它是从同样的 4 张 RGB 帧
额外计算出的低层质量描述，只注入第一层电子残差 E1。

因此应当把当前输入理解为：

```text
4 张 RGB 帧
├─ 主输入：冻结 Qwen patch embedding + 官方位置插值
│          -> [B,4,196,1024] -> Linear -> [B,4,196,192]
│
└─ E1 的辅助输入：14 个确定性质量通道 -> 冻结 Conv5
                   -> [B,4,196,192] -> 只加进 E1
```

它不是“纯 Qwen-only 输入”：E1 确实还使用了 Conv5 质量特征。它仍然只有
一条电子支路和一条光支路，因为 Conv5 没有自己的 MOS 读出头，也不会绕过
O/E 层直达预测。不过，如果论文约束是“除 Qwen 前端外不允许任何辅助视觉
前端”，那就必须关闭 Conv5 并重新训练；当前最接近的无 Conv5 严格训练结果
只有 SRCC 0.50975，不能把 0.625 的结果当作 Qwen-only 结果。

## 两个前端输入具体做了什么

### 1. Qwen 视觉主输入

每个视频固定取 4 帧，正式位置约为视频进度的 10%、36.67%、63.33%、90%。
每帧经中心裁剪和 Qwen processor 后，只运行冻结 Qwen Vision 的：

1. `patch_embed`；
2. `fast_pos_embed_interpolate` 官方位置插值；
3. 二者逐元素相加；
4. 按 Qwen 的 2x2 patch 分组做均值，把每帧 784 个 patch token 变成
   14x14=196 个 token。

这里不运行 Qwen Vision Transformer、Attention、learned merger 或 LM head。
结果是 `[B,4,196,1024]`，再经 `LayerNorm + Linear(1024,192)` 得到光电网络
共享的 `[B,4,196,192]` 视觉张量。

### 2. 14 通道与 Conv5

14 个通道依次是：R、G、B、亮度、Sobel-x、Sobel-y、梯度幅值、绝对
Laplacian、5x5 局部标准差、颜色饱和度、与前一帧的亮度绝对差、x 坐标、
y 坐标、时间坐标。

它们主要描述模糊、边缘、局部噪声、颜色变化和轻微时序变化。5 层普通卷积
把它们压成 `[B,4,196,192]`。当前正式模型读取的是离线缓存，Conv5 权重冻结。
在第一层中实际执行：

```text
E1 = ElectronicResidual1(QwenVision)
E1 = E1 + sigmoid(g) * LayerNorm(Conv5Quality)
```

而第一层光输入仍然是 Qwen 主张量：

```text
O1 = OpticalExpert1(QwenVision, OpticalRouter(QwenVision))
```

随后才执行 E1/O1 同尺度融合。因此，Conv5 不直接进入第一块相位 mask。

### 3. Spatial prompt

固定文本 prompt 经 Qwen chat template、tokenizer 和冻结 `embed_tokens`，得到
38 个 2048 维 token：`[B,38,2048]`。它再投影成 `[B,38,192]`。

这份文本有两个用途：

1. 38 个 token 的均值生成一组轻量 scale/shift，对视觉张量作最多约 10% 的
   条件调制，使同一视觉前端知道当前任务是 Spatial 而不是 Temporal；
2. 两层视觉 O/E 完成后，38 个文本 token 与 4 个图像 token 拼接，形成
   `[B,42,192]`，继续通过两层语言/序列 O/E。

Spatial 模型里所有样本使用同一句 prompt，所以它不会携带某个视频的标签，
也不能单独区分视频；它的作用是固定的任务条件。这里同样不运行 Qwen 的
Transformer 或 Attention。

## 从输入到一个 MOS 分数的完整结构

```text
Qwen patch+position [B,4,196,1024]
        -> 视觉投影 [B,4,196,192]
        -> prompt scale/shift
        |
        +-> E1：5x5 depthwise + 1x1 + 一个卷积残差单元
        |       并在 E1 内加入冻结 Conv5 质量特征
        +-> O1：光 Router 的四专家能量 Top-2 + 专家相位传播
        -> RMS 对齐，(1-alpha1)E1 + alpha1 O1
        |
        +-> E2：同类电子残差
        +-> O2：全局相位传播
        -> RMS 对齐，(1-alpha2)E2 + alpha2 O2
        |
        -> 每帧对 196 token 做 mean/max，384 -> 192
        -> 4 个图像 token + 38 个 prompt token = [B,42,192]
        |
        +-> E3：因果 1-D depthwise + 1x1 + 一个序列残差单元
        +-> O3：光 Router 的四专家能量 Top-2 + 专家相位传播
        -> RMS 对齐，(1-alpha3)E3 + alpha3 O3
        |
        +-> E4：同类电子残差
        +-> O4：全局相位传播
        -> RMS 对齐，(1-alpha4)E4 + alpha4 O4
        |
        -> 单一 SpatialGrid 读出头 -> 一个连续 MOS
```

四个融合层先分别把 E/O 的 RMS 调到同一尺度，再计算
`(1-alpha)E + alpha*O`，避免电子数值范围把光淹没。稳定模型四个 alpha 分别
约为 0.4852、0.4928、0.5139、0.5196。

读出头没有额外视觉旁路。它使用第二层后的 14x14 视觉 token，经一次 3x3
depthwise 和 1x1 卷积，再做固定 3x3 average/max pooling；4 帧之间取
mean/std/max。同时对第四层后的 42-token 多模态序列取 mean/std/max，最后由
MLP 输出一个连续 Spatial MOS。没有 VGG、Attention、Transformer、RNN，
也没有第三个预测分支。

## 训练与测试口径

- 数据划分：2250 个 train，558 个 test，不设 validation。
- 按当前项目约定，每个 epoch 测一次 test，并按 test SRCC 保存最佳权重。
- 回归主损失：标准化 MOS 的 Smooth-L1。
- 排序损失：batch 内 pairwise ranking。
- 相关性损失：batch Pearson；部分实验再加入可微 soft-Spearman。
- 教师约束只用于 train，并在课程实验中逐步降低，防止教师限制学生。
- Router 的 balance/importance 惩罚在后期降低，而不是一直强迫完全均匀。
- 训练时未调制直流功率在 20%--35% 随机，测试固定 20%。
- pixel shift 当前为 0；没有把 CCD 后非线性塞进网络。
- checkpoint 只保留 best 与 last，不再每 5 epoch 保存相位权重。

## 本轮优化的真实结果

| 实验 | 结构/训练变化 | 最佳 epoch | SRCC | PLCC | 同权重去光 SRCC |
|---|---|---:|---:|---:|---:|
| s324 稳定基线 | 严格双支路 | 6 | 0.62507 | 0.66147 | 0.52171 |
| s408 | 电子残差深度 2->3 | 0 | 0.62528 | 0.66159 | 0.52054 |
| s409 | 单一多尺度读出，温和 LR | 13 | 0.60532 | 0.64459 | 0.57035 |
| s410 | 单一多尺度读出，较高 LR | 32 | 0.61752 | 0.66098 | 0.56486 |
| s406 | 3 套 4 帧等概率训练 | 0 | 0.62507 | 0.66147 | 0.52169 |
| s413 | 3 套 4 帧按 80/10/10 | 0 | 0.62507 | 0.66147 | 0.52169 |
| **s414** | **3 套 4 帧按 90/5/5** | **3** | **0.62529** | **0.66198** | **0.51772** |
| s415/s416 | 冻结全部特征，仅重训读出 | 0 | 0.62509 | 0.66147 | 0.52170 |
| s417 | E1 内零初始化 3x3/5x5 校正 | 0 | 0.62508 | 0.66147 | 0.52169 |

同一 s324 权重直接把四个采样点整体提前 5% 时 SRCC 为 0.53489，延后 5%
时为 0.49797，说明正式中心取帧明显更可靠，另外两套帧只能低概率参与训练。

s414 是数值最好的严格候选，但相对 s324 只增加 0.00022，不能表述为显著
提升。它的同权重光学贡献是 `0.62529-0.51772=+0.10757`；视觉 Router 四专家
选中占比约为 22.18%、20.74%、32.86%、24.22%，没有专家坍缩。稳定交付仍可
保留 s324；若强调轻微取帧鲁棒性和更大的去光差距，可选 s414。语言 Router
的选中占比为 50%、0%、50%、0%：它确实固定使用同一对 Top-2 专家，这是固定
Spatial prompt 下的集中路由；不能把它描述成四个语言专家均衡使用。

## 为什么这轮没有继续堆结构

多组实验都出现“训练损失下降、test SRCC 下降”，说明当前权重位于一个较好
的局部最优点；继续增加读出容量会让电子头更容易拟合 train，并削弱同权重
去光差距。下一轮若仍要明显超过 0.63，优先应检查标签噪声、训练/测试内容
分布与 Qwen 前端的空间裁剪，而不是增加新的视觉网络或第三条分支。
