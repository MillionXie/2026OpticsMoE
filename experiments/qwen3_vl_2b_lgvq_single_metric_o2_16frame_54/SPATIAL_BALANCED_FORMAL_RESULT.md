# Spatial balanced formal candidate

正式候选在 558 个 test 视频上达到 Spatial SRCC **0.6393**、PLCC **0.6743**。同一 checkpoint 直接屏蔽全部光支路后 SRCC 为 **0.5250**，下降 **0.1143**；该对照没有另训一个纯电子模型。

视觉光路由四专家 `selected_share` 为 `[0.1877, 0.1902, 0.3257, 0.2964]`；序列光路由为 `[0.2357, 0.2634, 0.2455, 0.2554]`。四个序列专家均被实质使用，最大占比 0.2634，已通过“至少三个专家占比不低于 0.05，且最大占比不高于 0.5”的防坍缩门槛。

这里没有加入电子 router。物理路由仍为“CCD 四区域积分强度 → softmax → hard Top-2”。由于四个探测区域的固定能量尺度不同，仅使用 2250 个训练样本拟合四路 `log(energy)` 的均值/方差，并把它们作为无仿射、无可训练参数的标定常数写入 checkpoint；test 标签不参与拟合。在实验室逐层微调前，应由 `calibrate_router_channels.py` 或实际采集训练集更新这四路统计量。

四层融合的光学系数 alpha 依次为 0.4930、0.4966、0.5200、0.5201。每层先把电子与光学 feature 做 RMS 同尺度化，再计算 `(1-alpha) * electronic + alpha * optical`，因此 alpha 可以直接解释为同尺度下的融合权重。
