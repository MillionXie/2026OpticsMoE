# `github_D2NN_mnist4.ipynb` 最后训练段精确核对

参考文件：`opticalmoe/notebooks/github_D2NN_mnist4.ipynb`。以下 cell 编号从 0
开始。

## 输入光场

Cell 2 将 MNIST 灰度图双三次插值到 336×336，四边各补 32 个零，最终得到
400×400；随后 `ToTensor()` 将 8-bit 灰度变成 `[0,1]`。Cell 10 直接
`images.squeeze(1)` 作为场振幅：

- 没有开平方；
- 没有均值/方差标准化；
- 没有单帧总能量归一化；
- 没有背景扣除。

Notebook 的光场、相位和传播网格都是 400×400，像素间距 16 μm。最终正式模型
在 cell 11 被重新定义为一层，因此 3 cm 的层间传播没有使用；相位后直接传播
20 cm 到探测面。FFT 没有额外 padding，所以其边界是离散 FFT 的周期边界。

## 相位

Cell 8 为每层建立 400×400 的 `raw phase`，初值全部为 0，并使用：

```text
phase = 2π × sigmoid(raw_phase)
```

所以 raw 初值为 0，但初始实际相位为 π，不是 0 rad。Cell 11 的最终正式模型只含
一张相位 mask。

## 四个探测区域与 target

Cell 7/8 使用两个轴区间：

```text
[75,125), [275,325)
```

笛卡尔积得到四个 50×50 区域，中心坐标为 `(100,100)`、`(300,100)`、
`(100,300)`、`(300,300)`。中心分别处在 400 画面的 1/4 与 3/4。

每个类别的 target 是一张 400×400 二值模板：正确区域为 1，其余所有像素为 0。
Notebook 并没有先测量一张背景再扣除；“背景抑制”来自 target 外像素为 0 的
全平面 MSE。

## Loss 与判别

Cell 10 的训练 loss 为：

```text
100 × MSE(raw full-plane intensity, binary target template)
```

`MSELoss(reduction="mean")` 对 batch 和全部 400×400 像素求平均。强度没有经过
归一化或非线性压缩。分类准确率的计算路径与 loss 不同：四个区域分别求和，再除以
全平面总能量；因为四个分数除以同一个正数，这一步不改变 argmax。

Cell 11/12 使用 Adam、恒定学习率 0.01、batch 100、8 epochs；训练集每类 3000
张，验证集从 official test 中每类随机抽 600 张，未固定随机种子。最后一轮输出约为
`train_acc=0.9038`、`val_acc=0.9004`。

## v2 几何映射

v2 的物理 CCD 必须是 478×478，因此对 notebook 的四条边分别做比例映射，而不是
只保留旧的物理宽度。比例为：

```text
s = 478 / 400 = 1.195
edge_478 = floor(edge_400 × s + 0.5)
```

结果为：

```text
[75,125)  -> [90,149)
[275,325) -> [329,388)
```

四个区域均为 59×59，中心为 119.5 与 358.5，恰好位于 478 离散画面的 1/4、
3/4 半像素中心。理论连续宽度是 59.75 像素；采用 59 而不是 60 可以同时保持两组
中心完全对称。

## v2 与 notebook 的有意差异

- 532 nm、17 μm、相位到 CCD 10 cm；
- 400 输入补零到 478 有效区，再补到 518 物理画布和 1024 数值传播网格；
- 使用 0.65° 圆形 k 空间通带；
- 训练时分别对输入、相位、CCD 前复光场采样轻微的上下左右整数错位；
- CCD 是原始 478×478 `|E|²`，之后没有归一化、激活、log、背景扣除或 resize。

这些变化是新硬件/鲁棒性合同，不应称为 notebook 数值结果的逐项复现。
