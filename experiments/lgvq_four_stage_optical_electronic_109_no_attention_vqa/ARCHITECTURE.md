# 完整推理架构（正式约束版）

这个工程不调用 Qwen、Transformer、self-attention、cross-attention 或电子路由。固定文本提示在所有视频上完全相同，不携带样本信息，因此正式推理中直接删除语言分支。输入只包含同一视频的 4 帧 RGB 图像。只有两处路由，且都由光学探测区能量完成 Top-2 选择。

## 数据形状

```text
4 帧 RGB uint8
[B,4,3,224,224]
          │
          ├────────────── 原始光路 ──────────────┐
          │                                      │
          └─ 14 个固定质量通道 → 5 层二维卷积 ───┤
                                                 ▼
                                      第 1 层 RMS 等尺度融合
                                      [B,4,196,192]
                                                 │
                                      第 2 层光电融合
                                      [B,4,196,192]
                                                 │
                               固定池化桥接（无可训练参数）
                    先放 4×(4×4) 局部 token，再放 4 个帧均值 token
                                          [B,68,192]
                                                 │
                                      第 3 层光电融合
                                          [B,68,192]
                                                 │
                                      第 4 层光电融合
                                          [B,68,192]
                                                 │
                      v1 空间池化 + 时间 Depthwise Conv1D + MLP
                                                 │
                                  [B,2] = Spatial, Temporal
```

## 第 1 层为什么是真正的“前端光电并行”

- 电子支路：同一批 RGB 帧先确定性生成 14 个质量通道，再经过 5 个普通二维卷积，空间尺寸 `224→112→56→28→28→14`，通道 `14→48→64→96→96→192`，得到 `[B,4,196,192]`。
- 光支路：直接从同一批原始 RGB 帧取灰度振幅，双线性缩到 `109×109`，非负且逐帧 RMS 归一化。它不依赖电子卷积输出。
- 光路由：4 帧分别位于 `478×478` 有效区的四个 `232×232` lane；每帧用一个 `109×109` 路由相位，在 CCD 的 4 个固定探测区积分，softmax 后取 Top-2。
- 专家传播：每个 lane 内为 `2×2` 专家，单专家 `109×109`，pitch `123`，间隙 `14`。经 10 cm 传播和 CCD 电子读出后恢复为 `[B,4,196,192]`。

因此第 1 层的光、电都直接看到原始图像；不存在“先跑一个大电子网络再把特征交给光路”的隐藏前提。

## 四层的含义

1. 原始帧电子卷积 + 光学 Top-2 专家传播。
2. 一次显式二维 depthwise/pointwise 电子卷积 + 全局相位传播。
3. 固定桥接后的显式一维 depthwise/pointwise 电子卷积 + 光学 Top-2 专家传播。
4. 一次显式一维 depthwise/pointwise 电子卷积 + 全局相位传播。

第 2/3/4 层电子支路直接输出卷积结果，不加入额外残差、注意力或电子门控/路由。

## v3 的唯一结构改动：质量感知前端

每帧从同一张 RGB 图确定性生成以下 14 个通道：

1. RGB：3 通道；
2. luminance：1 通道；
3. Sobel x / Sobel y：2 通道；
4. gradient magnitude：1 通道；
5. absolute Laplacian：1 通道；
6. `5×5` local standard deviation：1 通道；
7. saturation，即 `max(R,G,B)-min(R,G,B)`：1 通道；
8. 与前一采样帧的 absolute luminance difference：1 通道，第一帧为 0；
9. 固定 `x/y/time` 坐标：3 通道。

Sobel 和 Laplacian 使用固定 `3×3` 核；local standard deviation 使用固定 `5×5` 统计。它们是无参数的确定性输入计算，不是预训练网络，也不存在冻结网络参数。之后 5 层均为可训练 `3×3 Conv2D + GroupNorm + GELU`，stride 依次为 `2,2,2,1,2`。

## 明确保留的 v1 行为

- 桥接顺序仍为：先连续放置四帧各 16 个池化 token，共 64 个；最后追加 4 个帧均值 token，得到 `[B,68,192]`。
- 第 3/4 层仍接收完整 68-token 序列。
- 最终质量读出仍直接取前 64 个 token，按每帧 16 个恢复并池化；时间支路仍是 v1 的 depthwise/pointwise 一维卷积和相邻帧差分。
- 全部光学类、相位尺寸、传播距离、探测 ROI、Top-2 router、CCD 归一化与融合公式均与 v1 完全相同。

所有光学传播参数固定为：`532 nm`、`17 μm`、`10 cm`、canvas `518`、CCD 有效区 `478`。训练时包含输入/相位/CCD 各 `±8 px` 零填充扰动、k 空间限带和 4 px 单元的相位失活。

路由训练还包含 `0.02 × capture loss`，用于提高四个固定探测区捕获到的能量比例；相位权重使用独立的较大学习率。训练结束会写出 `phase_training_diagnostics.json`，逐张报告相位标准差、相对初始化的环形相位 RMS 变化和真正发生变化的像素比例，避免只看 preview 主观判断 mask 是否训动。

优化器只对电子参数应用配置中的 weight decay；特征相位和路由相位两组的 weight decay 显式为 `0`，避免把相位 raw 参数无意义地拉向零。

## 融合与光占比

每层先分别计算光、电特征的逐样本 RMS，再做

```text
M = (1-alpha) * E/RMS(E) + alpha * O/RMS(O)
F = RMS(E) * M/RMS(M)
```

`alpha` 可学习，但每层严格限制在 `[0.50, 0.90]`，初值 `0.57`。这样电子、光学进入融合前处于同一尺度，不能依靠放大电子数值把光淹没。

## 去光实验

只训练一份正常光电模型。去光结果使用同一个最佳 checkpoint：四个光学传播和两个光路由都不执行，每层直接返回其电子支路。没有另训一个纯电子模型，因此差值回答的是“这个已训练模型在推理时失去光路后下降多少”。

## 最终电子读出

前 64 个 token 按 `4 帧 × 16 token` 恢复，并在每帧内平均为 `[B,4,192]`：

- Spatial：在 4 帧上分别做 mean 和 max，拼为 `[B,384]`，经 `LayerNorm → Linear 384→256 → GELU → Dropout → Linear 256→1`。
- Temporal：先对 `[B,4,192]` 做 `LayerNorm → Depthwise Conv1D(k=3) → GELU → Pointwise Conv1D`；再拼接时序均值、相邻帧差绝对值均值和最大值为 `[B,576]`，经 `Linear 576→256 → GELU → Dropout → Linear 256→1`。
- 两个标量反归一化后得到 `[B,2] = [Spatial, Temporal]`。

该读出仅含普通卷积、归一化和全连接层，没有 Transformer、attention 或可部署的外部模型。

## 正式训练期标量软目标

唯一推荐配置在训练时按 `sample_id` 读取 `[Spatial, Temporal]` 两个离线标量软目标，权重为 `3.0`，并与人工标签一样在标准化尺度上计算 SmoothL1。文件严格只含 2250 个训练样本，不含 558 个测试样本。

这不是部署结构的一部分：checkpoint 只记录软目标文件的路径、SHA256 和样本数，不保存或加载教师模型。模型 forward、测试和部署都不读取软目标，因此仍为零 Qwen、零 Transformer、零 attention；正常开光和同 checkpoint 去光使用完全相同的最终电子读出。
