# LGVQ 四层光电视频质量评价（109 px 专家）

> 实验室 ZIP 用户请从压缩包根目录的 `README_FIRST.md` 开始，并只按
> `LAB_DEPLOYMENT.md` 执行。`RUN_COMMANDS.md` 是完整服务器仓库的从零训练溯源，
> 依赖未随部署包附带的原始视频和训练期软目标，不能当作实验室部署命令。

这是新的、独立的正式工程。旧的 `qwen3_vl_2b_lgvq_o2_109_highalpha_vqa` 调用了完整视觉主干，不符合最新约束，不能作为本工程的正式结果。

当前模型合同是严格 `v3`，并且只相对成功的 `v1` 改一个变量：把最前面的 3 层 RGB 电子卷积换成“14 个显式质量通道 + 5 层普通二维卷积”。`v1` 的固定桥接顺序、质量读出、后续电子 route、全部光学传播、光路由和 `109 px` 专家硬件布局均原样保留。固定质量通道不来自预训练或冻结网络，只由灰度、固定差分算子、局部统计、帧差和坐标直接计算。

正式 `v3` 配置使用独立的 `_v3` 输出目录，避免覆盖或混入早期结果。checkpoint 合同也编码 alpha 下限，因此不同版本或不同 alpha 下限的权重不能互相误载。

本工程只有一个训练任务：正常四层光电模型。当前唯一推荐配置是 `formal_alpha50_kd300_center100.yaml`。训练结束后，用同一最佳权重自动得到两组结果：

1. 正常光电推理；
2. 同一 checkpoint 的去光推理消融（仅测试，不训练）。

不会单独训练纯电子基线，也不存在第二条去光训练命令。去光结果只回答：同一个正常光电 checkpoint 在推理时旁路光学分支后会下降多少。目标只有 Spatial 和 Temporal；不读取图文一致性分数。数据按 375 个 prompt group（2250 视频）训练、93 个 group（558 视频）测试，无验证集；每 5 epoch 测试一次并按平均 SRCC 选最佳权重。当前正式结果为正常光电 Spatial/Temporal SRCC `0.6094/0.8393`，同一最佳 checkpoint 去光后为 `0.4676/0.7859`。

推荐配置只读取已经离线导出的两维标量软目标，不加载教师网络。教师仅影响训练 loss；部署模型、正常光电推理和同 checkpoint 去光推理的模块图完全一致，且推理中为零 Qwen、零 Transformer、零 attention。

完整形状与物理布局见 [ARCHITECTURE.md](ARCHITECTURE.md)，从零运行命令见 [RUN_COMMANDS.md](RUN_COMMANDS.md)，正式指标与证据说明见 [RESULTS.md](RESULTS.md)。
