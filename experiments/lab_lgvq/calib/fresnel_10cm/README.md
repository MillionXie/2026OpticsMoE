# MATLAB 方窗菲涅尔 ROI 标定

振幅始终播放 `A_WHITE.bmp`（1024×1024，全部为 255）。相位 BMP 中的黑色表示 0 rad，不表示遮光。

相位严格使用老师 MATLAB 的方窗二次相位：`-k*((p*x)^2+(p*y)^2)/(2*f)`，再对 2π 取模。P1 用于寻找 10 cm 焦面；P4 的四个中心对应 478×17 µm ROI 的四个物理顶点；P9 增加边中点和中心，用于检查翻转、畸变与 ROI。

当前 n4/n9 方窗为 160×160 相位像素，这是在 y=590、1200 行面板上保证四角完整、不裁切的安全尺寸。区域外保持 0 rad；没有圆形孔径、外围光栅或人为 CROSS mask。
