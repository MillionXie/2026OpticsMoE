# Single-layer MNIST-4 D2NN for the new dual-SLM path

这是独立的四分类手写数字光学演示工程，只识别MNIST数字 `0/1/2/3`。没有MoE、
token mixer、Qwen或电子分类头；唯一可训练参数是一张相位掩膜。

## 物理结构

```text
MNIST 400×400振幅
  → 居中放入478×478逻辑有效区
  → 17 µm振幅SLM（原生一像素对应一像素）
  → 4F共面成像到相位SLM
  → 478×478逻辑相位：phase = 2π·sigmoid(raw_phase)
  → 5 cm角谱传播，532 nm，17 µm逻辑采样，518×518仿真画布
  → 中心478×478 CCD逻辑ROI
  → 2×2四个积分探测区，argmax得到数字类别
```

4F把振幅面共轭到相位面，因此模型在振幅与相位之间不额外加入自由空间传播。相位层
之后只传播一次5 cm。`raw_phase`严格从全0开始，所以初始实际相位是均匀的 `π`；均匀
常数相位不会改变光强，但 `sigmoid'(0)=0.25` 最大，便于初期训练。

训练使用两个直接对应光路的目标，没有蒸馏或额外辅助任务：

```text
classification = -log(正确探测区能量 / 四个探测区总能量)
capture        = -log(四个探测区总能量 / 整个518×518输出能量)
loss           = classification + 0.2 × capture
```

第一项直接拉开四类间隔，第二项避免四个探测区都没有足够光。不需要电子头或教师蒸馏。优化器只接收
`raw_phase`，Adam初始学习率为 `0.02`，余弦下降最低只到 `0.002`。

## ROI与四菲涅尔焦点的对应

478逻辑像素使用17 µm采样；相位SLM使用8 µm采样。2×2菲涅尔阵列中相邻透镜
中心相距508个相位像素，而分类器相邻探测中心相距239个逻辑CCD像素：

```text
508 × 8 µm  = 4064 µm
239 × 17 µm = 4063 µm
```

中心间距的物理误差仅1 µm；每个焦点相对光轴的位置误差仅0.5 µm。因此先用四焦点
得到CCD坐标映射，再将完整有效区映射、裁剪并面积重采样成478×478，四个分类探测区
就与标定坐标一致。探测区半开边界为：

```text
class 0: [95,95,144,144]      class 1: [334,95,383,144]
class 2: [95,334,144,383]     class 3: [334,334,383,383]
```

如果CCD图像存在旋转或透视，不能只轴对齐裁剪；应使用四焦点拟合仿射/单应变换后再
映射有效区四角。方向编码菲涅尔图用于确定四点对应，均匀四焦点用于精确拟合。

## 硬件导出

训练完成后自动生成：

```text
runs/mnist4_single_layer_17um_5cm/hardware_export_normal_polarity/
├── phase_to_play/        # 一张1920×1200相位BMP
├── amplitude_to_play/    # 默认每类10张，共40张1024×1024振幅BMP
├── samples.csv           # 标签、仿真预测、能量比例和哈希
├── detector_regions.csv
├── detector_roi_478.png
└── hardware_contract.json
```

相位按17 µm逻辑坐标中心对齐地栅格化到8 µm原生像素，得到1016×1016有效相位区，
放在 `(980,590)`，并保留原光路的纵向翻转。振幅一逻辑像素对应一个原生17 µm像素，
478×478有效区位于 `[273,273,751,751]`。振幅BMP直接使用修正后的硬件极性：
`255=白/透光`、`0=黑/遮光`，不执行黑白反相。

CCD评估不做没有依据的背景扣除。探测区能量除以整帧能量，因此对统一的曝光时间、
增益或入射光强缩放不敏感。
