## 01_fresnel_10cm

复制了此前生成的整套菲涅尔标定文件。`00_teacher_original_*` 是老师的原版 **30 cm / 9.2 µm / 1920×1152**，只作参考，**不要当作本次 10 cm 相位图**。`01`–`05` 才是 532 nm、8 µm、10 cm、1920×1200；每张都有 normal 与 `inverse255` 两版，其中反灰度关系为逐像素 `255 - normal`。建议先用振幅 `A_WHITE_1920x1080.bmp` 和 `01_single_10cm_8um_inverse255.bmp` 看焦距，再用 `03_four_roi_vertices_10cm_8um_inverse255.bmp` 看四角。四角设计在相位 SLM 有效区顶点，不是直接把相机坐标画到相位图上。焦点实验才能确认相位符号，不要仅凭文件名认定反灰度必然正确。详见此文件夹自身 README 和 manifest。

## 02_mnist_10cm

先在相位 SLM 加载 `phase/B_RECOMMENDED_native8_best.bmp`；振幅 SLM 播放 `inputs_40_fixed/mnist_i00013_y0.bmp`，之后换其他数字。文件名 `_y0`–`_y3` 是真值标签；每类固定 10 张，全部 40 张均来自先前未按实测结果筛选的 test 子集。不要把 1–2 张的成功当作准确率，完整测试可记录 40 张的四探测区能量及预测。

`phase/A_old_post_robust_resampled_8um.bmp` 是旧 `post_robust_best`（epoch 12）在 8 µm 原生栅格上的固定重采样对照。B 是原生 8 µm 网格重训选出的 best epoch 10。二者都对应 **532 nm、10 cm**，相位输出均为 **先逻辑上下+左右翻转，再 8 µm 栅格化，最后整幅灰度 `255-g`**，中心 `(960,600)`。这是旧实验室相位 LUT 的已测试导出约定，不要再手工翻转或反灰度第二次。振幅输入不做额外翻转；相机的左右镜像应由新四角 homography 处理，不在 BMP 上额外处理。

此前相同固定 40 张、旧 SHS 光路/ROI 下，A 实拍 24/40，B 实拍 37/40；完整 4157 张 test 的**仿真**分别为 86.5528% 与 88.7659%。这些是历史条件下的结果，**不能保证当前小相机、新 ROI 的准确率**。当前 CCD 的四角坐标和方向需要重新标定，不能沿用 2026-09-13 的 SHS 坐标。固定四探测区分类也需要先把相机原图按新的四角映射到逻辑 478×478，再积分四个 59×59 区域；绝不能对原相机图直接套旧框。历史核验见源工程 `ABO_Lab_SHS_8um/MNIST_VALIDATION.md` 与 `MNIST_NATIVE8_COMPARISON.md`。

## 03_dual_slm_alignment

每个子文件夹是一组配套图：`A.bmp` 放振幅，`P.bmp` 放相位；`P_V.bmp` 是仅相位上下翻转的诊断对照。建议先试 `01_check64`，再试 `02_blocks_x`、`03_blocks_y` 判断轴向。**不要同时加载 P 与 P_V**；两者是替代候选。相位灰度已按反向 LUT 编码，不要再做 `255-g`。`preview.png` 是逻辑示意，不是 CCD 预期像素级图像。格子包与 MNIST 训练相位的翻转约定是不同实验的导出设置：不要拿格子文件名推断 MNIST 相位该再翻一次。比较 CCD 上亮块与衍射条纹时，须区分几何镜像、相位方向和 LUT 相位符号。

## 测试顺序和安全边界

1. 两块 SLM 的 GUI/SDK 不要同时争用同一设备。先用低光强/短曝光确认相机未饱和，再调到信噪比足够的曝光。
2. 菲涅尔单焦点 → 四角焦点；随后格子配准；最后固定同一输入做 A/B 相位对照，再跑 40 张。
3. 每次换相位后用 CCD 同一振幅输入复拍一张，确认输出确实改变；若出现桌面、默认文字、全白或不变的光场，先停测并恢复 SLM 显示，不把这些帧纳入统计。
4. 当前包只提供静态投影文件与来源说明，**没有自动控制相机、也没有把新 CCD ROI 标定成 MNIST 判读器**。在新四角标定前，只能做手工目视/定性对照，不宣称新的识别准确率。

源文件均原样复制，未重新生成或重新编码相位/振幅像素。`02_mnist_10cm/training_result.json` 给出相位导出参数和 SHA256，可据此核对相位文件。
