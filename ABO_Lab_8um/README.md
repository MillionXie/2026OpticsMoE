唯一操作入口是 [COMMAND.md](COMMAND.md)。本目录与旧 experiments 工程隔离。

四个单角菲涅尔。`generated/P_opposite_vertical`仅用于确认相位上下方向，正式输出仍为`generated/P`。

双SLM像素配准已改为`dual_patterns.py`生成的`generated/dual/01_check64`等四组，
每组`A.bmp`与仅在对应白区加载条纹的`P.bmp`严格配套，另附相反上下方向`P_V.bmp`。

## 内容与边界

- `imports/`：3 个原始 ZIP；`original_*/`：只读留存的原包。
- `runtime/`：原版模型代码及本项目所需硬件 SDK；`assets/`：固定 checkpoint、2400 测试图、100 个标题、相位数组。
- `models/`：冻结 Qwen tokenizer/config 和原生前端参数。实验包只物化学生使用的参数，不加载被替换掉的 Transformer。
- `generated/cal/`：标定 BMP；`generated/P/`：六张正式相位 BMP。短文件名，不依赖旧包路径。
- `sessions/<名称>/`：该次配置、分阶段播放 BMP、原始 CCD、规范化坐标 CCD、结果。配置变化必须换会话名。
- `results/`：仿真复核、硬件探测、曝光检查证据。

模型路径：冻结 Qwen 图像/文本前端 → Vision 光 router / 专家 / global → 图文嵌入合并 → Language 光 router / 专家 / global → 原电子读出 → 64 维归一化嵌入 → 与全部100标题余弦匹配。图像走六次光传播，候选标题也须走三次 Language 光传播，不能默默换成仿真标题。

`backend.py` 只改变加载方式。保留 tokenizer、embedding、位置处理、patch embedding、merger、学生残差、融合、router、相位和读出。原 A100 通讯协议不用于新硬件，原包仍留存以便审计。

## 物理合同

模型仍为 532nm、10cm、478×478、逻辑像素17μm，物理宽度8.126mm。Holoeye与相位屏均8μm，因此有效光场约1016×1016设备像素。输入振幅双线性插值；相位按物理坐标最近邻，绝不对包裹相位直接双线性插值。相位使用原导出约定 floor(mod(phi,2π)/2π×256)。

振幅面板已通过SDK核验为1920×1080、8μm，连接时仍强制核验分辨率。相位1920×1200，手动加载。中心位置、方向、CCD四角须在新台架实测。默认无翻转不是已经证明方向正确；禁止沿用师姐的CCD坐标和Meadowlark LUT。

四角菲涅尔已更正：`fresnel.py`从用户三张15/20/40cm参考BMP核对出正二次灰度相位和`floor(255*mod(turns,1))`编码，三张全图逐像素重建误差均为0。新版是四个直接相邻的方形透镜区域，不是旧176px孤立窗口；不对已wrap BMP做缩放或灰度倍乘。只生成新版运行`python fresnel.py`，输出`generated/cal/Phase_BMP/P_F4_10cm.bmp`、全白振幅、带坐标预览和几何JSON；`patterns.py`的P_F4及四个单角诊断也已接入相同算法。原三张BMP保留不动。P_F1/P_F9暂保留旧诊断实现，本次四角标定不用它们。

当前相位中心(959.5,599.5)，四镜心为(451.625,91.625)、(1467.375,91.625)、(451.625,1107.375)、(1467.375,1107.375)，恰为8.126mm ROI连续四角。参考图镜心距400px，当前必须1015.75px；完整紧邻方窗阵列需2031.5×2031.5，超过1920×1200屏，所以外缘被屏幕截断，四中心和内部连接不变。默认四区覆盖全屏，振幅全白，不加四孔/圆形开口。

**限制必须保留**：8μm、532nm、10cm时，局部相位梯度的Nyquist半径约415.625px；当前外侧有约1.64px/周期的条纹，因此不能保证无混叠或无额外焦点。改变ROI、像素或焦距才能改变该限制，不能为了让图好看偷偷缩小镜心间距。参考BMP的灰度方向不等于实机已标定的相位正负号；本次没有操作硬件、验证焦点或改正式模型相位。预览上的标记不写入播放BMP。

## 图像与精度口径

2026-09-10 Router检查修正：固定checkpoint的100个标题纯仿真p2-p3均小于0.01（范围0.0001201–0.0007581；title_000为0.0004447），因此原硬门槛与模型不相容。
`router_quality.py`仅将该项降为告警，保留实测Top-2以及所有其他原始质量检查。网络、输入BMP、归一化、曝光与硬件身份均不改变。
`recover_router.py`可核验旧失败帧的原始TIFF及其线性校正PNG，补充路由与有效记录，不打开设备、不重采、不更改像素。
旧帧缺少采集时的相位/BMP哈希时须显式确认，恢复元数据保留该证据限制。后续新采集在检查前保存完整身份。

原始 `.tif` 使用无损压缩，不做逐图归一化/对比度增强；NPY仅用于相机进程传输，TIFF校验成功后移除临时副本。规范CCD `.png` 只做四角单应变换→478平方，按填写的传感器固定值域线性转8bit，不再翻转，不加log/gamma/CLAHE。网络内部保留原训练模型既有处理，不为了视觉相似额外修改。

8µm插值仅保持物理尺寸，不可能自动纠正Holoeye灰度响应、像差、偏振或光学放大率。先做32灰度×3帧响应和非对称方向验证，再少量六阶段试采。曝光3500μs只是起始值，不是从师姐设备移植后的标定结论。

当前包只含test，不含训练集。不得把2400 test悄悄当训练集微调；若以后微调，应显式补充训练数据并建立新版本/会话。本次不宣称已完成实测准确率复现。
