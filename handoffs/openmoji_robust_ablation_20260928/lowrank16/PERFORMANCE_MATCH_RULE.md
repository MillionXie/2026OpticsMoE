# 正常仿真性能匹配消融（预先固定规则）

基础组同一 TRAIN 留出集的无扰动验证 Changed-cell Accuracy 为 **0.9225**。四组架构均为 rank-16，实验目标是使各扰动训练组的**正常仿真验证值**尽量靠近这一基准，再比较实验光路结果；不得按原 TEST1000 精度挑 epoch。

已完成的8轮续训验证曲线显示：r1 的第1轮为0.9170（与基础相差0.0055）；r2 第3轮为0.9230（差0.0005）；r3 第2轮为0.9195（差0.0030）。因此预先锁定续训上限分别为 **1/3/2 epoch ×100 step**，从各组原12轮VAL-selected权重起步；训练扰动保持各组原配置。每组仍按其区间内无扰动VAL最优保存best，之后只做一次相同无扰动TEST对比。若本次重复运行曲线不同，也不得因TEST结果改选轮次。原最大VAL续训结果和原报告均保留，不覆盖。

这种“验证精度匹配”设计与“严格同训练步数”不是同一个实验；各组累计训练步数分别为基础12轮、r1 13轮、r2 15轮、r3 14轮。它适合控制正常仿真精度后观察鲁棒措施，不可宣称训练预算相同。原模型和已有TEST已参与研发判断，这也不是新的独立盲测。
