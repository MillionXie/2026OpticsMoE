# OpenMoji 更小电子头容量选择（TRAIN 留出集）

共同起点：用户自有 0.8890 原版权重 SHA-256 `579b19e78befe93cd258ce02308235f1a9176316f37bc42fc2e1b6ff06d38e9f`。同一 FIT4000/VAL1000、12 epoch × 100 step，四种低秩结构均仅用 VAL 做容量校准。TEST1000 不参与这些校准 run。

| 读出头 | 参数 | 最佳 VAL Changed-cell |
| --- | ---: | ---: |
| 原共享头 | 381,976 | 参考 0.9620 |
| rank-48 | 234,520 | 0.9580 |
| rank-32 | 197,656 | 0.9400 |
| rank-24 | 179,224 | 0.9395 |
| rank-16 | 160,792 | 0.9235 |

当前用户的目标是压缩电子头并使理想仿真回到约 0.8890，而非只追求最高仿真精度。选验证准确率仍高于 0.90 的最小头 rank-16（较原头减少 57.9%），固定结构后，四组按相同预算训练并仅以各自 VAL 选 best，最后再统一报告 TEST。rank-32 的先前 TEST 0.9115 已经被看过，因此此次结构决策不是全新盲测；不能把最终 TEST 当作完全独立于研发过程的数据。也不能通过 TEST 挑 epoch 凑目标值。

缩小电子头是有实际架构意义的控制变量；不能仅因仿真数值变低就声称光路鲁棒性或真实仿真-实测差距改善。五组均需真实 CCD 验证。
