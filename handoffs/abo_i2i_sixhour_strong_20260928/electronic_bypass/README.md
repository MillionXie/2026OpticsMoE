# ABO electronic bypass probe (2026-09-28)

## 2026-09-28 electronic-only robustness continuation

Independent-identity audit (2026-09-28): the source ABO similarity manifest has 2,400 rows, exactly 200 product IDs with 12 images per product (1,440 train / 480 validation / 480 test rows). Thus the current source manifest supplies no additional product identities for a genuinely unseen-product validation. Further generalization claims require a separately sourced, non-overlapping product set; do not recycle the historical 800-query set for model selection.

The selected physical six-layer model was copied into a **separate electronic-only student**. Its optical paths were disabled, frozen front-end and all optical tensors preserved, while existing electronic residual blocks/readout (1,126,472 trainable parameters; no new inference branch) were trained for six short epochs with complete-object mild brightness/contrast/translation augmentation and a frozen electronic-descriptor anchor. Only 1200 TRAIN images received gradients; 400 TRAIN-holdout images selected epoch 6. This holdout contains product/photo identities seen by the warm-start model in earlier training and is not independent generalization.

On that holdout, electronic-only R@1 improved **0.8300→0.8925**. Paired with the frozen physical gallery descriptors at the validation-selected 0.5 electronic share, R@1 improved **0.9100→0.9325** on the original physical capture. On the later recovered physical capture, the TRAIN-holdout scores were physical-only **0.8450**, electronic-only **0.8925**, fused **0.9175**. No original 800-query data were used to fit weights or choose the 0.5 ratio.

One sealed retrospective replay on the existing 1600 real-CCD gallery and 800 real-CCD query identities yielded R@1 **0.7975** for the validation-selected 0.5 fusion, versus **0.7625** for the previous frozen 4096-parameter adapter on the same recovered CCD. The new electronic-only ablation gave **0.8175**; the unchanged selected physical path gave **0.5975**. This is a substantial indication that the electronic path carries useful information despite the light-path transfer gap, but the same 800 queries were previously evaluated during development: **do not treat 0.8175 as an independent prospective result or retune the fusion ratio on it**. Per-query predictions and complete metrics: [electronic_robust_fixed_query_report_20260928.json](electronic_robust_fixed_query_report_20260928.json). The selected electronic checkpoint is [electronic_only_robust_best.pt](electronic_only_robust_best.pt), SHA-256 `dd5e6e5026ec6629180fe2594d75205a5b0875cfe8d7f563ccf2d50b2bc36f37`. Using the same selected optical checkpoint `f413efa865d6b1b7252d2b3babd0cedfbb4415a362f0818feafa36f2843f292e`, the model's existing electronic modules were run with both optical branches disabled. Those electronic-only descriptors bypass all six optical captures. They were combined **after** the existing physical six-stage descriptor; masks, upstream weights, BMP encoding, hardware settings and recorded CCD frames were unchanged. This is a late-fusion experiment, not a retrained six-layer model or new capture.

The 1600 physical TRAIN gallery entries were split 1200 fit/400 validation by the existing audited IDs. Electronic share was selected only by validation: descriptor fusion at 0.5 had R@1 0.8575, against physical-only 0.8300 and electronic-only 0.8100. The fixed 0.5 fusion was then evaluated once on the 800 physical query images against the 1600 physical gallery images: R@1 **0.7950**, R@5 0.9225, R@10 0.9575, MRR 0.85264. The same query evaluation reported physical-only R@1 0.75625 and electronic-only R@1 0.75625. The physical-only replay exactly matched the prior sealed result. No new camera captures were made.

Two TRAIN/VAL follow-ups were rejected without query evaluation: a 1,537-parameter low-rank residual fusion trained for 120 epochs selected its initialization (no validation gain), and score-level fusion peaked at validation R@1 0.8425, below descriptor fusion. Neither is deployed. Scripts and detailed reports remain in the independent bench candidate; report copies are alongside this README.

A subsequent electronic-only 64x64 linear adapter added **4,096 parameters**. It was initialized as the identity, fitted on the 1200 TRAIN rows with ranking/anchor loss, and selected at epoch 133 on the 400 VAL rows: fusion VAL R@1 0.8575→0.8650. With that fixed adapter, the 800 physical queries were evaluated once: R@1 **0.8000** (640/800), R@5 0.9250, R@10 0.9550, MRR 0.85629. This reaches the numerical 0.80 threshold exactly, not above it. The original six-layer masks and all 14,400 saved CCD images remain unchanged; the adapter is a late electronic addition, not a new optical checkpoint. The adapter weight and ID-level predictions are alongside this README.

This is a retrospective result on a query set previously evaluated during development, not an independent prospective generalization estimate. The 400-row validation is drawn from TRAIN products seen during earlier optical training. The electronic-only path is not stronger than the optical one by itself; their complementary errors account for the observed gain, but no causal mechanism beyond this ablation is established. Do not tune further on these 800 query outcomes. Confirm stability on genuinely fresh query/gallery captures before calling the model robust.

A further 24,640-parameter raw pre-optical visual bypass was tested only on TRAIN/VAL. Its best validation checkpoint remained the starting adapter (R@1 0.8650); later training fell to about 0.84. It was rejected without another query evaluation. This supports retaining the smaller 4,096-parameter adapter for now rather than assuming a wider electronic branch must help.
