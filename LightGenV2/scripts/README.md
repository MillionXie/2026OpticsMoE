这些脚本读取已有报告/CSV，部分会复制原始证据、绘图、写汇总或SHA清单。
**不要将原历史报告目录当作可覆盖输出目录，也不要为工程整理执行它们的main。**
Qwen汇总要求输出目录内事先有 `fresh/`、`work/` 实测来源；旧证据复制函数拒绝
覆盖既有目标，但不是整个main的事务保护。要重新生成派生汇总，先另行审查输入与
目标，准备新的输出位置；源数据和原报告不改。

`profile_latest_qwen_changed_a100.py` 是Qwen汇总所引用的旧测量来源，当前仍为
受保护的本地/服务器历史源码，未在本批采用；不能声称该测量运行入口已闭合。
本批CPU测试仅验证统计、等效工作量换算与已有证据覆盖拒绝，不证明完整环境、
原始模型资产、历史运行污染审计或新的模型性能/端到端时延。

原始逐样本时间、功率、来源报告、历史代码快照及所有测速均保留。
