# LGVQ 时间质量：红框数据的运算量与 TOPS/W

## 结论

按红框固定数据：

| 方法 | 16视频时间 | 16视频能耗 | 反算平均功率 | 计入运算量 | 有效吞吐 | 能效 |
|---|---:|---:|---:|---:|---:|---:|
| Ours | 8.660 ms | 1.162 J | 134.180 W | 2.506962 TOP | 289.488 TOPS | **2.1575 TOPS/W** |
| Qwen3VL | 1200.053 ms | 103.784 J | 86.483 W | 39.202220 TOP | 32.667 TOPS | **0.3777 TOPS/W** |

在该明确口径下，Ours 的 TOPS/W 是 Qwen3VL 的 **5.7116 倍**。

这里的 Ours 必须在论文中写作 **effective TOPS/W（等效 TOPS/W）**，因为自由空间传播没有在数字芯片上逐条执行乘加指令；其运算量是对应全场复数线性变换的等效运算量。Qwen3VL 则是实际执行网络的 MAC-derived OP。

## 统一算术口径

- 一个实数 MAC 计为两个 OP：一次乘法和一次累加。
- 一个稠密复数 MAC 计为八个实数 OP：复乘的四次实乘、两次实加，以及复数累加的两次实加。
- 统计 Linear、Conv以及注意力的 `QK^T` 和 `AV`。
- 不把激活、归一化、池化、归约、索引和Softmax加入MAC-derived OP。双方使用相同排除原则。

因此：

```text
TOPS/W = 本次推理的总TOP / 本次推理能耗J
       = 有效TOPS / 平均功率W
```

## Qwen3VL运算量

计数边界与红框一致：每个视频4帧、每帧448×448，从第一个原生Vision Transformer Block输入开始，到完整词表投影和五质量词分数输出。单视频实际张量为：

- Vision Block 0输入：`[1568,1024]`；
- Language Block输入：`[1,446,2048]`；
- 24个Vision Block；
- 28个Language Block；
- 词表投影：`2048 -> 151936`；
- 红框的16视频由16个batch=1前向组成。

| 模块 | 单视频GMAC |
|---|---:|
| Vision注意力QK/AV | 60.423143 |
| Vision Block线性层 | 473.520144 |
| Vision Block后的merger/deep-stack | 39.460012 |
| Language注意力QK/AV | 22.813278 |
| Language Block线性层 | 628.541620 |
| 完整词表投影 | 0.311165 |
| 五质量词读出 | 0.000010 |
| **合计/视频** | **1225.069373 GMAC** |

所以：

```text
单视频OP = 1225.069373 GMAC × 2 = 2.450139 TOP
16视频OP = 2.450139 × 16 = 39.202220 TOP
有效吞吐 = 39.202220 TOP / 1.200053 s = 32.667074 TOPS
TOPS/W = 39.202220 TOP / 103.784 J = 0.377729 TOPS/W
```

## Ours运算量

红框对应一幅478×478有效光场同时放置16个视频、每视频4帧，并经过六次相干全场传播。电子部分严格匹配8.660 ms/1.162 J报告中的窄口径组件及实际调用次数。

### 光学等效运算

```text
有效空间模式 N = 478 × 478 = 228,484
六次传播复数MAC = 6 × N × N
                  = 313,229,629,536 complex MAC
等效实数OP = 313,229,629,536 × 8
           = 2,505,837,036,288 OP
           = 2.505837 TOP
```

这是把每次自由空间传播视为一个从全部输入空间模式到全部输出空间模式的稠密复数线性变换。它是光学系统的等效计算量，不是FFT仿真程序的指令数。

### 电子神经网络运算

| 组件 | 次数 | 单次MAC | 总MAC |
|---|---:|---:|---:|
| 帧级CCD非线性读出 | 2 | 57,802,752 | 115,605,504 |
| 视频级CCD非线性读出 | 2 | 12,386,304 | 24,772,608 |
| 帧级并行电子残差 | 2 | 130,658,304 | 261,316,608 |
| 视频级并行电子残差 | 2 | 25,417,728 | 50,835,456 |
| Bridge神经网络 | 1 | 12,832,768 | 12,832,768 |
| 最终时间质量任务头 | 1 | 97,206,272 | 97,206,272 |
| **合计** |  |  | **562,569,216 MAC** |

电子部分为：

```text
562,569,216 MAC × 2 = 1,125,138,432 OP = 0.001125 TOP
```

光学与电子合计：

```text
总OP = 2.505837 + 0.001125 = 2.506962 TOP
有效吞吐 = 2.506962 TOP / 0.008660 s = 289.487549 TOPS
TOPS/W = 2.506962 TOP / 1.162 J = 2.157455 TOPS/W
```

## 复数MAC口径敏感性

如果合作方采用更保守但物理含义较弱的“一个复数MAC只记成一个MAC，再按一个MAC=2 OP”，则Ours为：

```text
总OP = 0.627584 TOP
TOPS/W = 0.540090 TOPS/W
```

因此不能只写一个数字而不声明复数运算换算规则。本文建议主表使用 `2.1575 effective TOPS/W`，脚注注明 `1 complex MAC = 8 real OP`；补充材料同时给出0.5401的敏感性结果。

## 公平性边界

- Qwen3VL计入第一Vision Block之后的24层Vision、28层Language、完整词表投影和五质量词读出；patch embedding、视频解码、processor、H2D不计。
- Ours计入六次物理光学传播，以及红框能耗中对应的CCD读出、电子残差、bridge和任务头；排版、搬运和I/O不计。
- Ours在线推理使用预先生成的Qwen边界特征，不在线执行Qwen Transformer。这与当前红框的速度和能耗边界一致，但论文中必须明确，不能写成从原始MP4端到端的比较。
- Ours的TOPS/W是光学稠密线性变换的等效值；任务级能效仍应同时报告为13.769 videos/J，对应Qwen3VL的0.1542 videos/J。
