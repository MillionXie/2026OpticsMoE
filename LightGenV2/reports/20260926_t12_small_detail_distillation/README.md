# 小版清晰度优化：蒸馏和训练期 PatchGAN

本轮从上次联合恢复训练的小版继续，不从头训练、不覆盖旧版。生成器仍为
11,137,746 参数（冻结共享 Qwen embedding 按既有约定另计），输入输出 256×256。
两层 Qwen-style 文字头、语言/图像光路、电子与光学并行结构全部保留。
光学 alpha 约 0.487–0.497，仍不小于 0.4。大版权重不变。

## 方法和边界

1. 蒸馏版继续 800 步，batch=2，学习率 2e-5，保留原图像 MSE、0.1×L1 和文字特征蒸馏。
2. 新增训练期冻结的 ImageNet ResNet18 浅层特征损失（0.02），边缘 L1 权重增至 0.08。
3. 同一批参考图和 prompt 经过冻结大版得到老师图像。仅在大版局部误差比学生更低的
   区域施加 RGB 和边缘蒸馏（0.1）。区域由训练 GT 判断，推理不使用 GT、区域标签或老师。
   这不是不同宽度网络之间直接对齐中间层，也不保证老师所有纹理都可信。
4. GAN 候选从蒸馏版再训练 1600 步，感知权重 0.05、边缘权重 0.1。
   使用参考图条件 PatchGAN、spectral normalization 和 hinge discriminator loss；
   生成器对抗权重 0.003，在前 200 步渐增。判别器不读取 prompt，不是语义匹配判别器。
5. 按固定 144 个验证对的 `MSE + 加权感知损失 + 加权边缘损失` 保存最优检查点，
   两阶段均选中了末尾检查点。不同阶段损失权重不同，不能直接比较两个综合分数。
6. 仍为理想 DC20 仿真恢复训练；没有加入随机硬件扰动，没有移除衍射传播。

老师、ResNet18、判别器全部只用于训练，不加入推理权重或推理耗时。
没有硬掩码贴图、GT 拷贝或输出后锐化；已有可学习 source gate 参数化保持不变。
两份 PT 仍需上轮说明中的 source 构建配置及共享 embedding，不能无外部资产独立运行。
新推理使用 `audited_unified_run infer --checkpoint <对应新PT>`，不要用旧的通用入口。

## 完整测试对照

三个版本均使用同一 2304 个 test 编辑对。MSE 在 [-1,1] 计算；PSNR 峰值范围为 2。
FID 为 ImageNet-Inception 变体，不是可与外部论文直接比较的 canonical FID。

| 指标 | 上轮小版 | 蒸馏版 | 蒸馏＋GAN |
| --- | ---: | ---: | ---: |
| MSE ↓ | 0.004009 | 0.003549 | 0.003412 |
| PSNR dB ↑ | 29.991 | 30.519 | 30.691 |
| 边缘 L1 ↓ | 0.087252 | 0.081365 | 0.078730 |
| ImageNet-Inception FID 变体 ↓ | 104.613 | 99.646 | 98.723 |
| KID ↓ | 0.023837±0.003717 | 0.023291±0.003247 | 0.024643±0.004427 |

优先看蒸馏＋GAN 候选：相较上轮 MSE 降低约 14.9%、边缘误差降低约 9.8%、
PSNR 提高约 0.70 dB。但没有纯 GAN 消融，不能将全部收益归因于 GAN；
KID 未改善且波动区间重叠，不声称所有生成指标都变好。

改善仍有限，不声称消除了模糊。台灯底座纹理、靠垫褶皱和细桌腿仍需看真实预览判断，
部分目标替换存在原物体残影。任务、固定目标目录和 seed 多样性边界与上轮相同。
