## “不同权重”具体是什么

实验版本可针对实测数据适配，SHA不同本身不等于版本错误。以下关系不因补算而改写。

| 任务 | Sim到Exp的训练/结构关系 |

## 冻结CCD重放与数据保护

`replay_in_place.py` 已发布main：SALICON执行固定Git内容 `6c07ced42`，OpenMoji执行 `d202c6987`。只调用归档项目原runtime的模型、OpticalBoundary和指标实现，强制CPU、eval和无梯度。完成时核对模型全部state tensor前后SHA、原PT、输入清单/缓存、逐帧SHA/相位身份，并断言未初始化CUDA。

分析脚本内容按Git版本和源码SHA核验后从标准输入执行，**不安装或覆盖实验室源码，不在远端写文件，不调用相机/SLM/SDK**。补算结果和逐例中间记录只返回本地 `source_records/derived/`。原始PT、CCD、输入、报告及设备状态不变。本轮不新增推理网络、训练loss或光学合同，不重新采集。

- OpenMoji：1000条/6000帧，8项整体及4×8分操作指标均与旧报告一致；逐例预测网格、编辑掩膜及CCD SHA保留。原请求曝光20000µs，6000份收据各层实际回读均为20002µs，gain1/wait240ms不变，二者分别记录，未修改或缩放CCD以“修正”曝光。
- SALICON：5000份输入缓存均核SHA、15000帧核对旧报告逐帧SHA。Sim与Exp均用相同原标签/指标实现补齐六指标；原CC不覆盖，CPU重放CC另存。其他指标逐图均值与本次完整累计器相符，并与原整体报告核对。CPU重放CC均值为Sim .8624944850 / Exp .8597746968，与原报告并非逐位相同，差约1.98×10^-6 /0.73×10^-6；原CC主列保留，重放结果另组可查。各项整体差异在预设3×10^-5核验容差内。
- 三方向检索：只重排原保存特征/embedding，不重新训练或采集；MAP使用所有正例名次，MAP@10单列，不能从首正例排名杜撰多正例AP。
