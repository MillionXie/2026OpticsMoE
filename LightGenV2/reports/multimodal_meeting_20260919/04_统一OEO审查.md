# 统一 OEO 审查与重跑方案

当前三组结果不能直接称为“同一个 OEO”：

| 任务 | 当前实际配置 | 是否已用音文标准 OEO |
|---|---|---|
| RGB/SAR | 无逐层 OEO，复场连续传播后 CCD 读出 | 否 |
| CLEVR 图文 | 每层：强度→均值归一化→`u/(1+u)`→单位功率振幅、相位清零 | 是 |
| 音文 | 每层：强度→均值归一化→`u/(1+u)`→单位功率振幅、相位清零 | 是 |

因此现有三组测试表只能作为历史配置汇总，不能作为严格的“统一 OEO”比较。统一版本应采用音文的 `intensity_softsign`：

```text
I = |E|²
u = I / mean(I)
r = u / (1 + u)
A_next = r / sqrt(sum(r²))
phase_next = 0
```

它作用于传播后的整幅有效面，不作用于复电场，不包含可训练电子权重；末层也执行 OEO，然后再做 CCD 窗口积分。三组应统一执行一次 OEO 后再进入下一层。RGB/SAR 的10类输出应改为10个检测窗口，图文和音文仍为两个窗口二分类。

## 公平训练合同

三组均采用两层主光路、相同传播距离和相同 OEO；MoE 与 D2NN 使用相同输入总功率、相同输出窗口、相同 batch、学习率、训练轮数和验证 NLL 选模规则。MoE 额外的动态路由相位单独记录参数量和路由功率；D2NN 是单张完整输入覆盖478×478全孔径，不复制成四个固定空间专家。D2NN 的四路统计若保留，只能写作接口分区的 `[0.25,0.25,0.25,0.25]`，不能称为学习路由。

## 输入排布

- RGB/SAR：冻结 CNN 输出128维特征，排成16×8后最近邻扩展到224×224，作为单幅光场输入；D2NN将同一幅224×224场双线性放大覆盖478×478。RGB与SAR均逐样本归一化到单位输入功率。
- CLEVR：RGB图像经过冻结 CNN，文本逐词 one-hot；视觉与文本槽位各占0.5功率。历史 `[V,V;V,T]` 布局保留，三份视觉槽位是接口重复，不代表增加信息。
- 音文：64×101 log-mel 谱和32×64逐词 one-hot分别映射到左右两个224×112区域，各占0.5功率，拼成一幅224×224场；D2NN将两区分别放大后拼成478×478，MoE每个专家接收完整输入。

## 轮数与选模

现有可比预实验为：CLEVR与音文光学网络30轮，seed17，batch32，Adam初始 lr=0.01 余弦降至0.001；CLEVR视觉 CNN 预训练60轮后冻结，音频没有 CNN；EuroSAT 原版共享 CNN 预训练20轮后冻结，光学网络20轮。若改为统一 OEO，三组都必须从随机初始化的光学权重重新训练，建议各30轮，并沿用“每个模型各自最低验证 NLL 选 checkpoint，再一次性测试”的规则。不能把无 OEO 的 EuroSAT checkpoint 直接当作统一 OEO 结果。

## 当前结果如何解释

CLEVR 的69.27%/57.47%确实不是75%以上；此前较高的约72%结果来自不同 OEO/训练合同，不能直接搬到统一 OEO 表中。RGB/SAR 原版测试差距是75.65%−72.85%=2.80个百分点，验证差距是3.55个百分点，并没有一份同合同下已核验的“大幅差距”版本。若需要更大差距，只能重新固定 OEO、输入与训练预算后重跑，不能从不同版本挑选 MoE 和 D2NN 的最好分数拼表。

本文件是重跑前的审查结论；在统一 OEO 版本完成训练和独立测试前，不把“CLEVR≥75%”或“RGB/SAR大幅领先”写入论文结论。
