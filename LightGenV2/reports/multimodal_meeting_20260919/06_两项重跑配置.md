# 两项待重跑配置

## RGB/SAR：无电子前端 + 逐层 OEO

配置文件：`LightGenV2/demo_check/pure_optical/config_oeo_intensity_softsign.json`

- 电子前端：取消；输入仍为原始 RGB 或 SAR 56×56×3，经固定通道排布得到224×224单位功率振幅。
- MoE：四个224×224专家，路由一次，四路全部相干传播；D2NN：一张224×224输入双线性放大覆盖478×478全孔径。
- 两层主光路；每层传播后执行 `I=|E|² → I/mean(I) → u/(1+u) → 单位功率振幅、零相位`。
- 输出：10个32×32窗口，归一化能量作为10分类概率。
- seed42、30轮、batch32、Adam lr0.01余弦降至0.001、水平翻转、验证准确率/NLL选模。
- 训练与测试必须使用相同空间划分；测试不参与选模。

该配置保留了旧无 OEO 版本，新增 OEO 版本不会覆盖历史结果。服务器正式命令：

```bash
CUDA_VISIBLE_DEVICES=0 python LightGenV2/demo_check/pure_optical/run.py \
  --phase train --config LightGenV2/demo_check/pure_optical/config_oeo_intensity_softsign.json \
  --data /DATA/DATA1/guest3/demo_reproduction_data/eurosat/phase_only_v1/data.npz \
  --out LightGenV2/demo_check/runs/simulation/eurosat_oeo_intensity_softsign_s42_v1
```

## CLEVR：无 phase dropout

- 保留冻结 CNN 前端；CNN 预训练时的临时24类辅助头已移除，不参与光学输出。
- 文本为固定逐词 one-hot；视觉与文本输入功率各0.5，历史 `[V,V;V,T]` 排布。
- 两层主光路，每层使用 `intensity_softsign` OEO；两个64×64窗口二分类。
- seed17、30轮、batch32、Adam lr0.01余弦降至0.001；`phase_dropout=0`。
- MoE 与 D2NN 分开从随机初始化训练，按各自最低验证 NLL 选 checkpoint，再统一测试。

服务器正式命令：

```bash
python -m LightGenV2.tasks.t09_multimodal_matching.run \
  --phase train --data /DATA/DATA1/guest3/demo_reproduction_data/clevr_attribute_s17_v1 \
  --out LightGenV2/tasks/t09_multimodal_matching/runs/simulation/clevr_visual_softsign_nodrop_s17_v1 \
  --architecture both --epochs 30 --phase-dropout 0 \
  --oeo-activation intensity_softsign --seed 17 --batch 32
```
