## 局部训练怎样做

每张训练图选两个不同的 96×96 区域。使用 GT 的 RGB 梯度和 GT－参考图差异评分，
优先高细节、需要修改的区域，限制横向裁剪中心范围以降低背景主导。
这不是人工标注的灯罩／桌腿语义分割，不保证所有裁剪均只包含物体。

对这些对齐区域增加：

1. 冻结 ImageNet ResNet18 浅层特征 L1，强调局部感知结构。
2. 有方向的 RGB 水平／垂直梯度 L1，补充原有灰度边缘幅值监督。
3. 局部老师图像蒸馏，仍只在大版比学生更接近 GT 的局部位置应用，权重为局部损失内 0.5。

局部总损失权重 0.04。保留上一轮损失：MSE、0.1×L1、0.08×边缘、
0.02×整图感知、0.1×整图可靠老师蒸馏、0.01×文字蒸馏、0.003×source gate、
0.05×修改区域 L1、0.001×轻量对抗。**没有提高 GAN 强度。**
lr=1e-5，batch=2，1200 步；固定 144 个验证对每 300 步评估。
选择分数包含 MSE、加权整图感知／边缘和局部细节（不含老师）；最优为第 1200 步。
训练记录里的 selection_metric 文本标签沿用了旧简写，但实际计算已包含 local_detail_weight。
验证 MSE 0.002618→0.002481。

## 推理不变

仍为 9,958,098 参数；冻结 Qwen token embedding 按约定单列。
两层 Qwen-style 文字头、语言及图像真实仿真光路均保留，alpha 约 0.487–0.497。
电子／光学同输入并行，纯相位仍 958,728。采用理想 DC20 仿真，没有随机硬件扰动训练。
GT、裁剪区域和老师都不用于推理。整张图由模型输出，不采用硬掩码 GT 贴图。

## 评测注意

同一 2304 个测试对、同一 prompt／参考图／随机噪声种子、256×256 和 [-1,1] 范围。
PSNR=`10log10(4/MSE)`。旧版与新版的内部局部指标都使用同一 GT 选择区域。
局部指标也被用于训练，所以不是独立的 LPIPS 或人类感知评测。
FID 仍为 ImageNet-Inception 变体，不与外部论文 canonical FID 直接比较。

局部对照是同一批整图预览的相同坐标 96×96 区域、nearest 放大三倍，没有锐化；
图片来自 JPEG 预览，存在压缩误差。展示六个预先固定的物体／联合编辑例子，不按结果好坏挑图。
不要仅凭数字改善就认定细节已经恢复。

| 指标 | 上轮 9.96M | 本轮局部训练 9.96M |
| --- | ---: | ---: |
| MSE ↓ | 0.002773 | 0.002639 |
| PSNR dB ↑ | 31.591 | 31.806 |
| 边缘 L1 ↓ | 0.073672 | 0.072843 |

MSE 降约 4.8%、边缘误差降约 1.1%、内部局部指标降约 1.9%。
KID 波动区间重叠，不声称具有显著性。数字有小幅改善，但固定放大对照里台灯底座纹理、
靠垫褶皱仍没有明显恢复，细节目标尚未充分达到。不能将指标改善解释为高频纹理已经学会。
这轮没有增加推理参数、修改任务或覆盖旧版，记录如实保留。
