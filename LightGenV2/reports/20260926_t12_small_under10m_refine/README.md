## 结构变化

从上一轮 11.14M 蒸馏＋GAN 小版继续，按权重范数乘积排序，对两个 SwiGLU MLP 做结构化
神经元剪枝：gate/up 512→1024 改为 512→640，down 1024→512 改为 640→512。
三组投影使用相同的保留索引，保留神经元的权重原值不变。不是随机重建文字头。

- 两个 Transformer block、512 隐藏维度、8 个注意力头、160 维图像条件保持。
- Qwen tokenizer、词表、冻结 token embedding 保持。embedding 按原约定单列、不计入预算。
- CNN 编码器/解码器、已有 source gate、语言及图像光路、并行电子残差都保持。
- 总参数从 11,137,746 降到 **9,958,098**，减少 1,179,648（约 10.6%）。
- 两侧纯相位参数仍为 958,728，物理 mask/传播尺寸没有缩小。alpha 下限仍为 0.4。
- 输入输出均 256×256，没有追加超分辨率或后处理锐化网络。

## 继续训练方法

继续 2000 步，batch=2，lr=3e-5，从上一轮权重剪枝后恢复；不是从头训练。
保留原 MSE、0.1×L1、0.1×边缘 L1、0.05×训练期 ResNet18 感知损失、
0.1×可靠区域的大版图像蒸馏、0.02×旧文字头特征蒸馏。
保留训练期 PatchGAN，生成器对抗权重 0.003，前 200 步渐增。

针对残影恢复两项已有训练思路：

1. source gate 的软保留监督，权重 0.01。训练时由 GT 与参考图的局部像素差产生连续保留目标，
   鼓励变化区域少沿用原图。不是 GT 掩码推理、硬贴图或保证逐像素一致的规则。
2. 修改区域额外 L1，权重 0.15，避免大面积背景在整体误差里稀释物体修改的监督。

不声称 source gate 是所有模糊的唯一成因；本轮同时剪枝和修改训练损失，没有逐项消融。
老师、感知网络、判别器全部只用于训练，不进入推理模型。
光路继续采用理想 DC20 仿真，不施加随机硬件扰动；物理传播和相位梯度保留。

## 评测口径

与前两版比较使用完全相同的 2304 个测试对、输入 prompt、256×256 输出及像素范围。
验证检查点由固定 144 个验证对选取，不根据测试集挑选训练检查点。
MSE 在 [-1,1] 计算，PSNR=`10log10(4/MSE)`；低 MSE 不保证更清晰。
FID 是现有 ImageNet-Inception 变体，不与外部论文 canonical FID 直接比较。
任务仍为固定目录的受控条件编辑，不声称开放式、多样化生成已经解决。

| 指标 | 上轮 11.14M 蒸馏＋GAN | 首段剪枝候选 | 推荐低学习率恢复版 |
| --- | ---: | ---: | ---: |
| 参数量，冻结 embedding 另计 | 11,137,746 | 9,958,098 | 9,958,098 |
| MSE ↓ | 0.003412 | 0.003698 | 0.002773 |
| PSNR dB ↑ | 30.691 | 30.341 | 31.591 |
| 边缘 L1 ↓ | 0.078730 | 0.079285 | 0.073672 |
| ImageNet-Inception FID 变体 ↓ | 98.723 | 95.114 | 92.330 |
| KID ↓ | 0.024643±0.004427 | 0.020586±0.003673 | 0.020061±0.004585 |

推荐版相较上轮参数少约 10.6%、MSE 降约 18.7%、边缘误差降约 6.4%、PSNR 提高约 0.90dB。
KID 有随机子集波动且区间重叠，不声称其改善已经具有统计显著性。
预览显示视觉提升仍偏细微：目标台灯底座、圆垫褶皱、细桌腿依然偏糊，联合编辑仍有残影。
因此本轮实现了低于 10M 的压缩和测量上的改善，不声称清晰度问题已完全解决。

检查：8 项单元测试通过；最终审计检查每侧实际光学调用、电子与光学同输入并行、
router/global 和 top-2 选中专家相位反向梯度。训练结束后释放所用 GPU。
