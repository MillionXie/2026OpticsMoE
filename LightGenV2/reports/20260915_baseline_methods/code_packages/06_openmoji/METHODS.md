# 06｜语义交互（OpenMoji）

**数据处理。** 使用 OpenMoji 17.0.0 的 16 种彩色图标合成 224×224 场景，图标尺寸为 30×30，位置落在 6×6 网格上，类别包含 16 种图标和空白类。添加、替换操作的源场景包含 1–4 个对象，移动、删除操作包含 2–4 个对象；按对象类别和相对位置生成文字指令，每种操作使用三种指令模板。种子为 73，共生成 5,000 条训练样本和 1,000 条测试样本，四种操作各占四分之一；跨集合及集合内部按“完整源网格＋指令”去重。每个样本保留源图像、指令、源类别网格、目标类别网格和修改位置标签。

**模型处理。** 采用完整冻结的 Qwen3-VL-2B-Instruct，以原生多模态对话格式输入场景图像和编辑指令。读取末层视觉空间合并前的 196×1,024 特征，以及最终语言层中原指令位置的 L×2,048 特征（L≤64），分别经线性投影和 LayerNorm 映射至 192 维。文字特征通过可学习的位置权重汇聚为条件向量，对 14×14 视觉特征施加 FiLM 调制并加入二维坐标，再经过膨胀率为 1、2 的两组条件深度卷积残差模块。网格解码器输出 6×6×17 类别 logits 和 6×6 编辑 logits，另设四操作辅助分类头。适配器及读出共训练 972,952 个参数，其中网格读出为 381,976 个参数。编辑概率不低于 0.5 的网格采用预测类别，其余网格保留输入提供的真实源类别。

**训练与评价。** 缓存冻结主干特征后训练适配器及读出，采用 AdamW，100 轮、batch size 32、学习率 3×10⁻⁴、权重衰减 0.01、种子 73；前 5% 步数线性预热，随后余弦衰减，EMA 系数为 0.995。监督包括类别交叉熵、编辑位置 BCE/Dice、未修改区域保留损失和操作分类损失，权重依次为 1、1、0.2、0.1；类别损失的修改格和前景权重分别为 8、2。第 1 轮、每五轮及末轮用完整测试集选取修改格准确率最高的 EMA 权重，最终选中第 25 轮。修改格准确率先在每个样本真实发生变化的网格上计算，再对 1,000 个样本平均，**Accuracy 为 0.8420**。
