# LightGenV2 仿真到光路的误差建模与正式消融方案

日期：2026-09-26。状态：文献核查与实验设计；尚未实施这些新消融，没有预设结果。

## 1. 明天汇报的核心观点

研究问题不是“加噪声有没有用”一个问题，而是三个问题：

1. 建模是否更准确：仿真能否预测真实 CCD 的统计、光场结构与任务性能？
2. 训练是否更鲁棒：同一真实误差下，误差感知训练是否优于未考虑误差的训练？
3. 改善来自哪里：mask、电子读出、电子残差，还是硬件标定？

这三者必须分开实验。预测误差更小，不自动意味着训练的 mask 更 robust；任务分数高，也不证明 CCD 模型准确。尤其不能只看“仿真和实测的分数差变小”：两者一起变差，也会缩小差距。

## 3. 工程核查：不要把不同 profile 混成一个模型

本报告核查了 LightGenV2 根说明、T06 说明、T02 common_dc20 配置及其共享后端、T06 独立后端与部署配置。

### 3.1 早期共享 DC20 路径

可核查入口：

- `LightGenV2/tasks/t02_keypoint_detection/configs/common_dc20.yaml`
- `experiments/qwen3_vl_embedding_2b_caltech101_four_layer_optical_retrieval_10cm_robust/optical_blocks.py`
- `experiments/qwen3_vl_embedding_2b_grocery10_optical_retrieval/optics/physical.py`

该配置包含：输入/相位/CCD 整数位移各 ±16 逻辑像素；CCD 增益 0.4–2.5；有偏截断 Gaussian；振幅和相位两处相干零级混合，名义系数各 0.20–0.30；phase block dropout；k-space 限制；CCD 均值归一化、裁剪和 log 压缩；phase DC 正则、CCD 均值工作点约束。Router 另有自身的位移、phase dropout 和训练 logit 噪声。

CCD 有偏截断分支实际为：

```text
I = 无 CCD 加性扰动的探测强度
m = mean(I)
g ~ Uniform(0.4, 2.5)，每幅图一个值
epsilon = Gaussian(mu=0.03, sigma=0.03) 的截断采样
          保留范围 [-0.03, 0.12]，逐像素采样
Y = max(g * I + m * epsilon, 0)
```

这是相对强度扰动，不是已标定的 Poisson-Gaussian 相机模型。mu/sigma 是截断前参数；截断后均值/标准差会变化。此分支不再额外叠加配置中的 offset_fraction/read_noise_fraction；后两项属于另一个分支，不能重复计算。

共享路径中的随机 CCD、位移及零级混合在普通 eval 下关闭。因此，正式误差测试需要独立 evaluator；不能把 model.train() 当作误差评估开关，否则同时启用了其他训练行为。

### 3.2 T06 不是同一套实现

`spatial_single_video4_two_branch_ema_q8.yaml` 写明：256 级相位量化、k-space 开启、theta=1°、零级名义系数训练 0.20–0.35、eval=0.20，但三类位移为 0。

其后端 `experiments/qwen3_vl_2b_lgvq_single_metric_o2_16frame_54/modeling.py` 的相位调制是：

```text
M = sqrt(1-eta) * exp(i*phase) + sqrt(eta)
```

这里不是早期共享路径的“输入振幅和相位两处混合 + 随机相对相位”。不能把早期 CCD 噪声参数直接当作 T06 已生效的参数。不同任务的归一化也需按最终 resolved config 核查。

因此，正式实验必须固定：task/profile、实际展开配置、模型实现、初始化 SHA、数据名单、物理合同。不能拿两个历史 best checkpoint 的差当正式消融。

推荐：先在一项能可靠采集 CCD 的任务完成主矩阵；优先考虑已有实测流程的 T03，再在 T06 Spatial 做关键组迁移验证。选定前需冻结具体 profile，本方案不擅自改变当前正式配置。

## 4. “直流分量”和“pixel 扰动”需要拆开

### 4.1 三种直流/背景不是同一个东西

| 类型 | 注入位置/形式 | 对应实验 |
| --- | --- | --- |
| 相干零级泄漏 | 复光场中的未调制场，进入传播并干涉 | 振幅路径、相位路径分开；固定 eta 与随机 eta；固定与变化相对相位 |
| 相机背景/黑电平 | 探测后的加性偏置 b，可能随位置变化 | 背景扣除；固定图样；背景随机化 |
| mask 自身 DC 成分 | 理想 mask 的空间平均复透射率 | phase DC 正则开/关及权重扫描 |

相干泄漏的示意模型：

```text
E_effective = sqrt(1-eta) * E_signal
              + sqrt(eta) * E_leak * exp(i*theta)
I = abs(Propagate(E_effective))^2
```

必须先加复振幅、再平方；不能用“CCD 强度加一个常数”替代相干干涉。eta 是名义混合系数，有交叉干涉项，不等于 CCD 实测光功率中恰好 eta 的占比。E_leak 的形状也应实测约束，不一定是全场均匀常数。

现有 phase DC 正则为每个物理相位平面分别计算 `abs(mean(exp(i*phase)))^2` 再平均。它不直接等于输入加权后的实际泄漏功率，更不等于相机背景。

### 4.2 pixel 至少包含六类不同问题

1. 输入振幅图相对光学坐标的平移。
2. 相位 mask 相对输入的平移。
3. CCD 平面/ROI 的平移。
4. phase block dropout：局部相位变为零、光仍通过，不是挡光。
5. 相位值误差：LUT 非线性、量化、相位偏差、空间相关响应误差。
6. CCD 像素响应误差：坏点、PRNU、DSNU、像素面积积分与采样缩放。

前三项还要区分整数平移与亚像素平移；旋转、缩放、轴向距离误差是其他独立因素。固定制造误差应在同一虚拟设备中保持固定，时间抖动才逐帧变化。

## 5. 正式消融主矩阵：先回答“各项训练措施有无贡献”

定义 F：选定同一架构和训练协议后，启用拟检验的完整误差感知训练方案。F 是将要建立的实验基线，不声称现有每个部署 profile 都已启用这些项。

所有组重新训练；同一 seed 使用同一初始权重、数据顺序和训练步数。消融只改训练侧的一项，测试物理条件保持一致。与架构无关的普通正则不在本表擅自关闭。

| ID | 训练组 | 相对 F 唯一变化 | 回答的问题 |
| --- | --- | --- | --- |
| A00 | 完整误差感知 F | 无 | 共同参照 |
| A01 | 无误差感知训练 | 一次移除被研究的训练误差建模/随机化，保留架构 | 整套方案的总收益；这是组合对照，不是单项消融 |
| A02 | 无 CCD 加性噪声 | 取消相对加性扰动；保留增益 | CCD 加性建模收益 |
| A03 | 无增益随机化 | 固定 g=1 | 曝光/亮度随机化收益 |
| A04 | 无振幅零级建模 | 振幅路径 eta=0 | 输入端未调制光建模收益；仅适用于该后端支持的路径 |
| A05 | 无相位零级建模 | 相位路径 eta=0 | 相位端泄漏建模收益 |
| A06 | 无输入位移训练 | 输入 shift=0 | 输入对准容差 |
| A07 | 无 mask 位移训练 | phase shift=0 | mask 对准容差 |
| A08 | 无 CCD 位移训练 | CCD shift=0 | 探测平面/ROI 容差 |
| A09 | 无 phase block dropout | dropout=0 | 局部相位失效容差 |
| A10 | 无 phase DC 正则 | 仅其 loss 权重=0 | mask DC 抑制的额外贡献 |
| A11 | 无 CCD 工作点约束 | 仅其 loss 权重=0 | 平均强度约束的贡献 |

核心为 12 个条件。第一阶段每组 3 个 seed，共 36 个训练 run；重要结论资源允许时补到 5 个。单 seed 结果只能算筛选。若所选后端没有某项，不列一个实际无变化的“消融”，应标“不适用/待实现”。

A04/A05 若用于 T06，应合并为它实际实现的单一相位零级混合项，不能伪造其不存在的振幅泄漏路径。Router 和特征光路的同名扰动需要清楚声明作用范围：主表建议同类几何扰动在两者同步关闭，后续再拆位置消融。

注意：取消“训练随机化”与取消“名义硬件模型”不同。对量化、有限孔径、固定泄漏等问题，要将训练假设和统一测试装置分开配置；不应把真实硬件特性从所有组的测试中删除。

## 6. CCD 模型专项：把“拟合更准”和“训练更 robust”分别测

### 6.1 候选模型

| 模型 | 内容 | 用途 |
| --- | --- | --- |
| C0 | 无 CCD 随机噪声 | 干净训练参照，可共享 A02 对应条件 |
| C1 | 现有有偏截断 Gaussian | 复现当前经验模型 |
| C2 | 标定背景 + 零均值 Gaussian，先不加 shot noise | 检验把背景与随机噪声拆开是否有帮助 |
| C3 | 标定 Poisson-Gaussian | 检验信号相关 shot noise 的收益 |
| C4 | C3 + 固定 PRNU/DSNU + 实测空间/行列相关项 | 只在实测支持这些结构时增加 |

C1–C4 应使用相同标定数据预算。新增模型复杂度必须通过留出 CCD 数据检验，不能只看拟合集更好。

建议物理链：

```text
I[p] = 光学传播后的理想强度
lambda[p] = exposure * optical_scale * response[p] * I[p]
N[p] ~ Poisson(lambda[p] + dark_rate[p] * exposure)
raw[p] = ADU_per_electron * N[p] + bias[p] + read_noise[p]
Y[p] = ADC_quantize(sensor_clip(raw[p]))
网络输入 = 与真实部署完全一致的背景处理、裁剪及归一化(Y)
```

单位必须明确：lambda/N 是电子计数；bias/read_noise 若写在 raw 中则用 ADU；response 是相对响应。若读出噪声用电子单位建模，需先与 N 相加、再转 ADU。饱和包括满阱与 ADC 量程；不能仅把负值裁零就称“建模了相机饱和”。

Poisson 项训练需要适当梯度估计或高计数近似，不能直接采样后让强度梯度无意中断；实现时先做梯度与数值单测，低光测试仍用 Poisson。

### 6.2 先做相机标定，不立即扩大训练

以下是建议起点，不是已测参数：

- 暗场：3 个工作曝光，每个 50 帧，检查黑电平、时间噪声、暗电流、行列结构。
- 稳定平场：6–8 个不饱和光强，每档 30 帧，拟合均值–方差，估计转换增益和响应非均匀性。
- 图样：选 50 个固定输入/mask 组合，各重复 10 帧，区分时间噪声与系统性光场不匹配。
- 另一天重复部分采集，留作建模验证；激光散斑或照明不均不能直接当成 CCD PRNU，需光源监控或多平场位置/方法分离。

由这些数据确定各项是否需要进入 C4，不能默认所有误差都是独立白噪声。光学仿真残差也不能全部塞到 CCD Gaussian 中。

建模评价：暗场/平场均值、时间方差、均值–方差曲线、残差偏置与分位数、空间相关、饱和比例、跨日预测误差。光场结构评价另报告配准后 PCC/SSIM、能量分布与强度比例；配准只能由独立标定确定，不逐张优化到最好。

鲁棒训练评价：使用 C0–C4 分别训练，在相同真实 CCD 测试和同一独立标定的误差测试中比较任务分数。不要各自在自己的生成噪声上测试然后互相比较。

## 7. 必须补充的机理对照

### 7.1 零级固定模型 vs 随机鲁棒训练

用相同架构做三组：训练忽略泄漏、训练固定标定 eta、训练在标定区间随机 eta；统一在实际非零泄漏装置测试。再比较固定/随机相对相位。这样能区分“名义物理模型更准确”和“随机化扩大容差”。

### 7.2 robust mask 与电子鲁棒性分离

完整联合训练只能证明系统鲁棒，不能单独归功于 mask。

从同一个干净预训练 checkpoint 出发，相同预算做四组：不继续训练、仅更新 mask、仅更新电子部分、联合更新。均在相同误差下测试；仅 mask 组冻结电子参数，关闭电子训练行为，并验证冻结参数哈希。仅电子组固定光学参数。

这解释的是“在该起点下，哪个模块的更新产生改善”，不替代从共同初始化开始的主消融。补充无电子读出的光学指标：有效探测区能量占比、能量集中度、固定扰动前后特征变化量与重复拍摄稳定性。不能只用 mask 看起来更平滑作为证据。

### 7.3 仿真鲁棒训练与实测电子适配的 2×2

| | 不做实测电子适配 | 做实测电子适配 |
| --- | --- | --- |
| 不做误差感知训练 | H00 | H01 |
| 做误差感知训练 | H10 | H11 |

适配冻结全部 mask 和前置模块，只更新预先指定的原有读出头；从原 train 划出固定适配样本，分别测 1%、5%、10%、20% 的样本效率。适配选模不得用最终 test。这里是借鉴 ACCEL 的适配思路，不把我们的数字电子残差/读出说成它的全模拟 EAC。

### 7.4 电子残差与归一化另作补充表

- 电子残差：有/无残差 × 有/无误差感知训练，控制训练预算并报告参数量；不能在主消融中同时改变架构。
- 归一化：均值归一化、均值+clip/log、固定标定尺度；要分别训练，不能只换测试预处理。
- 无加性噪声、无饱和时，`g*I / mean(g*I) = I / mean(I)`，全局增益会被均值归一化消去。因此增益消融的作用应结合 SNR、偏置、饱和和归一化分析，不能预设它必然提升。
- Router：只扰动 router、只扰动特征路径、两者都扰动；记录 Top-2 选择变化、分数间隔和任务性能，识别是否路由翻转放大误差。

## 8. 统一测试：曲线比一个分数更重要

全部 checkpoint 固定、eval 模式，误差由 evaluator 显式注入。测试不更新权重；各组使用相同误差样本与随机 seed，至少 10 个误差实现，分别统计训练 seed 与测试误差的不确定性。

每个模型测试四类环境：名义条件、逐项误差扫描、复合误差、真实硬件跨会话。名义条件包含已确认的固定硬件特性，不等于假设硬件完美。

| 误差 | 初步仿真扫描建议 | 单位与注意事项 |
| --- | --- | --- |
| CCD 加性噪声 | 标定量级的 0、0.5、1、2、4 倍 | 相对 Gaussian 专项可另测 sigma=0、0.01、0.03、0.06、0.10；两种口径不混用 |
| 光强/曝光 | 标定工作点的 0.25、0.5、1、2 倍 | 保持真实 sensor 噪声链；不是只把归一化前图整体乘系数 |
| 零级 eta | 0、0.10、0.20、0.30、0.40 | 名义混合系数；真实范围靠标定 |
| 输入/mask/CCD 位移 | 0、±1、±2、±4、±8、±16 | 先测单轴，再测斜向；这里是逻辑网格像素 |
| 亚像素位移 | 0.25、0.5、0.75 像素 | 必须用正确采样/插值，并区分复场与强度所在平面 |
| 旋转 | ±0.25°、±0.5°、±1°、±2° | 仅仿真筛选；实测须确认安全标定范围 |
| 相位误差 | std=0、0.02π、0.05π、0.10π、0.20π | 独立像素 vs 空间相关；固定设备误差 vs 逐帧抖动 |
| phase dropout | p=0、0.02、0.05、0.10、0.20 | 同时记录 block 尺寸；不能与 CCD 坏点混同 |
| 轴向距离 | 10 cm ±0.5/1/2/5 mm | 先仿真；实际移动要建新标定会话 |

以上扫描值是待筛选的设计，不是已证明真实装置的误差范围。逻辑采样 pitch=17 μm 不等于 CCD 原生 pixel pitch；需根据放大率、binning、ROI 重采样换算成实测单位。

复合误差先做两对：CCD 噪声×零级泄漏；位移×phase dropout。用一个不随消融组变化的联合测试集。必要时做这些训练因素的 2×2 对照，不能把 leave-one-out 差值相加当总贡献。

固定设备误差在一次虚拟 session 内保持固定；帧级噪声逐帧采样；曝光与漂移等 session 参数整批共享。空间相关误差不要一律按 iid pixel 采样。多层复合误差应报告逐层注入位置与相关性。

## 9. 还容易遗漏什么：按优先级补，不一次全铺开

| 优先级 | 因素 | 处理建议 |
| --- | --- | --- |
| P0 | CCD 偏置/时间噪声/shot noise、相干零级、三类位移、phase dropout、DC/工作点约束 | 主矩阵与 CCD 专项 |
| P1 | phase LUT/量化、有限孔径与 k-space、亚像素/旋转/缩放、轴向误差、PRNU/DSNU/坏点、饱和/ADC 量化 | 先标定或敏感性筛选，有明显影响再做训练消融 |
| P1 | 路由敏感性、电子残差掩盖光学误差、跨日漂移 | 机理补充与跨会话实测 |
| P2 | 光源波前/像差、振幅 SLM 非线性/填充因子、SLM 像素串扰、偏振/相干性、时间稳定延迟、杂散光 | 只有独立测量支持才增添模型 |
| 特定任务 | 多槽位相干串扰、视频换位、批次组成、padding 有效位 | 多视频/多样本并行时按完整光场测试；不能独立传播后无损拼接 |

k-space 是物理带宽假设，不是普通噪声。比较“训练假设不限带宽”和“训练使用标定孔径”，但测试始终使用同一真实孔径。相位量化同理：continuous-training vs quantization-aware-training，测试统一导出为实际设备量化/LUT。

## 10. 正式统计与硬件采集协议

1. 在原训练集中固定划 validation。视频按源视频/场景分组，避免相邻帧泄漏。所有组共享名单；原 test 保持不参与反传、超参数和选模。
2. 工程历史协议存在 test 选 best；这些历史分数仅作背景，不称未触碰测试。已经被反复选模/适配使用的样本不能通过重新命名变成独立最终 test；如无新测试数据，明确声明这一局限。
3. 同 seed 配对比较，保存每个样本预测；报告 mean±std、配对差与 bootstrap 95% CI。视频按视频单位重采样；不要把同一视频的帧当独立样本。
4. 同初始化、相同步数/学习率策略、同选模频率，分别记录计算成本。关闭某项随机采样不能无意改变其他随机项：训练数据、dropout、光学误差最好分离 RNG。
5. 所有组报告名义性能、统一扰动性能、真实硬件性能。任务指标为 T03 CC/NSS/SIM，或 T06 SRCC/PLCC/RMSE；不跨任务比较绝对分数。
6. 画性能–误差曲线、训练范围×测试范围热图；曲线 AUC 必须声明范围和权重。报告最坏预定义条件或低分位数，不能事后只展示有利区间。
7. 真实硬件至少 3 个独立会话/时段，组间采集顺序随机或交错，穿插固定参考图样；记录激光功率、曝光、增益、LUT、ROI、朝向、等待时间、环境和相位验证。日内多拍不是跨日独立会话。
8. mask 或前置输入编码改变后必须重新实采对应光场；旧 CCD 缓存不能代替新 mask 的部署。只有光学及全部前置模块固定、仅下游读出变化时，才可共用实测缓存。
9. 硬件主表所有组先不适配。适配结果另表，不能某组已适配另一组未适配。改变曝光/LUT/ROI 等建立新 session 身份，不覆盖旧采集。
10. 每个 run 保存 commit、展开配置、初始化与最终权重 SHA、数据 manifest、采集 session、全部预测与指标。记录真实增益/SNR，不能只有训练配置里的随机区间。

推荐结果表字段：

```text
组ID | seed | profile | 名义仿真分数 | 统一扰动分数
     | 未适配硬件分数 | 适配硬件分数(另表)
     | 名义仿真-硬件差 | 低光曲线AUC | 几何容差
     | CCD统计预测误差 | 采集会话 | 是否独立test
```

## 11. 实施顺序与预算

第一步，不新增正式训练：冻结 profile，确认 eval 注入器；做暗场/平场/重复图样标定和现有 checkpoint 敏感性测试。这一步回答“装置主要误差是什么”。

第二步，跑主矩阵 12 条件×3 seed。先用仿真筛选，但不把筛选结果当硬件因果证据。

第三步，CCD 模型专项 C1–C4×3 seed；C1 可与主表共享完整条件，C0 可共享相应无 CCD 组，前提是其他设置完全相同。优先比较现有模型和标定 Poisson-Gaussian，C4 需标定证据。

第四步，硬件验证 F、无误差感知、无 CCD、无零级、无几何随机化、标定 CCD 模型等关键条件，保留跨 seed 和跨 session 信息。小子集是 pilot，正式结论要预定义有足够统计功效的测试样本量。

第五步，实测适配 2×2 与 mask/电子更新分离实验；最后选第二任务验证关键结论，避免全部任务一开始全面重训。

全部训练遵守工程预算：默认单 GPU 串行排队。本报告不启动训练、不改模型、不改硬件参数。
