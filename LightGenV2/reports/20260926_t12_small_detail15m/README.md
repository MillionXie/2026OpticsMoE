# 15M 内的 decoder 扩容候选

本轮只改变小版图像 decoder 容量，任务、数据、文字头和光路保留；旧权重不覆盖。
从上一轮 9.96M 局部细节权重继续训练，不从头训练。

## 参数用在什么地方

新总量 **14,718,450**，增加 **4,760,352** 参数；冻结 Qwen token embedding 按原约定另计。
文字部分仍是两层 512 宽度、8 个注意力头、640 中间宽度的 Qwen-style Transformer。
CNN stem/down、图像光电瓶颈、最后 up1 与 RGB 读出头保持。

原图像路径为 stem(256²,48) → down1(128²,96) → down2(64²,160)
→ down3(32²,224) → 光电瓶颈 → up3(64²,160) → up2(128²,96)
→ up1(256²,48) → 已有 RGB delta/source gate 输出。

本轮在 up3 后新增 5 个条件残差模块，在 up2 后新增 2 个：

| 位置 | 模块数 | 每个模块 |
| --- | ---: | --- |
| 64×64、160 通道 | 5 | 3×3 Conv 160→256；16组 GroupNorm；文字条件 160→512 产生 scale/shift；SiLU；3×3 Conv 256→160；0.1×输出加回输入 |
| 128×128、96 通道 | 2 | 3×3 Conv 96→160；16组 GroupNorm；文字条件 160→320 产生 scale/shift；SiLU；3×3 Conv 160→96；0.1×输出加回输入 |

每个末端卷积零初始化，初始扩容输出与原版完全一致。随后学习特征层修正。
这是新增电子 decoder，不是新增光学 block；不将新增参数声称为光学参数。
没有 RGB 后处理锐化、超分辨率、模板贴图、GT 推理或迭代生成。
语言／图像光路纯相位仍为 958,728，物理尺寸不缩小，光电并行关系不变。
alpha 指现有瓶颈融合系数，不代表整个扩容网络的光学计算占比。

## 训练

batch=2，1800步，每450步验证固定144个验证对。
旧权重 lr=1e-5，新 decoder 模块 lr=5e-5。同时训练，不重新初始化旧网络。
保留上一轮 MSE/L1、整图感知、局部可靠老师蒸馏、修改区域、source gate、文字蒸馏。
局部细节权重 0.06（上轮0.04）；轻量对抗权重仍0.001，不提升GAN强度。
老师、判别器和感知网络只用于训练。
仍为理想 DC20 仿真恢复训练，没有硬件随机扰动，物理传播及相位梯度保留。

按验证集的 MSE＋加权整图感知／边缘＋加权局部细节选择检查点，不根据test选训练步骤。
局部权重不同，不能把新旧训练的验证综合分数直接横比。

## 使用与公平评测

新 PT 同时记录 `text_mlp_indices` 和 `decoder_refinement=true`。
必须使用更新后的 `audited_unified_run`，从旧 source 构建后自动恢复剪枝及扩容结构，
再严格加载新权重。推理时不要再次加 `--expand-decoder`。
仍需旧 source 配置和冻结共享 embedding，权重不是无依赖部署包。
服务器：`/DATA/DATA1/guest3/t12_assets/runs/abo_audited_v2_small_14p72m_decoder_detail1800/adapted_model.pt`。

同一2304个test对、prompt、参考图、噪声种子，输入输出均256×256。
MSE在[-1,1]计算，PSNR=10log10(4/MSE)。内部局部细节指标也用于训练，不是独立LPIPS。
FID为ImageNet-Inception变体，不与外部论文canonical FID直接比较。
局部图是相同96×96区域nearest放大三倍，无锐化，来自JPEG预览。
固定展示六组物体／联合编辑例子，不按美观挑图。

## 本轮结果

1800步结束，验证最优为第1800步。验证MSE从0.002481降到0.002357。

| 指标 | 上轮局部训练9.96M | 扩容14.72M |
| --- | ---: | ---: |
| MSE ↓ | 0.002639 | 0.002472 |
| PSNR dB ↑ | 31.806 | 32.090 |
| 边缘L1 ↓ | 0.072843 | 0.070803 |
| 内部局部细节指标 ↓ | 0.141863 | 0.136759 |
| ImageNet-Inception FID变体 ↓ | 88.580 | 82.761 |
| KID ↓ | 0.018533±0.003274 | 0.017800±0.002436 |

MSE降约6.3%，边缘误差降约2.8%，内部局部指标降约3.6%。
KID波动区间重叠，不声称显著性。固定放大图中仍缺少灯座高频纹理和靠垫完整褶皱；
总体改善偏小，未达到明显清晰度跃升。新增参数约47.8%，不能仅凭小幅误差下降断言性价比更好。
本轮也包含额外训练及局部损失权重变化，没有等步数9.96M消融，不能把全部收益归因于扩容。

11项单元测试通过；最终审计检查光学实际调用、同输入并行、router/global/选中专家相位梯度，
并记录7个新增模块末端卷积的非零权重，确认不只是保存零初始化的扩容壳。
旧9.96M权重保留，所用一张GPU在评测和审计完成后释放。
