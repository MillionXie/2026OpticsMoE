# EuroSAT 光学/SAR 追加实验

用户已明确要求追加本数据集实验，沿用已完成 CORe50 的实验步骤。A 为 Sentinel-2 光学 RGB，B 为 Sentinel-1 SAR VV/VH；两者共用十个地物类别。原始数据及使用许可来自作者发布页，证据保存在 DATA_LICENSES.json 和 licenses/。

模型：391 个依赖源文件逐字节复用 CORe50 的已验证版本。MoE 有四个224×224专家（E0/E1 为 A 组，E2/E3 为 B 组），478×478有效孔径、518×518传播网格、60×60探测窗口、两个光电混合模块。D2NN 使用两个全局478×478相位层，电子支路、十分类头、冻结输入骨干与 MoE 一致。可训练参数 MoE1,186,804 / D2NN1,164,408，冻结骨干各3,933,184。所有模型从 seed42 的新初始化开始，不加载 CORe50 训练权重。

流程和超参数维持原方案：共享40轮→A专家15轮、B专家15轮（各自从同一共享检查点开始）→精确合并→路由15轮；D2NN A-only和B-only各70轮，D2NN AB走相同40AB/15A/15B/15AB采样课程。批量60，AdamW、学习率、余弦日程、前4轮相位冻结、标签平滑、KD、域KL和capture权重保持原值。共享及路由阶段每轮250步；本次两域为等量配对数据，A/B单域阶段均每轮125步。这是针对新数据对称性的预算适配：MoE与D2NN AB各17,500步、A/B各525,000次呈现；单域基线各8,750步。原CORe50不对称B域25步/轮没有沿用。

数据：光学官方RGB JPEG；原始多光谱GeoTIFF仅用于核验位置与范围。SAR按作者VV/VH顺序与固定均值/标准差缩放，逐图1%/99%分位裁剪，三通道为VV、VH及两者均值。两域统一采用原图中心56×56共同地理区域，SAR对齐到该网格，再采用与旧实验一致的224×224双三次处理、水平翻转与ColorJitter。无按模型分开的输入编码，也不从验证或测试集合拟合缩放参数。

划分：50km地理块为分组基础；中心距离3km内的地块及重复像素样本合并到同组。使用seed42分层分组五折，fold0测试、fold1验证、其余训练，光学/SAR同地点绑定在同一分区。实际样本数、类别数、最近跨分区距离、结构无效数据排除记录在SPLIT_AUDIT.json，训练前封存。仅根据数据完整性排除缺失覆盖、恒定双极化或标签冲突的样本，绝不依据模型性能挑样本。

验证：数据压缩包作者MD5/SHA256、逐成员CRC、图像SHA256与重复检查；真实GPU预检确认电子初始化、参数数量、相位梯度、冻结状态、功率归一化与batch60更新。预检更新丢弃；正式训练重新加载保存的初始参数。MoE/D2NN AB逐轮核验实际样本、标签、增强种子哈希和呈现次数。

评估：全部模型检查点先封存，再分别测试A/B。同一个A-only检查点和同一个B-only检查点都输出双域准确率、Macro-F1、混淆矩阵。正常MoE推断不提供域标签；均匀路由、已知域隔离及恢复专家初始相位是预先规定的诊断。最终下载代码、日志、逐样本预测、检查点哈希与图表，本地独立复算。单seed结果，无按测试集调参；光学参数量、损失和教师计算量差异如实报告。

入口 run_eurosat.py，独占队列锁，依次运行四模型。所有新数据、代码与结果均位于独立EuroSAT目录。完成后由本任务的EuroSAT跟进交付结果，既有CORe50/CIFAR/OfficeHome实验保留。

封存前实测：保留26,892对、共53,784张图像。A、B各训练15,998 / 验证5,465 / 测试5,429，三个分区均含全部10类。552个地理组；最近跨分区中心距离3,023.219米，独立空间哈希算法检查99,645对近邻后确认均未跨分区。391个架构依赖文件与CORe50逐字节一致。
