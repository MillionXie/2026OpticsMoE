# BloodMNIST：多种子与输入孔径对照协议

本轮在读取新增训练的测试成绩前固定。原seed17测试已在上一轮看过，因此这不是全新隐藏测试集；新增对照来自第一层照明几何问题，不按测试优势选配置。原结果保留，不能被上采样对照静默覆盖。

## 对照及预算

- seed17、27、37；主干2、4、6层；MoE、原D2NN、上采样D2NN，共27份选定权重。
- 原seed17的6份光学权重从`bloodmnist_dedup_s17_20260916`复用并核验源文件、数据、权重哈希，新增21次训练。各配置固定30轮上限及同一验证选模规则，不按MoE领先程度选择随机种子。
- 用户明确允许同时使用两张空闲GPU，使用GPU0和GPU1，各卡同一时刻一个训练进程。优先排长作业仅依据架构与深度，不读取指标决定排程。
- 数据、增强、AdamW、标签平滑、捕获率约束、相位平滑、EMA、早停和验证选模完全沿用`bloodmnist_profile.json`，不新增超参数搜索。旧profile中的seed17说明是其初始适用范围，实际本轮种子和架构以suite及每个job的metadata为准。

## 输入覆盖修正

共同的信息源是28×28 RGB，按旧协议得到100×100振幅拼图`[R,G;B,RGB均值]`，所有训练增强在原RGB上完成。原D2NN将它置于500×500计算面中央，第一层相位边长在2/4/6层配置下分别为474/472/470。第一层之前没有传播，所以仅10000个相位像素被直接照明，覆盖率约4.45%/4.49%/4.53%。外围相位可因平滑正则改变，但不因此获得第一层分类梯度。

上采样D2NN把四个50×50块分别双线性抗混叠插值到237/236/235边长，再拼成474/472/470振幅，避免在不同颜色块的边界互相混色。随后逐样本乘以`sqrt(sum(A100²)/sum(Awide²))`，保持与原输入相同的总入射光功率。它只是固定光学输入缩放，不增加可学习电子参数或新的图像信息。相位面、传播距离、波长、OEO、探测窗口、参数量和初始化全部不变。同种子、同深度的两种D2NN初始相位逐位一致。

MoE仍将100×100图像复制至9个146×146专家的中央，入口振幅按路由概率L2归一化，总主路输入光功率保持不变。首个专家相位的直接照明比例约46.91%，并非100%。因此原先“输入大小相同、总参数接近”不足以证明有效自由度公平；上采样D2NN是必要的更强覆盖对照，也改变了输入空间尺度，不能将全部性能差异归因于有效像素数这一个因素。

仍保留理想无损九端口假设；没有证明器件面积、光路数量、系统总功率或运行时间相等。MoE的2/4/6层指主干专家相位和全局相位的数量，另有一个100×100路由相位，不包含在主干深度标签中，但包含在总参数量中。

## 检查和评估

正式训练前检查三架构×三深度的前向、分类反向、两种D2NN相同初始化、上采样功率守恒及每个PhaseLayer的照明与分类梯度。

所有新训练完成后记录不可变选模清单。先精确重放全部27份选定权重的验证指标，再评估官方测试3421张及原协议去重测试3415张；不按测试成绩重新选轮数。原seed17复评还应与其先前测试逐样本一致。

每个相位层保存验证集平均入射光强图、两个类别平衡训练批次的纯分类梯度图和参数变化比例。分别报告严格非零覆盖率及高于本图最大值10⁻⁶的覆盖率；后者只是透明的数值阈值，不等于物理噪声下有效自由度。代表批次梯度不能替代全训练轨迹的逐像素证明。重点区分无照明、分类梯度、正则更新与相位饱和。

主指标为准确率；另报平均类别召回率、宏F1及宏平均一对其余AUROC。跨种子均值、样本标准差、每个原始点和中位数一起展示。只有3个种子，不用平滑小提琴密度暗示可靠分布形状；采用与参考图配色和标记相近的散点、均值菱形、中位线及标准差。

真实图片示例按固定样本索引展示每类训练图片；测试预测示例同时包含按预定规则选择的正确与错误样本，明确选择规则，不只展示成功案例。保存图片ID、标签、预测和数据来源。所有图导出PNG、PDF、SVG；论文用图的原始数值另存CSV。

## 命令

```bash
CUDA_VISIBLE_DEVICES=0 python LightGenV2/demo_check/reproduction/bloodmnist_multiseed.py --phase smoke --data /path/to/bloodmnist.npz --out LightGenV2/demo_check/runs/smoke/<id>
python -u LightGenV2/demo_check/reproduction/bloodmnist_multiseed.py --phase suite --data /path/to/bloodmnist.npz --out LightGenV2/demo_check/runs/simulation/<id> --reuse LightGenV2/demo_check/runs/simulation/bloodmnist_dedup_s17_20260916 --gpus 0 1
```

suite协调器自身不分配GPU，各worker通过CUDA_VISIBLE_DEVICES固定到授权GPU。训练或校验失败时保留run与错误日志，不自动降低检查标准或删除结果。
