# 两小时 Adrenal 泛化优化协议

目标：降低过拟合，确保MoE的路由和各层相位训练有效，在2/4/6层与D2NN公平比较。预算从2026-09-16 11:34 UTC开始，默认GPU0单卡。当前固定Softsign OEO，仅开发训练/验证部分，不改变原官方1188/98/298划分及标签。理想九端口的物理可实现性不在本轮修订，保留原限制。

首轮两个配对配置：分类主损失＋EMA的原像素相位，及相同训练下的二倍间距相位控制网格。每个配置均训练两架构全部三个深度，seed17，最多50轮，相同增强和批次顺序。每个深度两种结构可训练参数量仍近似匹配，粗网格对两者同时减少约75%参数；光学孔径、传播与探测位置不变。

总损失为类别平衡NLL（标签平滑0.05）＋0.05×原光斑MSE＋0.05×圆周相位平滑。类别权重只由训练标签计算；batch16，Adam lr0.002，余弦降至0.0002，梯度裁剪1。每次更新后指数平均参数，decay0.95；推理仅使用一份平均相位，不做多模型集成。每个epoch记录验证，每5轮记录不增强的完整训练集指标；每轮第一批记录所有相位梯度，训练后记录相对初始化的参数变化。

统一按验证集类别平衡NLL选择EMA权重，改善阈值0.0005；最少25轮，连续12轮未改善则早停。验证AUROC、召回率及训练/验证差距同时报告；不按MoE−D2NN差距或测试成绩选模，不要求层数趋势单调。不同模型可能提前停止，实际训练轮数如实记录。

首轮只读取训练/验证。追加方案和种子取决于剩余预算，必须保留全部配置结果；统一配置比较之外，也需报告相同搜索预算中D2NN的较强验证候选，不能故意采用较弱baseline。之后若引入轻量电子前处理，须在两架构之间共享同一份冻结参数及相同编码，并与无前端配置分开报告。

最终选定候选、阈值和SHA256封存后才允许独立测试命令；官方测试在之前的任务中已查看，因此本轮是回顾性开发，不称为新的盲测。单种子/98例验证结果不作稳定显著优势结论。历史实验及所有失败候选保留。

入口：`adrenal_generalization.py`；配置：`adrenal_nll_native.json`、`adrenal_nll_coarse.json`；独立CPU审计和曲线：`verify_adrenal_generalization.py`。

追加共享轻量前端方案（在读取测试结果前确定）：`adrenal_shared_frontend.py`。特征部分808参数：28×28输入，5×5卷积1→8、GroupNorm(2组)、ReLU、2倍平均池化；再3×3卷积8→8、GroupNorm、ReLU、2倍平均池化，输出8×7×7。预训练时临时使用Dropout(0.35)＋392→2线性头（786参数），AdamW lr0.003、weight decay0.01、batch64、最多60轮、最少20轮、patience12，按验证平衡NLL选前端。类别平衡NLL及0.05标签平滑与光学阶段一致，增强作用在原图上。

光学训练中完全删除分类头的计算，仅使用冻结特征。8张特征图按2行4列拼成14×28，双线性放大至100×100，逐样本除以最大值，作为非负振幅；无额外可训练编码或输出旁路。光学训练先增强原图、后经冻结前端，不对拼接特征图旋转。两架构与三个深度使用同一份前端权重，记录哈希并检查训练前后不变。仍分别运行原像素相位和粗网格相位两个配对配置；与无前端结果分表比较，不能把前端带来的改善单独归因于MoE。

复评入口 `evaluate_adrenal_generalization.py` 需要全局候选锁；先检查每个run的锁和权重SHA256、逐项复现完整验证指标，再读取测试集。测试不参与任何后续配置修改。

根据首轮训练/验证路由诊断，另设 `adrenal_nll_router10.json`：无电子前端，路由softmax温度100→10，其余沿用原像素NLL配置。原温度下，已完成两/四层模型的多数专家概率标准差约0.001–0.002，中央专家在97/98或98/98例中最大；存在训练更新但输入相关分配偏弱。降低温度只是预先指定的一个配对验证候选，不作测试搜索。D2NN没有路由，此参数不改变其计算；再次训练D2NN用于检验结果可重复，不将重复结果计作独立随机种子。
