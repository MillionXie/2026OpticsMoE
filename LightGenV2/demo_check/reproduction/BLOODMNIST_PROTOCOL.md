# BloodMNIST八类光学分类：预定试验协议

任务：区分八种正常外周血细胞类型，不是正常/患病二分类。使用28×28 RGB标准版，保留所有类别及官方划分边界。原11959/1712/3421训练/验证/测试中，训练图内部有8个重复项、3个唯一图像与验证重复。只在训练端保留每种RGB字节内容的第一张，剔除与验证完全相同的图，剩11948训练图；验证1712不变。首个尚未完成的试跑`bloodmnist_rgbtile_s17_20260916`已在发现此问题后停止并保留，不进入正式比较；新run为`bloodmnist_dedup_s17_20260916`，全部模型从头重训。仅本次可行性试验采用seed17，不能据单种子声明稳定优势。

在查看测试数据前预先规定：同时报告完整3421张官方测试，以及去除与任意官方train/val完全相同图像、并去除测试内部重复后的敏感性分析；不改变标签，不依据预测结果过滤，保存全部保留索引。该处理只排除字节完全一致图像，不能代替患者级或近重复审查。

数据版本：https://zenodo.org/records/10519652 ，文件`bloodmnist.npz`，官方MD5 `7053d0359d879ad8a5505303e11de1dc`。MedMNIST项目与原始数据 https://data.mendeley.com/datasets/snkd93bnjr/1 均明确标CC BY 4.0（2026-09-16核查）。发表时同时引用Yang等Scientific Data 2023（doi:10.1038/s41597-022-01721-8）、Acevedo等原数据doi:10.17632/snkd93bnjr.1及原论文doi:10.1016/j.cmpb.2019.105020，说明缩放、编码与模型修改。许可并不代表Nature录用标准已满足；此实验不能代替临床验证。官方为图像级7:1:2划分，本缓存没有可核查的患者分组ID，不宣称患者级外部验证。

输入uint8除255，双三次抗混叠放大至100×100并截断；训练时在RGB图上做共同的±10°、±3像素、±5%仿射增强，再双线性抗混叠到50×50。光学输入按`[R,G;B,mean(RGB)]`固定拼为1×100×100，均为非负振幅。无可训练电子前端、电子残差或输出分类头；不把颜色直接丢弃。验证与测试不增强。正式训练前，第四块全零的初版在深层MoE初始化冒烟中出现部分专家零梯度，故用固定RGB平均图替代全零块；不依据测试指标更改编码。

使用已审查归档传播模型：2/4/6层，MoE为全部九专家的动态振幅加权，D2NN为整孔径；均开启Softsign OEO。原500面、相位尺寸、功率归一化和理想九端口假设保留，仅分类器改为八个探测窗口，两行四列、每个32×32、左上角(126,198)、窗口间净间隔40像素。类编号按行优先对应八窗口。相同深度参数量仍近似匹配，不将此说成物理成本完全一致。

第四块改平均图后，零相位初始化的四层MoE仍在首批数据出现部分零梯度，因此不能将原因仅归于全黑块。正式训练前，两架构统一改为raw_phase∼Uniform(-1,1)，实际相位2πsigmoid(raw_phase)，打破恒定相位的传播对称性；其余计算图不变。初始化使用同一随机种子、相同分布，参数形状不同不宣称逐元素相同。训练允许ReLU导致个别批次零梯度，完整保留记录；核验要求每个参数张量在所记录批次中至少出现非零梯度且最终有实际更新，不将单批次零梯度直接等同于整个训练死亡。

损失：类别平衡且标签平滑0.02的NLL＋0.2×负对数探测捕获率＋0.02×圆周相位平滑。捕获率=八窗口光强之和/整个最终探测面光强之和，直接约束聚光，不能解释为含OEO的端到端光电效率。相比前轮Adrenal的损失已改变，不作数据集变化的单因素因果比较。所有光学模型采用同一损失、AdamW（weight decay=0）、lr0.002余弦降至0.0002、batch16、裁剪1、EMA0.95；最大30轮、至少15轮、验证平衡NLL连续8轮无0.0005改善早停，按同指标选择EMA权重。

预先固定小CNN作为可学习性参考：Conv3→16(3×3)、ReLU、AvgPool2、Conv16→32(3×3)、ReLU、AvgPool2、AvgPool2、Dropout0.2、Linear288→8。RGB28输入，同类仿射增强后缩回28；AdamW0.001、wd0.01、batch128，其余选模和EMA原则相同，最多30轮。CNN单独训练、独立分类，不进入光学模型，也不作为参数预算匹配的D2NN对照。首次结构冒烟发现CUDA自适应池化反传不支持严格确定性，在任何正式训练前改为固定池化（7×7→3×3），保留严格确定性设置。

主报告准确率、宏平均召回率（balanced accuracy）、宏F1、宏OvR AUROC、每类召回、混淆矩阵和多数类基线。八类均匀随机准确率期望12.5%；多数类基线按训练集多数类别固定，再在验证/测试计算。明确区分AUROC与准确率。

先只读train/val，保存相同顺序/增强哈希、全相位梯度和参数变化；全部模型训练完成才封存源码、数据、best权重与验证结果哈希。测试入口逐项验证并重放验证指标后，才打开test数组。测试不参与超参数或任务选择，不按MoE与D2NN差距挑权重。失败和退步结果保留。GPU0单卡串行，正式新源码先提交推送再执行。
