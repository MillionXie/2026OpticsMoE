# AdrenalMNIST 非线性筛选与公平比较

用户要求尝试其他非线性，主指标 AUROC，希望 MoE+OEO > MoE > D2NN+OEO > D2NN，并尽可能兼顾准确率。排序是待检验的目标，不是改写结果或削弱对照的选择标准。

## 固定架构

9专家全激活 MoE：100×100 灰度振幅 → 100×100 光路由相位与5cm ASM、CCD九区域能量、softmax(S/100) → 理想九端口复制中继，入口振幅权重按 L2 归一化 → [九路146×146专家相位与各自5cm局部ASM（pad30后传播再裁剪）→ 拼498×498平面、专家OEO → 498×498全局相位、500×500画布5cm ASM → 全局OEO] × L/2 → 额外5cm至相机 → CCD两个32×32区域归一化能量分类。后续周期从全局场裁剪九窗口，无再次路由加权。

D2NN：灰度输入 → [中心相位层 → 500×500画布5cm ASM → 中心498×498 OEO] × L → 额外5cm至相机 → 相同探测区域。L=2/4/6相位边长474/472/470。MoE参数449848/889696/1329544；D2NN参数449352/891136/1325400。两种架构均无Qwen、TF、电子分类头。

OEO强度 I=|U|²，逐样本498×498非仿射LayerNorm（eps=1e-6）得Z，A=f(Z)，直接零相位振幅重编码，不开方、加增益或再归一化。专家OEO仍在整拼接平面归一化，输出仅保留九专家窗口；全局OEO/D2NN保留画布最外1像素原复场。无OEO跳过完整中间强度检测、归一化、激活和相位重置；路由与最终CCD保持。

候选共享函数：Softplus β=2（log(1+exp(2Z))/2，稳定实现）；正半轴Tanh（tanh(max(Z,0))）；正半轴Softsign（max(Z,0)/(1+max(Z,0))）。不增加可训练参数。相位参数化中的Sigmoid不变。

## 数据与预算

使用既有AdrenalMNIST3D沿axis2平均投影灰度数据；28×28双三次抗混叠缩放100×100。train/val/test=1188/98/298，测试标签0正常229、1增生69。数据SHA256=22bc193a85c43be85f093bf12f3ffdc5ed79b5efda63925bd9e063a70594bf93。无增强、重采样。

每次50轮，batch8，Adam lr0.001、WD0、StepLR每10轮×0.7。损失仍为完整探测面连续强度归一化MSE×100；无CE或路由正则。检查点按验证AUROC选取（容差1e-6，同分按更低探测面MSE，再更早轮次）。相位初始raw=0实际π，与历史同深度同种子哈希一致，数据逐轮顺序按种子配对。

筛选：4层 × 两种架构 × 三候选 × 种子17/27，共12次50轮训练。聚合两种架构及两种子的最佳检查点验证AUROC；候选若距最优<=0.01纳入，再按平均固定0.5验证准确率、平衡准确率、AUROC、更低探测面MSE、候选预先顺序依次选取。一个共享激活用于两种架构及全部深度。测试结果、期望的架构排序不参与筛选。

正式：2/4/6层 × 两种架构 × 有/无OEO × 种子17/27/37/47/57，共60次；其中四次入选激活的4层筛选运行完全复用，故总计68次独立训练，不为重现实验而重复相同计算。无OEO也重新训练，为验证阈值提供同等完整模型与预测。

## 阈值、锁定与报告

保留固定score1>0.5主结果。另分别在各检查点验证集选最高准确率阈值、最高平衡准确率阈值。阈值集合为相邻唯一验证分数的中点，加0、0.5、1；主指标相同则另一指标更高，再更接近0.5，再更小阈值。四模型组全部使用相同规则，测试集不选阈值。阈值不会改变AUROC/AP/连续MSE。

筛选完成后锁定共享激活；全部60最佳权重与对应验证阈值锁定后才读取本轮测试数组。落选候选不评测试集。测试集历史已被使用，不声称完全独立新测试。统计5种子均值和样本标准差，并给配对差、九指标折线图及逐样本预测，不删除失败排序。主图fixed_0.5；补充val_accuracy和val_balanced，所有均值是否满足严格排序分别输出。
