## EuroSAT：数据、张量与计算图

同一10类分类任务的RGB/SAR双域；原27,000对，按原预设有效性规则保留26,892对。
每域train/validation/test=15,998/5,465/5,429。同地点RGB/SAR绑定划分；50km地理块和
3km邻近关系分组，五折分层分组划分，seed42。已核对清单中26,892对和552个空间组
无跨集合混用；尚缺原图像包，不能重审图像与地理坐标的原始来源。

RGB从64×64中心裁56×56；SAR VV/VH重投影到对应56×56网格，各通道1/99百分位
截断，再按原作者固定均值±2标准差缩放，第三通道取前两通道均值。保存8bit三通道PNG。
两域统一双三次放大224×224；训练水平翻转和ColorJitter(.1,.1,.1,.02)。
两种模型使用相同样本顺序、增强种子和采样次数。

以B表示batch（正式训练B=60；hook检查B=2）：

| 位置 | 实际形状／运算 |
|---|---|
| 处理后图像 | B×3×224×224；像素/255，再按mean=std=(0.5,0.5,0.5)标准化 |
| Qwen打包patch | (196B)×1536；1536=3×2×16×16，静态帧按处理器规则复制到时间patch |
| grid | B×3，每行[1,14,14]；没有额外的多帧信息 |
| 冻结patch投影＋位置嵌入 | (196B)×1024；无视觉Transformer、语言网络或merger |
| 电子输入投影 | B×196×1024 → B×196×192，并做LayerNorm |
| 光场编码 | 每token 192→224，LayerNorm、Softplus，得到B×196×224 |
| SLM输入 | 补28行零成B×224×224；每样本RMS归一化到0.5 |
| MoE路由 | B×4概率，L2归一化成振幅系数；4个224×224专家，2×2排列 |
| D2NN输入 | 224×224特征光场双线性放大478×478，保持输入总功率 |
| 数值传播 | B×518×518复场，有效区478×478，λ=532nm，像素17μm，主传播10cm |
| 每次CCD读出 | B×478×478 → 强度归一化 → adaptive average pool到B×224×224 → 每行LayerNorm/ReLU |
| 光学输出回特征 | 只取前196行，每行224→192，得到B×196×192 |
| 最终分类 | 两个光电混合块后，token均值和最大值拼成B×384，LayerNorm＋Linear→B×10 |

Qwen的196个patch以2×2块优先排列。用编码patch编号的测试图确认了该顺序；电子
二维卷积前的`_mix_spatial_tokens`正确恢复14×14空间网格，卷积后再恢复Qwen排列。
这里未发现顺序错误。SLM的两个轴分别为token和投影特征，不能把SLM图直接解释为遥感图像。

两个块的实际结构：
`f1 = electronic_block1(z) + alpha1 * optical_expert_readout(z)`；
`f2 = electronic_block2(f1) + alpha2 * optical_global_readout(f1)`。
第二个光学块重新电子编码、振幅加载第一块融合特征，并沿用第一块路由系数；不是
第一块复光场不经探测直接穿过第二张相位板。两个块都含非线性电子/OEO操作，D2NN对照也一样。
初始alpha1=alpha2=0.055，下限0.05，上限1；这不是归一化贡献比例，不能据此说光学只贡献5.5%。

## 四专家究竟如何加权

自动推理全部4专家激活，不是Top-1/Top-2。令softmax输出p，则入口振幅
`w_i=p_i/sqrt(sum_j p_j^2)`，功率份额`q_i=w_i^2`。系数在光场入口生效，随后传播、
相干叠加和强度探测；不是4个分类器独立预测后对类别概率加权平均。
SAR/光学域标签只用于训练的专家分组/路由监督与诊断，不作为自动推理输入。

“组目标0.7”监督的是原始概率：正确组[0.35,0.35]、另一组[0.15,0.15]。
此时正确组入口功率为0.245/0.29=84.48%，不是70%。目标需明确要约束概率还是光功率。
初始概率归一化、权重L2归一化和专家分组监督在数学上能运行；概念不可混用。

## EuroSAT训练中的优先排查项

| 阶段 | 训练内容 | 固定内容 |
|---|---|---|
| 共享40轮 | 电子模块、分类头；第5轮起共享全局相位 | 专家相位、路由器；uniform/isolated交替加载 |
| A专家15轮 | 只训练E0/E1相位，使用A域和隔离路由 | 共享电子、头、全局相位、B专家、路由器 |
| B专家15轮 | 只训练E2/E3相位，使用B域和隔离路由 | 共享电子、头、全局相位、A专家、路由器 |
| 合并 | 直接组合专家权重；共享部分哈希一致；隔离输出逐位一致 | 不训练 |
| 路由15轮 | 只训练路由相位，CE＋0.2蒸馏＋0.02路由KL＋0.005捕获项 | 全部专家、电子、头、全局相位 |

此处“多阶段训练”与“网络有两层光学块”是两回事。

1. **后期缺少专家与路由协同优化。** 专家按隔离输入训练，自动推理却同时混合；合并后只有
   路由器可改变。任务已被共享部分很好解决时，专家相位和路由器的额外收益可能很小。
   这是设计风险，尚不能凭初始化证明已训练模型完全绕过光学支路。
2. **光学分支起点较弱。** alpha初始0.055且靠近0.05下界，电子可训练40轮，而专家冻结。
   应读取训练后alpha、两支路输出RMS和CE梯度，再判断是否电子支路主导；目前无原权重。
3. **电子dropout实际上关闭。** 配置p=0.1，但训练入口`M.set_mode(...,False)`、`M.predict`
   均使用eval模式。eval不禁止梯度，因此参数仍训练；它确实关闭dropout。两模型同受影响，
   不是单方面偏袒，但方法说明应写实际值0，或另开新版本验证启用dropout。
4. **路由损失权重不能直接说明约束强弱。** 要记录CE/KD/KL各项对路由相位的梯度，
   不能只把0.02增大就假定分工改善；全样本平均负载均衡也不保证按域分工。
5. **已有消融更指向专家贡献弱。** 自动、均匀、已知域隔离平均准确率为78.57%、78.48%、
   78.18%；已知域本身没带来收益。恢复A/B专家初始相位也影响很小，故不能只怪路由器。

## 建议的新训练协议（待验证，不替换历史结果）

目的为固定相位下的已知双域自动分工；所有优化只用训练与验证集。

1. 先建立A/B×专家组A/B的交叉评估矩阵、关闭光学支路的诊断、固定等功率分光对照，
   检查“正确专家有用”是否成立。域路由正确率高但性能不变，不能视为分工成功。
2. 保持相同输入和共享电子结构，从短共享预热转入按域分组训练；在均衡A+B批次中，让
   A组处理A、B组处理B，更新对应专家，共享部分由两域共同更新。无需先把共享网络充分
   训练40轮再留给专家补差。预热和总预算需预先固定或等预算验证选择。
3. 冻结已形成能力的专家，训练路由器模仿域分组；评估入口功率、逐域分配和任务损失。
   先证明路由器能区分两域，再与固定分光比较。不能只有一张平均路由热图。
4. 逐步从已知域分光过渡到自动分光，低学习率联合训练路由器、专家及必要共享部分，
   保留适度域分组辅助监督。若模块独立替换是额外硬要求，应禁止改共享部分并单独立项，
   不要把它与本次“推理相位固定”的要求混为一谈。
5. 在验证集比较合理的融合初始化与归一化设置，两种架构同等预算调参；避免只优化MoE。
   目前两个专家组成一组，只能先证明组间分工，不能自动宣称四个专家各有不同能力。

## 对照公平性与“无路由D2NN”

用户将固定分光网络视为无路由D2NN是可行定义；应明确它的物理拓扑。
建议保留：①当前动态四路MoE；②相同四支路、固定等功率输入、移除路由器的D2NN；
③现有整孔径D2NN。①②最直接检验输入相关分光收益，①③比较完整架构。
②应从头训练，不只是把训练好的MoE临时改成均匀权重。若比较无中间OEO，
固定光路对复场为线性，但最后强度读出仍为平方关系。

当前已匹配：划分、样本/增强顺序、17,500步、每域525,000次样本呈现、相同电子网络及分类头。
总可训练参数MoE1,186,804／D2NN1,164,408，接近但并非完全相同。
仍不相同：四个小孔径vs整孔径加载、路由额外光路、可更新参数集合、损失、教师前向计算、
分阶段选模策略。D2NN AB每阶段仍训练其电子/头/相位，最后选85轮中最佳双域验证结果；
MoE最终只在15轮路由阶段选模，且优先保留满足每域不降超过3个百分点的检查点。
相同SGD步数不能解释为相同训练FLOPs或同等优化机会。

新的公平对照应统一数据协议、输入功率定义、共享电子、读出、OEO开关、验证选模和调参预算；
分别披露相位像素、孔径、传播距离/次数、路由CCD开销。无需为了制造预期排序削弱D2NN。

## SAR ColorJitter的含义

RGB的三通道表示颜色，而此处三通道表示VV、VH、两者均值。ColorJitter的saturation/hue
按颜色改变通道关系，不对应明确的雷达物理变化，也可能破坏第三通道等于前两通道均值的关系。
不是仅凭使用ColorJitter就能判定“不规范”，更不是数据泄漏；它是缺少物理依据、值得消融的选择。
两模型使用同一增强，形式上的一致性已有，但不代表增强符合SAR测量含义。
建议RGB/SAR按模态分别定义增强，同一模态在两模型中保持一致；SAR先去掉色相/饱和度扰动，
保留经验证合理的几何增强。需要强度噪声时，在原始VV/VH上建模并重建第三通道，不能随意RGB染色。
接口定义见https://docs.pytorch.org/vision/0.14/generated/torchvision.transforms.ColorJitter.html。

## Adrenal：数据、结构与层数

任务为正常/增生二分类（标签0/1），输入是肾上腺3D形状掩膜的二维平均投影，不是直接读整幅CT。
官方标签见https://github.com/MedMNIST/MedMNIST/blob/main/medmnist/info.py。
每例28×28×28除255、沿最后一个空间数组轴平均成28×28，再双三次抗混叠放大到100×100并截断[0,1]。
未做逐图max归一化，无增强/过采样。官方划分1188/98/298；标签计数分别[929,259]/[76,22]/[229,69]。
本地NPZ没有患者ID，只能确认沿用官方划分，不能独立证明患者级隔离。

MoE张量：B×1×100×100灰度振幅→B×500×500复场画布；路由B×9；图像补边至146×146，
分配九份到3×3专家孔径，pitch176，总有效区498×498。各专家局部ASM使用pad30，即206×206，
再裁回146×146；拼接后经过498×498全局相位，在500×500画布传播。每个周期为
“专家相位/传播/OEO＋全局相位/传播/OEO”。L=2/4/6对应1/2/3周期，路由仅在入口计算一次。
探测器两个32×32区域积分，输出B×2能量，经两区域总和归一化得到分类分数。
D2NN同为B×1×100×100输入和500×500画布，L层相位边长分别474/472/470，读出相同。

此处OEO为强度→498×498全平面非仿射LayerNorm→正半轴Softsign→零相位振幅重编码。
专家OEO拼接归一化后再丢弃窗口间隙；因此即便公式相同，MoE与D2NN的归一化输入分布并不相同。

2/4/6层分别从头训练，同一模型的全部层通过最终MSE联合反传，不是逐层训练，也没有
“先训2层再加2层”。所有模型都是50轮。加深不保证测试AUROC或准确率单调提高：
- 这里加入的是实际传播/裁剪/OEO，新增层没有保证能成为恒等映射；各深度D2NN孔径还不同。
- 无OEO的固定光路仍是线性复场变换，更多相位可以改变可实现线性算子，但不会自动提供新输入非线性。
- 有OEO时多次强度探测、零相位重置、归一化、饱和及窗口裁剪，可能损失信息或增加优化难度。
- 同样50轮并不能证明各深度都已充分优化；按验证AUROC选模与优化探测面MSE的目标也不一致。
- 小数据和测试抽样误差仍存在；五个seed只改变训练顺序，使用同一划分，不能代表五次独立数据实验。

优先审查各深度训练/验证曲线、分层梯度/场能量、OEO输出的零值率和饱和率，再进行等预算
学习率/训练长度验证；不要为了单调曲线调整测试集、选seed或删结果。

**暂缓事项 ARCH-01（按用户要求记录）：** 理想无损九端口复制、局部独立传播再拼接与
真实共孔径光路之间的差异。后续核对损耗、串扰、路由分光功率以及是否需要全幅相干传播；
本轮不修改该物理模型，也不将其当作已经验证的硬件实现。

## 阈值和指标：用本次真实结果解释

“阳性”是数据标签1（增生），“阴性”是标签0（正常）；并非分数正负。
模型输出两区域能量E0、E1，代码将s=E1/(E0+E1)（加极小数保护）作为增生分数。
它是归一化分数，尚未校准为真实患病概率。代码使用s>0.5判增生，否则判正常。
0.5就是阈值；降低阈值通常增加检出，也增加把正常判异常的数量。

| 指标 | 含义 |
|---|---|
| Accuracy准确率 | (判对的正常+判对的增生)/全部样本 |
| Recall/敏感度/阳性召回率 | 检出的增生/真实增生，即TP/(TP+FN) |
| Specificity特异度 | 判对的正常/真实正常，即TN/(TN+FP) |
| Precision阳性精确率 | 真增生/全部被判增生，即TP/(TP+FP)；无阳性预测时代码约定为0 |
| Balanced accuracy | (增生召回率+正常召回率)/2，减小类别数量不平衡的掩盖作用 |
| AUROC | 跨阈值的排序区分能力；随机抽增生和正常，增生分数更高的比例，平分计半；0.5随机、1完美 |

例如真实增生分数0.3、正常0.1，排序正确；但都小于0.5，因此标签预测都是正常。
本次两层MoE+OEO的298个测试分数范围0.02331至0.37826，全部低于0.5；增生/正常
分数中位数分别约0.1572/0.1087。因此AUROC=0.7216与召回率0完全可以同时成立。
全部判正常会得到76.85%准确率、0%增生召回率、100%特异度和50%平衡准确率。
示意图为本轮真实预测：`../../runs/smoke/tensor_review_20260916/threshold_and_roc.png`。

阈值只能在验证集按预先声明的目标选定，再固定测试；不能看测试分数后挑好看的阈值。
AUROC不因单独更换决策阈值而改变。参考定义：
https://scikit-learn.org/stable/modules/generated/sklearn.metrics.roc_auc_score.html。
