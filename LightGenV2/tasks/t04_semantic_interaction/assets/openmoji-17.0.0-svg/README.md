# OpenMoji SVG subset

These 16 files are the official OpenMoji 17.0.0 color SVGs used by T04.

- Source: https://github.com/hfg-gmuend/openmoji/tree/17.0.0/color/svg
- Authors: OpenMoji contributors
- License: CC BY-SA 4.0, https://creativecommons.org/licenses/by-sa/4.0/

The filenames are Unicode codepoints. The experiment rasterizes each SVG at
1024×1024, crops the transparent boundary, and then applies a documented
category-specific visible height. The SVG geometry itself is not distorted.
