# OpenMoji 语义编辑指标说明：定义、例子与论文写法

更新时间：2026-10-15。面向论文撰写与绘图同学。

本说明对应 T04 应用线的实验室 Ours **0.8655** 与 Qwen baseline **0.8120** 定量图表。
不改变模型、数据划分、指标计算或权重选择。实际结果及报告/PT 身份见
[本目录 README](README.md)；下面用于解释计算的场景是**假设教学例子，不是实测样本**。

## 1. 先理解这个实验在做什么

输入包含一张 OpenMoji 场景图和一条文本指令。例如，图中有房子、小狗和树，指令为：

> 把小狗移动到房子右边，其他内容保持不变。

模型需要理解图像和指令，再输出编辑后的场景。当前定量评估的对象是
**6×6 语义类别网格及编辑位置网格，不是渲染 RGB 图片的逐像素相似度**。

- 类别网格：每个格子保存类别编号；0 表示背景，非零表示物体类别。
- 编辑位置网格：每个格子是否应该修改。
- 操作类别：新增（add）、替换（replace）、移动（move）、删除（remove）。

网格位置是场景中的语义锚点，不是相机像素，也不是物体轮廓/检测框。一个视觉上很大的
房子不因此在本套指标中按 RGB 占地面积获得更大的权重。

### 最终结果如何合成

实际评估器先取类别 logits 的最大值位置，得到每个格子的生成类别；对编辑 logits
取 sigmoid，概率 **≥0.5** 的格子视为预测需要编辑。最终类别网格按下面的规则形成：

```text
预测需要编辑的格子   → 使用模型生成的类别
预测不需要编辑的格子 → 复制输入网格原来的类别
```

以下类别准确率、Object F1 和 Scene exact match 都评估这个**最终合成网格**；
Edit-grid IoU 则直接评估预测的编辑位置集合。因此，要同时考虑“内容是否改对”与“位置是否找对”。

## 2. 一个贯穿全部指标的例子

以下行列编号均从 1 开始，仅为便于阅读；程序内部数组从 0 开始。

| 物体 | 输入场景中的位置 | 正确目标中的位置 |
|---|---|---|
| 房子 | 第1行第1列 | 不变 |
| 树 | 第2行第5列 | 不变 |
| 小狗 | 第4行第2列 | 第4行第4列 |

指令是：**将小狗从第4行第2列移动到第4行第4列，其他内容保持不变。**

令 A = 原小狗位置，B = 新小狗位置，C = 第6行第6列。正确执行需要修改两个格子：

- A：小狗 → 背景，删除原位置的小狗。
- B：背景 → 小狗，在新位置生成小狗。
- 其他 34 格保持不变，包括房子、树和背景。

假设模型犯了下面的错误：

1. 正确判断指令属于“移动”。
2. 正确在 B 生成小狗。
3. 没有把 A 预测为编辑位置，因此原位置的小狗被复制保留。
4. 错把 C 预测为编辑位置，并生成一只猫。
5. 房子和树均正确保留。

| 位置 | 输入内容 | 正确目标 | 模型最终结果 | 是否正确 |
|---|---|---|---|---|
| A：第4行第2列 | 小狗 | 背景 | 小狗 | 错，忘记删除 |
| B：第4行第4列 | 背景 | 小狗 | 小狗 | 对 |
| C：第6行第6列 | 背景 | 背景 | 猫 | 错，多生成对象 |
| 其余33格 | 房子、树或背景 | 保持不变 | 保持不变 | 对 |

真实编辑位置集合为 **{A, B}**；预测编辑位置集合为 **{B, C}**。
目标有 3 个对象，预测有 5 个对象，其中 3 个对象的类别和位置完全匹配。

## 3. 八项指标的具体含义

### 3.1 Task accuracy：操作类别识别准确率

检查模型的四分类操作头是否正确识别出 add / replace / move / remove。
逐场景预测正确记为 1，否则为 0，最后取平均。

**例子：**模型判断为“移动”，与指令一致，因此该场景得 **100%**。
即使移动错了对象、忘记删除原对象，这一项仍可能正确。

**它回答：模型知道要做哪类操作吗？**

建议在论文里写成“操作类别识别准确率”，不要将 Task accuracy 不加解释地写成
“任务完成准确率”。本次两系统均为 100%，区分度有限，适合补充材料。

### 3.2 Preserved-cell accuracy：应保留格子的准确率

只在数据标记为应保留的格子上，计算最终类别与目标类别相同的比例。
应保留位置既包括已有物体，也包括应继续为空的背景位置。

**例子：**34 个应保留格子中，C 被错误地从背景改成了猫，其余 33 个正确：

$$
\mathrm{PreservedAcc}=\frac{33}{34}\approx97.06\%.
$$

**它回答：编辑有没有误伤不该改变的地方？**

适合补充说明编辑保真度。因为系统本身会复制预测为不编辑的原网格内容，
此项很高并不等价于模型完成了困难的编辑。

### 3.3 Cell accuracy：全部格子的准确率

在整张 6×6 网格的 36 个格子上，比较最终类别与目标类别。
它包含背景、未编辑物体和需要编辑的物体。

**例子：**只有 A 和 C 错误，其他 34 格正确：

$$
\mathrm{CellAcc}=\frac{34}{36}\approx94.44\%.
$$

**它回答：整张网格平均有多少位置正确？**

该例移动没有完整成功，但这个指标仍很高，因为大量背景及无需修改的位置都正确。
因此不能只用 Cell accuracy 证明编辑能力；建议放补充材料。
图表中的 Cell accuracy 与原数据的 `cell_accuracy` / All-cell accuracy 是同一项。

### 3.4 Foreground category accuracy：目标前景类别准确率

只在**目标网格中类别大于 0** 的格子上，计算最终类别正确的比例。
它排除目标背景，但仍包含目标中未被编辑的物体。

**例子：**目标前景只有房子、树以及 B 处的小狗。这三个位置的类别都正确：

$$
\mathrm{ForegroundAcc}=\frac{3}{3}=100\%.
$$

A 和 C 在目标里都属于背景，不进入这个分母，所以多出的小狗和猫没有直接扣这一项。

**它回答：目标要求存在物体的位置，其类别是否正确？**

它不充分惩罚额外生成物体，需结合 Object F1。正文版面允许时可作为第 5 项，
否则放补充材料。不能把它直接称为对象 Precision。

### 3.5 Object F1：对象集合的综合匹配程度

将所有非背景格子写成 **（类别，行位置，列位置）** 三元组。类别与位置都一致才算匹配：

- TP：预测与目标共有的三元组数量。
- FP：预测中存在、目标中不存在的三元组数量。
- FN：目标中存在、预测中不存在的三元组数量。

$$
P=\frac{TP}{TP+FP},\qquad
R=\frac{TP}{TP+FN},\qquad
F_1=\frac{2PR}{P+R}.
$$

**例子：**预测 5 个对象，目标 3 个，匹配 3 个，因此 TP=3、FP=2、FN=0：

$$
P=\frac35=60\%,\qquad R=\frac33=100\%,\qquad F_1=75\%.
$$

**它回答：对象整体是否正确，是否存在遗漏或额外生成？**

建议进入主图。这里匹配的是语义网格三元组，不是检测框 IoU、像素轮廓重合或实例分割 F1。
模型在错误位置输出正确类别也不算 TP；在正确位置输出错误类别同样不算 TP。

### 3.6 Changed-cell accuracy：要求修改位置的类别准确率

只在**真实要求编辑的格子**上，比较最终类别与目标类别。
检查范围由真实标注决定，不由模型自己预测的编辑位置决定。

**例子：**真实编辑位置为 A 和 B。A 没有正确变成背景，B 正确变成小狗：

$$
\mathrm{ChangedAcc}=\frac12=50\%.
$$

**它回答：真正要求修改的内容，最终改对了多少？**

它不会因另外 34 个位置正确而大幅抬高分数，因此建议作为主指标。
移动通常同时涉及原位置与目标位置；本例只完成一半，得 50%，不意味着指令完整成功。

### 3.7 Edit-grid IoU：编辑位置集合的交并比

令 E 为真实编辑位置集合，预测集合为 E-hat，计算交集大小除以并集大小：

$$
\mathrm{EditIoU}=\frac{|\hat E\cap E|}{|\hat E\cup E|}.
$$

**例子：**E={A,B}，E-hat={B,C}；交集只有 B，合并后有 A、B、C：

$$
\mathrm{EditIoU}=\frac13\approx33.33\%.
$$

**它回答：模型是否找对了应该修改的位置？**

它不直接检查修改后的类别。比如，指令要求把狗换成猫，模型找准狗的位置却生成了树，
IoU 可以是 100%，Changed-cell accuracy 却可能为 0%。因此二者互补，均建议进入主图。

### 3.8 Scene exact match：完整场景精确匹配率

对一个场景，最终 36 格类别全部等于目标时记为 1，任意一格错误就记为 0；最后对场景平均。

**例子：**A 和 C 仍然错误，该场景得 **0%**。

**它回答：整个语义场景是否被完整做对？**

建议进入主图。它最严格，但不是 RGB 图片逐像素完全一致，也不是要求所有辅助输出头都正确。
按当前代码，只要最终类别网格与目标相同，此项就为 1；编辑位置头仍可能存在不影响最终类别的差异。

## 4. 同一例子的八种分数

**本表仅为教学计算，禁止作为真实实验数据画进结果图。**

| 指标 | 例子中的得分 | 原因 |
|---|---:|---|
| Task accuracy | 100% | 知道这是移动操作 |
| Preserved-cell accuracy | 97.06% | 34 个应保留格子只错 1 个 |
| Cell accuracy | 94.44% | 36 格中只错 2 格 |
| Foreground category accuracy | 100% | 目标的 3 个前景位置类别都正确 |
| Object F1 | 75% | 3 个对象匹配，但多出 2 个对象 |
| Changed-cell accuracy | 50% | 2 个应修改位置只完成 1 个 |
| Edit-grid IoU | 33.33% | 漏改 A，又误改 C |
| Scene exact match | 0% | 最终网格没有全部正确 |

这些数值并不矛盾。八项检查的是不同能力，不能将它们简单平均成一个综合“准确率”。

## 5. 统计方式、单位与边界

### 5.1 先逐场景计算，再取平均

当前代码先为每个场景计算各项指标，再按 overall / add / replace / move / remove 分组平均：

$$
\overline m=\frac1N\sum_{n=1}^{N}m_n.
$$

例如，Object F1 是先算每个场景的 F1 再平均，而不是将全测试集 TP/FP/FN 汇总后算一个 F1。
Changed-cell accuracy 也是先在每个场景的真实编辑位置内部平均，再在场景之间平均；
编辑格较多的移动操作不会因此在 overall 中自动获得更大场景权重。

本次两份报告各有 1,000 个 TEST 场景，四类操作各 250 个，因此 overall 也等于四类操作
对应场景均值的等权平均。不要改变汇总口径后继续使用原来的指标名称与数值。

### 5.2 小数、百分数与百分点

- 0.8655 = 86.55%。
- 86.55% − 81.20% = **5.35 个百分点**。
- 相对提升为 (0.8655 / 0.8120 − 1) × 100%，约 **6.59%**。
- Scene exact match=0.7620 对应 1,000 个场景中 762 个最终网格完全正确。
- Changed-cell accuracy=0.8655 则不能直接解释为 865.5 条指令完整成功。

### 5.3 与源码一致的边界处理

原评估器将没有目标前景的场景的 Foreground category accuracy 设为 1；
编辑位置并集为空时 Edit-grid IoU 设为 1。Object precision/recall 的分母以 max(1,数量)
保护，P+R=0 时 F1 设为 0。Changed/Preserved accuracy 对标注掩码内元素直接取均值，
不能擅自给空掩码另设成绩；复用到新数据集时应先检查标注是否满足该前提。
这些是代码口径说明，不表示本次正式数据一定包含这些边界场景。

### 5.4 不能混淆的比较边界

本目录主对比是 Ours **实验室光电实测**与 Qwen **数字推理**，不是两个仿真结果；
Ours 的同 PT 仿真 0.8765 不能替代实测 0.8655。原实验使用 TEST 参与选模，故应标为
开发结果，不冒称独立留出泛化。现有实测汇总报告缺少逐样本预测 ID，不能从汇总均值
推算某一张图片的指标或进行逐样本配对显著性检验。

## 6. 论文正文建议放哪些

推荐正文放下面四项，补充材料放完整八项；版面允许时可增加 Foreground category accuracy。

| 推荐指标 | 在论文中的作用 |
|---|---|
| Changed-cell accuracy | 主指标：修改后的内容是否正确 |
| Edit-grid IoU | 编辑位置是否找准 |
| Object F1 | 对象整体是否正确，兼顾遗漏与额外生成 |
| Scene exact match | 整张语义场景是否完整成功 |

选择依据是指标互补性，不是挑分数较高或较有利的指标。分操作结果仍应完整呈现，
包括 Ours 较弱的操作；不能将高 Task/Cell accuracy 等同于高编辑成功率。

## 7. 可用于论文方法部分的说明

> 我们从编辑内容正确性、编辑区域定位、对象集合一致性和完整场景成功率四个方面评价
> 语义编辑性能。模型输出类别网格与编辑位置网格，并利用预测编辑位置将生成类别与输入
> 网格合成为最终结果。Changed-cell accuracy 衡量真实编辑位置上的最终类别准确率；
> Edit-grid IoU 衡量预测与真实编辑位置集合的交并比；Object F1 基于类别及网格位置完全
> 匹配的对象集合计算，综合反映对象遗漏和额外生成；Scene exact match 要求整个输出
> 语义网格与目标完全一致。各指标首先按场景计算，再在测试场景上取平均。我们另外报告
> 全格准确率、目标前景类别准确率、应保留格准确率和操作类别识别准确率作为补充分析。

论文结果段落另外明确实测/数字推理、选模协议和样本数；不要省略这些信息后称为独立泛化结果。
