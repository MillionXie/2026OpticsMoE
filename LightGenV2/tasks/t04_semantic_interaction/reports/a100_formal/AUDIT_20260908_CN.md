# T04 OpenMoji 语义交互：光学、电子与 Qwen3-VL 基线审计

## 结论

原表中的 `Optical 0.980` 与 `Qwen3VL 0.548` 不是同等训练条件下的“光模型与大模型”比较。

- `Optical Router Top-2` 是一个经过同任务 warm-start、具有四个可训练任务块和专用 6×6 解码器的**光电混合模型**。四层最终光学融合系数仅为 5.09%–5.34%，电子系数为 94.66%–94.91%。
- 原 `Qwen3VL` 行冻结了完整 Qwen，仅训练 1.212M 参数的浅层结构化读出头；它没有得到光电模型那套四层任务适配能力。
- 删除同一光学 checkpoint 的光支路后，changed-cell 从 0.9800 **升至 0.9850**；仅保留光支路时 changed-cell 为 **0**。光支路对 edit IoU 和 exact match 有小幅正贡献，但不是 98% 主指标的主要来源。
- 去掉光学传播和光路由、保留相同任务数据流和专用电子块的匹配电子对照达到 changed-cell **0.9965**。因此任务与数据没有问题，低的 0.54 来自过弱的 baseline 定义。

正式表格不应把 0.980 写成“纯光性能”，也不应把 0.5415 简写成不加限定的“Qwen3VL”。建议同时报告光电混合模型、匹配电子对照和冻结 Qwen 结构化读出三行。

## 相同的数据与指标

- 数据：OpenMoji 6×6 场景，训练 5,000、测试 1,000；add / replace / move / remove 各占四分之一。
- 输入：一张场景图和一条编辑指令。
- 输出：17 类的 6×6 category grid，以及 6×6 edit grid。
- 主指标：changed-cell accuracy；同时报告 foreground category、edit IoU、object F1 和 scene exact match。
- 没有 validation；各训练实验均允许周期性测试并按 test changed-cell 选权重。该口径存在 selection bias，但与当前项目约定一致。

## 三条实际数据流

### 1. 当前 Optical Router Top-2

1. 文本由冻结 Qwen3-VL-2B-Instruct 生成最多 64 个 contextual hidden，随后离线缓存。
2. 图像只经过冻结的 Qwen patch embedding 和 position embedding；不经过原生 Qwen Vision Transformer block。
3. 语言两层、视觉两层任务块均为 `(1-alpha)E + alpha O` 的光电融合；光 Router 选 Top-2/4 专家。
4. 语言条件被注入视觉支路，最后由三层 conditioned residual block 和 6×6 category/edit/task 头输出。
5. 从旧 OpenMoji 同任务 epoch-20 checkpoint warm-start 116 个电子/解码器张量，光学与 Router 重新初始化；新训练按周期 test 选中 epoch 20。

正式 checkpoint 的 scale-matched alpha：

| 融合位置 | 光系数 alpha | 电系数 1-alpha |
| --- | ---: | ---: |
| Language block 1 | 0.05341 | 0.94659 |
| Language block 2 | 0.05300 | 0.94700 |
| Vision block 1 | 0.05112 | 0.94888 |
| Vision block 2 | 0.05087 | 0.94913 |

### 2. 原冻结 Qwen 结构化读出 baseline

1. 图像和文本通过完整、冻结的 Qwen 原生 Vision/Language Transformer。
2. 取 Qwen 原生视觉 token 和最后一个文本 hidden。
3. 只训练 1,212,434 参数的 FiLM + depthwise-convolution 6×6 读出头；Qwen 参数修改数为 0，无 LoRA。
4. 预测 edit grid 后，代码把未编辑位置从 source grid 直接复制到输出。

该头在 remove 上得到 0.988，但 add 仅 0.220、replace 0.340、move 0.618；它主要学会“删除/不改”，没有稳定学会物体定位与关系推理。

把输入从 224 提到 448，使 Qwen 视觉 token 从 7×7=49 增至 14×14=196，changed-cell 仍只有 0.538；只改成光学任务 loss 则更差。因此低分不是简单由分辨率或 loss 造成。

### 3. 匹配电子对照

该对照保留冻结 Qwen 文本 contextual hidden、冻结 Qwen patch/position stem、语言两层、视觉两层和同一个专用 6×6 解码器；只把光学传播与光 Router 替换为普通电子 token mixer + residual MLP。

- 可训练参数：2,663,716。
- 训练：50 epochs，batch 32；每 epoch 测 test。训练在空闲 RTX 3090 上完成；性能随后用选中 checkpoint 在 A100 上复核，正式速度/功耗全部来自 A100。
- 全周期 test 最优：epoch 28，changed-cell 0.9965。
- 若强制采用和光学相同的 epoch 1 / 每 5 epoch / final 选择频率，最佳 changed-cell 仍为 0.9955。

它是解释“光还是电”的主要公平对照；但它不是完整原生 Qwen3-VL 推理，应命名为 `Qwen-derived matched electronic control`。

## 性能结果

| 方法 | Changed ↑ | Category ↑ | Edit IoU ↑ | Object F1 ↑ | Exact ↑ |
| --- | ---: | ---: | ---: | ---: | ---: |
| 光电混合 Optical Router Top-2 | 0.9800 | 0.98945 | 0.93500 | 0.98368 | 0.8950 |
| 同 checkpoint，去掉光 | 0.9850 | 0.99163 | 0.92182 | 0.98091 | 0.8760 |
| 同 checkpoint，只留光 | 0.0000 | 0.70543 | 0.00000 | 0.67988 | 0.0000 |
| 冻结完整 Qwen + 1.212M 结构化头 | 0.5415 | 0.17212 | 0.27134 | 0.12782 | 0.0090 |
| Qwen-derived 匹配电子对照 | **0.9965** | **0.99667** | **0.99383** | **0.99698** | **0.9830** |

“只留光”的 foreground/object 指标来自大量未编辑 source cell 被保留，不能解释为模型成功完成编辑；其 changed、edit IoU 和 exact 均为 0。

## A100 速度与能耗

### 测量协议

- GPU：NVIDIA A100-PCIE-40GB，额定功率上限 250 W；PyTorch 2.6.0+cu124，bfloat16。
- 进程启动一次后连续测完整 1,000 个 test 样本。
- 显式 warm-up 为 0，第一个样本计入；因此同时给 mean、median 和 P95。
- 冻结 Qwen 边界：原生 Vision Transformer block 0 入口，到 category/edit 结果；文件 I/O、PIL/processor 和 H2D 排除。
- 匹配电子边界：已归一化图像张量和缓存的 Qwen 文本 hidden，到 category/edit 结果；Qwen 文本 hidden 的离线生成排除。
- 光电混合耗时采用项目约定的 paper serial path：6 次物理 pass，加四次 CCD 后读出/归一化/融合、语言到视觉 bridge 和最终任务头；并行电子残差、Router post 和下一张 SLM 重建不重复计入。

| 方法 | Mean ms | Median ms | P95 ms | 平均板卡/光路功率 | 实测/估算能量 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 冻结完整 Qwen + 结构化头 | 49.053 | 46.894 | 64.858 | 91.257 W | 4.476 J/样本 |
| 匹配电子对照 | 6.535 | 5.914 | 7.892 | 68.500 W | 0.448 J/样本 |
| 光电混合 paper serial path | 11.808 | — | — | 光路 80.388 W | 0.949 J/样本 |

补充口径：

- 冻结 Qwen 的 idle-subtracted 能量为 1.498 J，250 W 额定上界为 12.263 J。
- 匹配电子对照的 idle-subtracted 能量为 0.0519 J，250 W 额定上界为 1.634 J。首个冷样本 415 ms 被保留，因此 mean/能量高于 median 所暗示的稳态值。
- 光电混合若除了 80.388 W 光路，还把 A100 在光传播等待期的 idle 功率和串行电子阶段实测功率都计入，组合代理能量约 1.697 J、平均功率约 143.7 W；它不是实验室功率计直接测得的端到端数值。
- 按主表的 80.388 W 光路口径，冻结 Qwen 相对光电混合约慢 4.15×、耗能 4.72×。
- 上述 4.15×/4.72× 只在项目的 paper boundary 下成立：光电路径使用离线缓存的 Qwen 文本 hidden，而冻结 Qwen baseline 计入原生 Vision/Language block。若目标是“任意新指令的真正端到端系统”，还必须把光电路径生成文本 hidden 的时间和能量加回来。

## 建议如何改正式表格

1. 把 `Optical` 改名为 `Hybrid optical-electronic Router Top-2 (alpha≈5.1%–5.3%)`。
2. 把原 `Qwen3VL` 改名为 `Frozen Qwen3-VL-2B + 1.21M structured head`，保留 0.5415，不能暗示这是充分微调的大模型上限。
3. 新增 `Qwen-derived matched electronic control`，正式可用同每 5 epoch 选模口径的 0.9955；全周期最优 0.9965 放在补充材料。
4. 同时列出 remove-optical 0.9850 和 optical-only 0.0000，作为光贡献的必要消融。
5. 当前结果只能支持“光电混合架构在速度/能耗上有潜力”，不能支持“光学计算带来 98% 准确率”或“光学优于 Qwen”。

如果后续要让光承担实质任务，应单独训练 alpha 下限更高的版本（例如 alpha≥0.2、alpha≥0.5），并同时报告准确率、remove-optical 和 optical-only，而不是继续提高电子读出能力掩盖光支路。
