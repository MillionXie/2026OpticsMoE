# 02｜商品检索：图搜文（ABO）

**数据处理。** 使用 ABO 的固定 100 商品子集，每个商品包含同一转台拍摄序列的 72 张视角图像，其中 48 张划入训练集、24 张划入测试集，共 4,800/2,400 张。每个商品使用元数据中的一条原始标题，构成固定的 100 项文本候选库。测试查询为保留视角，候选标题覆盖全部 100 个商品。图像经 EXIF 方向校正并转换为 RGB；使用模型原生图像处理器保持长宽比，将最小和最大像素预算均设为 50,176（224²），由处理器确定实际网格尺寸。

**模型处理。** 采用冻结的 Qwen3-VL-Embedding-2B，分别编码图像查询与文本标题。图像端的 system 指令为 “Retrieve the product title that best describes this product image.”，user 内容为商品图像；标题端的 system 指令为 “Represent the user's input.”，user 内容为原始标题。两端均采用原生对话模板并加入生成提示，执行各自所需的完整主干，取最终语言层最后有效 token 的 2,048 维表示并作 L2 归一化。使用 BF16 主干和 batch size 1，不对模型微调，也不训练额外投影或检索头。

**检索与评价。** 预先计算 100 条标题的归一化向量。对每张测试图像提取查询向量，与全部标题计算余弦相似度并降序排序。每个查询仅以同一商品 ID 对应的标题为正确项，R@1 定义为排名第一的标题正确的查询比例。完整 2,400 张测试图像的 **R@1 为 0.7358**。训练划分不参与该冻结基线的参数拟合。
