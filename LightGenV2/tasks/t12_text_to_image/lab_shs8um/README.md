# T12小版光路试采

这是六个固定图文商品编辑输入的试采，不是完整测试集成绩。严格加载20260926最终small.pt，9,958,098预算参数；冻结词嵌入另列。前端缓存仅为词嵌入，不缓存训练语言主干输出。

师弟电脑独立工程：`E:/code/guest/2026OpticsMoE/T12_Small_Lab_SHS_8um`。`assets`包含权重、固定输入和SHA合同，`source`包含独立代码，不覆盖ABO。复用ABO_Lab_SHS_8um的GPU环境与硬件驱动。

运行本目录的`run_physical_pilot.cmd`，必须在实际登录桌面执行（SSH需通过交互式计划任务启动）。相机及两块SLM的GUI均关闭，不通过可视化远程桌面改变扩展屏。输出目录不可复用；重复试验改用新目录，不覆盖已有CCD。

配置：400微秒、Gain_X4、240ms换振幅等待；相位换层0.8秒，连续排空相机旧帧。仿真17微米/10cm/532nm；478有效区重采样1016，居中于振幅1920×1080和相位1920×1200。相位hv翻转并255-g，相机flip_v，沿用20260926四角。旧棋盘格非零包围框[452,32,1468,1048]已核对为1016平方；本试验不要求重新标ROI。

完整顺序：语言router→语言expert→语言global→视觉router→视觉expert→视觉global→原电子decoder输出256 RGB。六张输入批处理，每层各拍六张。不会替换router决策或绕过光计算；回填CCD后由原模型进行强度读出、同尺度融合及下一层幅度编码。仿真CCD仅用于参考，不替代实拍。

`runs/physical_pilot_01/ccd`保存478线性ROI PNG和曝光/相位SHA收据；`phase`保存六层1920×1200 BMP；根目录保存输入、GT、仿真和实际输出，以及report.json。正式不保存全幅TIFF。指标为此固定试采的MSE，不能称全测试集性能。

接口自检：先使用`run_pilot --selftest`新目录，仿真CCD经同一回填接口，六阶段顺序正确且RGB最大误差<1e-6；自检不占用硬件。
