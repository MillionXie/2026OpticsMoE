## 原架构与适配候选

原T16两方共同：532 nm / 17 µm / 每段10 cm，986²有效口径、1026²画布；无alpha和电残差。
MoE：router224²独立CCD→16专家槽联合相干传播→一次OEO→global相位→CCD→均值归一化28²池化→唯一无偏置Linear(784,10)。
D2NN：两层完整口径相位，中间同一OEO，末端同结构Linear；无router。
MoE是dense soft routing，不是Top-k，已开放全部专家参与，功率q对应输入振幅sqrt(q)。
阶段开放4/8/12/16槽，旧专家冻结，router/global/同一共享读出更新；不能按任务换头或换专家选择器。
EuroSAT/CLEVR使用同一冻结32,128参数CNN；Speech/Physical不用CNN。特征缓存保持原float16→float32步骤。

原物理口径986×17 µm=16.762 mm，当前1016×8 µm=8.128 mm，无已验证中继合同，不能直接resize复现原传播。
`model.py`构建**新实验室适配图**：native8 µm、active1016²、canvas1056²，16槽各230²、gap32、border20。
保留16专家、两层分类相位、MoE独立router、一次OEO和同一Linear结构；明确改变物理孔径/传播采样及相位张量形状。
插值原raw相位可warm-start，但需要新A→B→C→D顺序训练/验证链；不能独立微调四个原PT后拼成终身学习结论。
原开放顺序保持4/7/10/13→2/5/12/15→3/8/9/14→1/6/11/16（1-based）。

适配阶段允许训练光学参数；**上机阶段每个学习阶段全部采完，仅微调原共享Linear，不做逐层mask训练**。
每阶段只允许一个共享PT和共享Linear，联合评估该阶段所有已见任务；禁止逐格独立选PT拼曲线。

同相机上一Caltech任务收据：2011帧约1086–1238秒，即约0.54–0.62秒/帧。
据此参考EVAL约7.5–8.6小时；含上述TRAIN约11.9–13.6小时，另计标定、服务器训练、优化与必要下游重采。

## 训练和实验边界

先完成硬件前向适配、服务器smoke、数据/源/PT SHA闭包和子集仿真，才做新硬件会话/桥接/pilot。
曝光/坐标/LUT从既有会话只读参考，不自动用旧478裁剪替代1016；实测方向、动态范围、OEO振幅、窗口映射须核验。
native模型现在显式包含固定TRAIN标定显示增益、振幅8位round量化与相位8位floor量化（STE训练）；实际相位响应和相机采样仍须物理验收。
不能逐图按峰值拉满；单位L2振幅若直接乘255常不足一个灰阶，需固定TRAIN增益后把量化写入前向，防止看似通光实际全零。
既有phase LUT是linearVoltage，不应冒称已完成线性相位标定。
逐层整组TRAIN/EVAL连续、已测前缀冻结；上游改变则只使后继CCD失效，不混入其他phase的CCD。
目标距同适配模型同子集仿真6pp以内，是目标非保证；若实测更高则如实保留，不压分维持趋势。
原模型同1000条子集仿真、适配后仿真、完整实测必须三列并列；不能仅因适配仿真降低就声称已恢复原图性能。
默认增强/教师仅TRAIN；评估选PT是开发指标。教师若接触TEST/增强TEST，蒸馏学生也受污染，单独隔离，不作独立测试结论。
实验室只接收Git源码，权重/数据按manifest+SHA；不开新branch/worktree，不用定时任务，不操作已收官Caltech。

## 本轮训练入口与资源边界

`train_native.py`：A从原A权重插值warm-start，B/C/D只能继承适配链父阶段，禁止直接加载原全量回放B/C/D拼接曲线。每阶段保持旧专家逐位冻结，开放下一组四专家；router/global和共享读出继续训练。
`config_native_memory300_20261024.json`固定小batch4、每阶段16/10/10/10轮上限、VAL选择（最少4轮、5轮无改善早停）。原TEST与分层TEST不参与梯度；选定阶段后才计算该阶段全部已学任务的同1000条TEST。
LightGen允许上一适配阶段教师在旧TRAIN记忆上进行普通蒸馏；D2NN不蒸馏，二者回放记录和次数相同，教师机制差异单独披露。教师不接触TEST。
用户确认0/1/3/4低占用，本轮仅允许共享1/3/4完整UUID，最多三张，单进程显存上限40%；不用GPU0、不用A100、不停止已有进程。实际开训前检查UUID/卡型和剩余显存。
