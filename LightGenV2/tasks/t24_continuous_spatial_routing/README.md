## 首轮设计

本任务比较两种在入射面上放置两份图像的方法。固定对照使用 T17 的四个探测窗选出两个角落。位置路由在同一光学路由器的 CCD 强度图上定位两个峰，以局部强度质心细化坐标，按两个读数分配光振幅。两路各输入完整的 224×224 振幅图，同相叠加后通过一张共享的 478×478 专家相位面，再经过 OEO、478×478 全局相位面、OEO 和同一个形式的无偏置 Linear 读出。两相位面均按 518×518 画布在 17 µm 像素间距、532 nm 波长、0.1 m 距离传播。新任务的代码和产物均位于本目录。

位置是光点检测和位移控制的数字仿真。两个图像左上角各有横纵两个坐标，每个坐标范围 0–254 像素。空间共享允许部分重叠，包括原 30 像素间隔处。探测峰的选择离散，局部质心与平移是连续的。模型在专家面前归一化合成光场的总功率，表示同一入射功率预算。光学平台上的寻址器、亚像素投影精度、相干叠加效率和控制延迟均需要另行测量。

## 对照设计

使用与 T17 图 b 一致的 Kather2016 固定划分，训练 3496 张，验证和测试各 752 张。两种路由从相同初始化开始，训练样本、同一随机种子的批次顺序、梯度更新预算和选模规则配对。仅用训练标签更新，验证集选权重，最终用同一批测试切片计算正确数和逐样本差异。该划分曾用于 T17 的开发。两个预定种子 17、29 各训练 8 轮，不为选择结果而延长。与历史 T17 成熟模型的预算不同。

两个分支都存储同样大的首层相位张量。固定角落分支实际能照亮的区域限于四个 224² 方块，连续分支可访问其间区域。比较包含位置选择、窗口读数和有效受光区域的共同变化。更灵活的前向放置方式可以是更好的归纳偏置，也可能带来插值衰减、峰切换和优化难度，分类性能由实测判断。

## 坐标精度与适用范围

连续分支在路由 CCD 的 17×17 个候选中心读取 60×60 光强窗口。选出第一峰之后，第二个候选中心与第一中心的切比雪夫距离至少 60 像素。每个峰周围 3×3 窗口的光强质心给出浮点坐标，按双线性插值平移输入。这个约束分开的是 CCD 读数窗口，224×224 的入射图仍可重叠。连续分支所有测试图上两份输入均有面积交叠。可选位置增多与短预算下准确率下降同时发生，本实验尚未单独测定重叠的因果影响。

## 复现

在仓库根目录运行以下命令。每个种子、每个 mode 使用自己的新输出目录，MODE 取 fixed 或 continuous，SEED 取 17 或 29。每台 GPU 按授权 UUID 设置 CUDA_VISIBLE_DEVICES。
```bash
python -m LightGenV2.tasks.t24_continuous_spatial_routing.train --config LightGenV2/tasks/t24_continuous_spatial_routing/configs/kather2016.json --seed SEED --mode MODE --out LightGenV2/tasks/t24_continuous_spatial_routing/runs/simulation/kather_sSEED_MODE
```

第二个数据集为 BloodMNIST128 血细胞八分类，使用 T17 的完整原划分 11948/1712/3421。原划分的训练/测试间有 5 个相同像素哈希，验证/测试间有 1 个。第一组测试准确率揭晓前确定这一数据集及相同预算。使用 configs/bloodmnist128.json，将输出命名前缀 kather 改为 blood。运行 compare 模块时用 --dataset kather 或 --dataset blood。
