# 专家数量与稀疏度：实验协议 v2

状态：设计。下文“采用”描述拟实施合同，不代表模型、训练、光学梯度检查已完成。
用户最新要求：只做仿真，输入17 μm逻辑网格、权重映射至8 μm相位设备；间隔30逻辑像素，单专家224²；4–49专家全部保留。
历史 demo 指标及checkpoint不作为本协议的结果。主入口与进度见 [README](../README.md)。

## 1. 研究问题与变量

研究三个可区分的问题：固定 k 时增加可选择专家是否改善分类；固定 k/N 时增加容量是否有效；
联合学习两个域时是否出现可验证的专家分工。专家数、每图激活数、总相位参数量、有效孔径、
全局混合距离与输入功率都要单独报告，不能把它们合称为“模型规模”。

主网格 N={4,9,16,25,36,49}；
k=unique({1,2,4,ceil(N/4),ceil(N/2),N})。
绝对 k=1/2/4 回答相同入口分支数下扩大专家库是否有用；比例网格回答稀疏比例的变化。
不同 N 的取整比例不同，图中同时标明实际 k/N。k=N 是连续加权的 dense MoE，不是普通 D2NN。

默认特征深度 L=6，专家/全局各3层。仅做 N=9、k=9 的 L∈{4,6} 验证校准：
MoE、总参数匹配 D2NN、等孔径 D2NN 均同样尝试两个深度、两个学习率。
每个候选深度先各自选验证损失最低的学习率，再取三个模型验证宏平均NLL的均值，选择最低的共同 L；
若相同取较浅层。各任务可有自己的共同 L，但同任务内各 N/k/模型固定。
小规模校准只选模型，不再绘制深度性能主图。若 L 改变，重新生成设计矩阵并锁定 profile；
矩阵目前以 L=6 计算。不能给 MoE 多层、D2NN 少层后称同深度比较。

## 3. 输入编码与张量

所有模型接收同一张图、同一次增强。RGB转float [0,1]；非正方形图先等比例缩放并对称补零成方形，
使用相同双线性插值与antialias设置，再得到 [B,3,112,112]。主协议不直接把RGB平均成灰度。
按二维拼接 `[R,G;B,(R+G+B)/3]` 得到 [B,1,224,224] 的非负振幅图。
四象限是空间编码，并非四种光波长，也不是Qwen token或可学习patch embedding。

MoE：编码图直接填满每个224²专家入口；按分光权重缩放后放入整场，张量为 [B,C,C] complex64，
其中 C=G+40。Router也使用同一份224²编码图。
D2NN：从同一112²/通道图逐象限插值至 S/2，再拼成 S² 输入，S为其可训练相位边长。
禁止先将RGB拼图整体插值造成象限边界串色；禁止给D2NN读取更高分辨率原图。
放大只改变照明覆盖，不增加原始图像信息。两者均以平方和归一化使总主路入口功率为1；
全黑图不强行放大，在manifest中检查并统一处理。

训练增强初案：Kather/PBC随机水平、垂直翻转及90度旋转；DeepWeeds随机水平翻转，
裁剪尺度[0.85,1.0]、长宽比[0.9,1.1]。无色相扰动、无独立模型专属增强。
validation/test不随机增强。所有增强由(sample_id,epoch,seed)独立确定，防止模型RNG消耗不同导致输入不一致。

## 4. 光学计算与 OEO

λ=532 nm，逻辑像素17 μm，每个特征阶段传播0.1 m；末端探测传播也是0.1 m。
与正式工程一致，在17 μm网格训练224²逻辑专家权重；按相同物理宽度映射到8 μm相位SLM，
单专家为476设备像素，30逻辑像素间隔对应510 μm。映射不引入额外可训练参数。
仿真不缩小物理孔径，也不将8 μm设备pitch当成17 μm输入数组的计算pitch。全局相位为G²逻辑像素。
每个专家阶段将所有专家相位嵌入同一全场传输函数，间隔处为固定单位透射；
**所有区域一起进行相干ASM传播**，不逐专家独立传播后无损拼回。无专家参数的间隙光也参与传播。
global阶段是整块G²可训练相位；外围数值画布不含可训练相位。

每个特征阶段后执行相同的整面OEO：

1. 在G²区域探测 I=|U|²；除以该样本区域平均强度加epsilon，得到无量纲强度。
2. 对整块G²作无仿射参数LayerNorm，epsilon=1e-6；不为MoE单独按专家归一化。
3. t=ReLU(normalized_intensity)，a=t/(1+t)，重新编码为零相位振幅。
4. a在G²内L2归一化至总发射功率1，区域外置零。零输出单独记异常，不靠除小数放大。

OEO的归一化/重新供能是电子操作，不是光功率无损；记录每级OEO前后的功率及增益。
没有绕过衍射网络到分类输出的电子残差支路，没有可训练电子分类头。
主路和Router使用独立再编码曝光，入口功率1只约束主路，不能忽略Router曝光后声称两者总能耗相同。

末端每个类别窗口固定32²、中心间隔48像素；按ceil(sqrt(类别数))的方形网格居中，
按固定类别ID逐行分配，未用位置不算类别窗口。所有N和两种模型保持完全相同的类别窗口坐标与面积，
不随G增大窗口以人为改善捕获率。输入/OEO功率归一化中的零分母保护使用1e-12，并记录触发次数。

主仿真暂用无噪声OEO研究架构规律。另在冻结的代表模型上评估固定总光子预算1e4/1e5/1e6、
Poisson散粒噪声及2电子RMS读噪声（单位和量化步骤实现时明确），所有模型同预算、同噪声种子。
光子数按总入射能量分配，不能让靶面变大自动获得更多总光子。
单张图按场归一化会掩盖低捕获率，故无噪声准确率不足以证明硬件性能。

ASM补零从2倍C开始，在N=4与49、同一固定输入/相位上比较2倍与4倍补零，
检查输出能量、类别能量分数、边界能量和相对误差；相对场/强度误差阈值1%，探测概率最大差0.005。
不满足时增大补零或采用验证后的带限实现，对两种模型同步处理，不能以压缩专家解决显存问题。
先profile真实显存/每步时间；显存不足用microbatch累积至有效batch16、checkpointing，保持更新次数一致。

## 5. 路由的定义与训练

当前旧代码`optical_reference/prompt.py::_topk_routing`先保留Top-k概率，
`models.py::RelayFanoutMoE`再按振幅L2归一化，实际入口功率正比p²。
新协议明确用概率表示功率：选中集合S后 q_i=p_i/sum_{j∈S}p_j，振幅a_i=sqrt(q_i)，未选中为0。
这与旧p²功率合同不同，必须重新训练，不能混画为同一系列。

Router相位固定224²。在同一224²输出平面放固定7×7个24²探测区、pitch32；
按到中心距离、行号、列号排序取前N个作为该N的专家输出端口，全部N共用固定面积探测单元。
空间端口与专家编号一一映射，但不要求Router探测排布与专家阵列几何相同。
完整49端口坐标由plan.py导出。记录非活动端口/探测区外功率；分数用区域能量/全router面能量，
再softmax(logits/T)，T初案0.05固定，不能按N改变检测面积或手调温度救某个点。
若温度导致梯度或分布问题，只在pilot增加T∈{0.02,0.05,0.1}的统一搜索并冻结全N使用的规则。

**k=1不能直接照搬旧hard Top-k训练。** 归一化后选中振幅恒等于1，选中索引几乎处处不可微，
分类损失无法通过这条路径教Router换专家；epsilon造成的极小导数不构成有效学习。
拟用前5epoch dense预热，之后hard前向、dense振幅梯度代理：
`a_ST = a_soft + stopgrad(a_hard-a_soft)`，其中a_soft=sqrt(p)。
推理始终执行声明的hard Top-k。STE是有偏梯度估计；训练可能计算全部专家，不声称训练算力降为k/N。
先检查无STE时Top-1梯度退化、有STE时分类项可改变router相位及选择；不能只看均衡损失梯度证明训动。

主表采用 **entry_topk**：仅入口选k路，后续全局传播可能把光送回其他专家。
因此它研究入口稀疏度，不称“每层仅k专家激活”。记录各层每个专家实际入射功率及非选中区功率。
补充 **persistent_topk**：每个专家层前重用入口选中集合遮挡未选中区域，后续不补偿遮挡损失；
OEO仍遵守共同重新供能定义，区分遮挡前后及OEO供能。此模型单独命名并重训，不与entry曲线混合。

在N=9、k=1/4及N=25、k=4上加：固定集合等功率、按样本ID确定的随机集合等功率、动态路由。
这些是MoE内部路由消融；固定多支路不命名为普通D2NN。
专家分工证据至少含：每类/每任务专家选择分布、跨样本选择变化比例、每专家梯度/相位更新、
打乱路由与固定路由的性能变化。只看到负载均衡不能证明学会语义分工。

## 6. D2NN公平对照和容量控制

共同：图像ID/增强、源信息分辨率、主路总入口功率、波长/像素/传播距离、特征深度、
OEO数学定义、检测窗口、损失、batch/更新次数、验证选模方式；两者所有相位联合训练，不逐层冻训。
MoE额外Router相位/曝光、理想分光、全局相位和电子Top-k开销必须单列。

设L=2J，E=224，R=224，G为全局面：

`P_MoE = J×(N×E² + G²) + R²`。

- D2NN-P（主baseline）：L张S² dense相位；取最接近sqrt(P_MoE/L)的可容纳偶数S。
  主路总相位参数误差不超过0.5%，**包含MoE的Router与global相位**；逐象限将相同输入铺满S²。
  其OEO测量区域仍为G²，传播画布与对应MoE相同。
- D2NN-A：L张G² dense相位、输入铺满G²，等有效孔径但总参数通常较多，明确标注，不能称参数相等。
  其结果回答“给D2NN同样大靶面是否仍存在优势”。

D2NN没有k，同一N的D2NN只训练一次即可用于该N所有k；图中N仅表示匹配的MoE几何。
两个baseline均保留其最好验证checkpoint，即使高于MoE也完整展示。
主表不要求匹配仅k个专家的激活参数，因为当前有global再分配，且dense算法训练不等于物理稀疏计算。

固定global控制：所有N使用同一1748² global/OEO面，专家在中心按原间隔排布，
在N=4/16/49比较k=4及k=N，并重算D2NN-P；固定孔径D2NN-A此时只需一份。
仍是随N增加专家参数，但全局相位数量不再增加。这能排除global参数增长的一部分混杂，
不能排除专家覆盖面积与布局改变。另记录无路由/冻结路由后的差异，不将相关性写成唯一因果。

## 7. 优化、泛化和选模

初案60epoch、有效batch16、AdamW、lr=0.002、weight decay=0，cosine衰减到初值0.01，
梯度范数裁剪1、EMA=0.95；每epoch验证一次，固定总预算不因某模型提前停止而增加另一个预算。
前5epoch路由dense预热包含在60epoch内；D2NN同样获得60epoch，不少算5epoch。
pilot学习率各尝试0.001/0.002，各模型拥有相同试验次数；之后学习率随模型类型冻结，不能逐N手挑。
当前这些是候选超参，不冒充在新224²模型上已验证有效。

类别概率为各窗口能量加epsilon后除以全部类别窗口能量和。所有任务均为多分类argmax，无二分类阈值调优。
损失：宏类权重交叉熵（label smoothing0.02）+0.02×[-log(capture+epsilon)]
+0.02×相位平滑项；MoE另加0.01×路由均衡项。
类权重仅由train计数计算，归一化使train样本平均权重为1；validation选模用每类平均NLL再取类均值。
capture=类别窗口能量之和/末端探测画布总能量。
相位平滑用相邻差的`1−cos(Δφ)`均值，再按相位面求均值，避免专家越多正则总量自动变大；
Router均衡用`N×sum(mean_batch(p)²)−1`。这些项及原始量分别记日志，检查梯度比例。
若capture接近0，报告低捕获率，不通过单样本归一化隐藏该问题。

主选模：EMA validation macro-NLL最小，同分取较早epoch。校准后冻结N/k、损失、训练预算和checkpoint清单，
再做一次test。test仅用于描述预先设计的整张矩阵；“最佳k”必须由validation确定再引用对应test，
不能在test上取每个N的最大值作为方法成绩。Kather旧test暴露限制保持披露。

过拟合：同一个EMA checkpoint、同样无增强评估的train/val/test差距和逐epoch NLL，
不能把在线增强train accuracy与无增强test直接相减。训练差+验证差是优化/表示瓶颈，
训练好+验证差才支持过拟合判断；N增大不保证单调提升。要改增强/正则时对照同预算重跑并保存旧协议。

## 8. 联合任务与图表

先完成单任务，在N=9与25、k=1/4/N预先定义联合Kather+DeepWeeds的17类实验。
单一共享光路、单一17窗口读出，类别ID偏移，不提供任务ID给Router，不用任务专属电子头。
batch16各取8个样本，任务等权loss；小数据集循环采样，固定每任务样本曝光次数而非含糊称相同epoch。
单任务补充对照使用相同17窗口布局、相同每任务曝光次数，未使用类别窗口在其任务loss中屏蔽，
但仍计入光捕获诊断。联合训练报告完整17类accuracy、各域条件8/9类accuracy和每任务相对单任务变化。
只在条件分类时屏蔽跨域类别不能冒称17类联合识别。

联合模型各N训练量为两个单任务总样本曝光量之和；同时报告实际更新次数与总GPU时长，
不将联合训练的额外数据预算混同于架构收益。若加PBC，扩展为25类，独立profile并重新配平任务采样。

必须输出：

1. validation与最终test的N×k热图，含对应两种D2NN差值；缺失格明确留空。
2. 固定k、固定k/N的性能曲线；横轴另画总参数/有效面，标明是否固定global。
3. 各模型相同checkpoint的train/val/test柱状图、训练损失和泛化差距。
4. 路由使用率、各层专家入射功率、类别/任务×专家热图、真实图像及其路由/预测示例。
5. accuracy、balanced accuracy（各类召回率均值）、macro-F1、macro-NLL、混淆矩阵；
   AUROC如使用则为one-vs-rest macro并交代类别权重，不以多数类accuracy替代学习证据。
