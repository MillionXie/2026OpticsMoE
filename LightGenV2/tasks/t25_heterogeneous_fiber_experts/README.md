# T25 四专家的单模光纤阵列对照

### 实验结果

实验室 GPU 上的 16 次仿真均完成 180 轮。下表按各次运行的验证集选中权重计算原 TEST 准确率，再对种子 37、53 等权平均。每个数据集、种子下的四组共享初始参数、训练样本顺序、优化器、更新次数和物理 GPU。Kather 每次训练更新 19,800 步，Blood 更新 67,320 步。[逐轮训练、验证、测试曲线和各专家的功率统计](reports/matched_fiber_20261128/results.html)

| 四专家布局 | 单模通道总数 | Kather2016 准确率 | BloodMNIST128 准确率 | Kather / Blood 模拟通光率 |
|---|---:|---:|---:|---:|
| 同构，全衍射 | 0 | 71.94% | 90.06% | 100% / 100% |
| 异构，两衍射＋两全覆盖光纤 | 1,568 | 73.27% | 89.78% | 83.24% / 67.76% |
| 同构，四个半覆盖阵列 | 1,568 | 72.81% | 90.09% | 61.98% / 59.57% |
| 同构，四个全覆盖阵列 | 3,136 | 73.60% | 90.35% | 29.44% / 14.86% |

通光率取自同一获选权重，在专家面上用首个 OEO 前的出射功率除以入射功率。全光纤组的平均准确率在两个数据集上最高，透过的功率也最少。异构组在 Kather 上接近全光纤组，同时保留了较多光功率。

相同的 1,568 个通道集中到两个专家后，Kather 平均准确率比均匀分到四个专家高 0.47 个百分点，Blood 低 0.31 个百分点。按种子 37、53 分开，Kather 的差值为 −0.80、+1.73，Blood 为 −0.79、+0.18 个百分点。现有两种子结果不足以支持异构布局稳定提高准确率。

若统一取第 180 轮，混合组相对半覆盖组的均值差分别为 +5.19、−2.05 个百分点；Kather 混合组此时准确率为 68.82%，较其验证集选模结果低 4.45 个百分点。按预定的验证曲线稳定性诊断，Blood 8/8 次、Kather 3/8 次满足条件。Kather 的两个混合组均未满足，四组仍按相同的 180 轮预算比较。

两个数据集的混合组在 99.47%–100% 的测试图像上同时选中一个衍射专家和一个光纤专家。所有 16 个获选模型在测试中均未选中 E4。Blood 的两个异构模型都在每幅图上选择两种专家，但分给光纤专家的入射功率分别为 65.13% 和 13.07%，整个专家面的通光率分别为 46.94% 和 88.58%。种子和光纤槽位同时变化，无法将这项差异单独归因于位置。

训练共完成 696,960 次参数更新。本机 CPU 严格加载了所有 16 个获选模型的四个参数张量，每个数据集固定抽取每类第一张 TEST 图。128 次推理的分类预测、带顺序的两个专家和落点均与服务器的逐样本记录一致，最大类别概率差为 0.00000433 以内。两台训练 GPU 上属于本任务的进程均已退出。[CPU 权重复核](reports/matched_fiber_20261128/checkpoint_replay.json) · [GPU 准入与文件校验](reports/matched_fiber_20261128/smoke_transfer.json) · [权重与逐样本归档校验](reports/matched_fiber_20261128/train_transfer.json)

### 实验设计

本任务比较固定四区域 Top‑2 路由中的两种专家。每个专家均有一块独立可训练的 224×224 相位区域。普通专家将调相后的复光场直接送入后续光路；光纤专家先用理想单模光纤阵列耦合、再出射。四个实验组共用 T24 四角模型的路由器、入射光功率、478×478 全局相位面、两次 OEO 和同一个形式的无偏置 784→8 读出。四个区域的排列顺序为左上 E1、右上 E2、左下 E3、右下 E4。

| 实验组 | 四个专家的光纤覆盖 | 总单模通道数 |
|---|---|---:|
| 同构衍射 | 全部直接传播 | 0 |
| 异构混合 | 两个全覆盖、两个直接传播 | 1,568 |
| 同构半阵列 | 每个专家的 28×28 单元中，相同棋盘布局的 392 个单元耦合，其余单元直接传播 | 1,568 |
| 同构光纤 | 四个专家全覆盖 | 3,136 |

### 光纤如何改变专家

在各光纤专家的 224×224 模拟平面上铺设 28×28 个单通道耦合口。每个 8×8 像素单元内的基模取归一化高斯振幅函数，场半径为 2 像素。对入射复场计算模式内积，每个单元传一项复系数，再乘输出基模重构出射场。保留导模的相位以及耦合造成的能量损失。未耦合的模式离开计算光路。各专家出射场随后在同一画布上相干传播。单模耦合的归一化场重叠积分见 [Ansys OpticStudio 光纤耦合说明](https://optics.ansys.com/hc/en-us/articles/42661682185107-Single-mode-fiber-coupling-in-OpticStudio)。

按 17 µm 的模拟平面像素计，单元间距为 136 µm，场半径为 34 µm。这是入射／出射光学中继平面上的有效耦合模设计值。仿真假定各芯相位对齐、导模传输系数为 1、芯间串扰为 0。实物光纤的模场直径、微透镜耦合、偏振、芯间相对相位和连接损耗仍需实测。OEO 沿用原模型的光强归一化；单独报告 OEO 之前的通光率。四组拥有相同的可训练参数和梯度更新预算，光纤数量、传输的空间自由度及算子成本随实验组变化。

### 预先确定的比较方法

在实验室服务器使用 Kather2016（3496/752/752）和 BloodMNIST128（11948/1712/3421）的原始 TRAIN/VAL/TEST 划分。四种模型均从头训练 180 轮；同一数据集和种子共享初始化、样本顺序、学习率、batch 及读出层。混合组的光纤专家取一对对角槽，在种子 37 和 53 之间对调。两种子均值包含布局和随机初始化的变化，不能单独估计布局效应。按验证集正确数选模，同分再按验证交叉熵和较早轮次。同步记录逐轮 TRAIN、VAL、TEST、共同末轮和获选权重的成绩。每个槽分别统计被选频率、入射功率份额和实际透过功率。原 TEST 曾用于 T17 开发；Blood 原划分中 5 个相同像素哈希跨 TRAIN/TEST、1 个跨 VAL/TEST。[实验配置](configs/matched_fiber_20261128.json)
