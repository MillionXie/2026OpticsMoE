# 四任务终身学习：架构、电子成分和数据协议复核（2026-09-24）

本文件只审计已完成的 seed=17 三张正式矩阵及其代码/数据协议；不把不同训练制度产生的分数归因为单一光学结构。正式指标均为完整测试集的 balanced accuracy。已完成的历史结果保留，不因本审计重选 checkpoint。

## 1. 两种模型实际处理链

共同入口：任务数据先在电子侧变成 224×224 非负振幅并做功率归一化。EuroSAT 以训练过的冻结 CNN 提取 128 维特征；CLEVR 以训练过的冻结视觉 CNN 提取 128 维特征，再拼查询词编码。Speech 采用固定 log-mel 图，Physical 采用固定的八帧相邻差分；两者无目标标签监督的 CNN 前端。**同一任务的已缓存输入对 MoE 与 D2NN 一样，但四任务并非共享一套 CNN。**

|环节|固定 16 槽 MoE|同画布 D2NN|
|---|---|---|
|第一段|224² router phase → 1026² 角谱传播 → 16 个 CCD 窗口测强度；按温度 1.25 和任务可用槽位算 soft 权重。输入振幅乘 `sqrt(q)` 后复制到允许的 224² 专家槽，乘各槽相位并传播。|输入从 224² 双线性插值到 986²，乘整块 986² 第一相位并传播。|
|中段|传播强度 → 均值归一化 → `softsign` → 功率归一化 → 电子重注入（OEO）。|相同 OEO。|
|第二段|986² global phase → 传播 → 相同 OEO。|986² global phase → 传播 → 相同 OEO。|
|读出|986² CCD 强度固定池化到 28×28，归一化并 `log1p`，按已知任务选一个 `Linear(784,C)`。|相同读出结构。|

相同画布为 1026²，有效相位口径 986²；最终 MoE 相位参数 1,825,188，D2NN 为 1,944,392（多 6.53%）。**参数和画布相近，不表示完全等算力/等光路**：MoE 多一次路由传播，第一段是稀疏槽位及数字权重调制，D2NN 则是整孔径插值照明。`OEO` 和路由都要求探测后的电子计算与重注入；它们不是被单层 Linear 限制涵盖的电子部分。最后只有一个线性读出层，指的是**每次推理所选任务的读出路径**；模型同时保存四个不同任务头，任务名在推理时已知，并控制 MoE 可用专家槽位。系统不是无任务标识的类增量分类器。

MoE 阶段按 4→8→12→16 激活；新增四个 expert phase 可训练，旧 expert phase 与旧任务头冻结，但 router 和 global phase 仍更新。D2NN 始终重训两块共享大相位，旧任务头冻结。光学参数均不包含冻结的前端 CNN、电子预处理、OEO 或任务头。EuroSAT 冻结 CNN 保留约 93,472 个特征提取参数；CLEVR 冻结视觉 CNN 保留 32,128 个。这些参数与光学参数不能混称。

## 2. “电子是否统一同权重”的准确答案

- EuroSAT / CLEVR 的各自冻结前端 checkpoint，在**同一个任务**内为 MoE 和 D2NN 共用；Speech / Physical 的固定编码规则也一样。EuroSAT 前端曾用地物标签训练，CLEVR 前端曾用颜色×形状存在性标签训练；仅删除最终分类层并不能抹去已学语义。已核对 CLEVR 辅助前端训练来自官方 train 图像的旧 pilot，不是正式测试采用的官方 val 图像，未发现此处的测试图像重叠。
- 两种模型的最终读出**同结构、不同训练权重**；各任务之间也有自己的 `Linear(784,C)`，不是同一组系数。输出类别数为 10/2/8/10。
- 矩阵 2 每行只替换独立训练的源任务 D2NN 光学相位，每列始终使用目标任务原已训练的 Linear 头及目标任务固定前端；逐格优化步数为零。它检验的是“源光学相位 + 已会做目标任务的电子表示/头”的兼容性，不能解释成整套异源模型不经适配直接跨任务工作。
- MoE EuroSAT 起点使用训练期电子 teacher（128→512→256→10 MLP）蒸馏，并筛选后导入；teacher 不在推理图中。MoE 后续任务有三轮新增专家预热、512/旧任务的 replay、当前任务 Linear 校准候选（仅验证增益时保留）；正式顺序 D2NN 无 replay、无校准。所以三张矩阵展示当前**系统和训练制度**的比较，不能单独证明 MoE 光学拓扑导致全部优势。

## 4. 目前结果说明什么

正式 MoE replay 下三角最终行是 EuroSAT 75.36%、CLEVR 66.38%、Speech 59.79%、Physical 78.76%；D2NN 无 replay 最终行是 52.62%、69.74%、52.47%、74.93%。MoE 最终四任务平均高 7.63 个百分点，但 CLEVR 更低，且 Speech 刚学入时 MoE 56.94% 低于 D2NN 58.84%。这不是“MoE 在所有任务均优于 D2NN”。MoE 第一阶段 EuroSAT 80.11% 对同画布 D2NN 79.92%，仅差 0.19 个百分点。

独立 D2NN 4×4 中，EuroSAT 目标列的异源光学相位得到 72.56%/76.36%；都低于 EuroSAT 自己相位的 79.92%，但可能高于**已经经历遗忘**的顺序 D2NN 最终 EuroSAT 52.62%。这两种对照不是同一个问题，不能说异源相位胜过同任务独立训练相位。相位消融进一步显示，在保持原电子头不动时，EuroSAT D2NN 训练相位/全平相位验证为 80.27%/74.55%（+5.72 pp）；CLEVR 为 76.72%/50.20%（+26.53 pp），Speech 为 66.79%/36.12%（+30.67 pp），Physical 为 80.37%/49.09%（+31.28 pp）。EuroSAT 的前端电子语义可能过强；但不能由此断言其余任务“全靠电子”。全平相位仍包含传播、OEO 与读出，且固定头的扰动会造成分布偏移；上述分数是敏感性证据，不是光/电贡献的严格因果拆分。

**命名错误：当前所谓 `full replay` 并没有完整回放旧数据。**配置每个旧任务只留 512 个不同训练样本，每个当前任务 batch 从每个旧任务取 4 个循环使用。CLEVR 一轮约 3,282 个 current batch，单个旧任务约 13,128 次 replay 样本曝光，512 个旧样本平均约重复 25.6 次/轮。正确名称应为“每旧任务 512 样本的固定记忆回放”；不能在汇报中称“旧数据全量回放”。

## 5. 下一轮先做什么，才值得重跑

1. **先用现有 checkpoint 做诊断，不训练新光学矩阵。**在完整验证集上分别测：原模型、仅保留冻结前端特征并训练同容量一层 Linear 的电子-only 基线、固定/全平/随机光学相位加固定头与重新训练头两组对照。针对 MoE 单独置平 router / expert / global，避免“一起置平”造成的错误归因。Speech/Physical 将固定文本半幅置零应几乎不改变其任务信息；若仍称“音文/视频文”，应先把文本改为逐样本变化的候选顺序，并验证遮掉文本后降至机会水平。
2. **补最小控制实验再谈结构优势。**保持同一冻结前端、相同光学几何、相同可用数据、相同电子头训练和 checkpoint 选择规则；仅在补充控制中做 2×2：MoE/D2NN × 有/无相同 512 样本 replay。训练期 teacher、EMA 和读出重拟合要两边同施或两边均不用。正式三张历史矩阵不必抹除；这组控制只用于拆分“架构效应”和“回放/教师效应”。先选 EuroSAT→CLEVR 两阶段跑通，确认相位变化、旧任务保持和输入消融，再决定是否花时间跑四阶段。
3. **减少无效训练。**正式 MoE CLEVR 20 轮中最佳验证均值在第 1 轮（另有 3 轮预热），继续完整 20 轮对最终 checkpoint 没收益，却占大部分 GPU 时间。下一轮预先固定每阶段验证早停（例如最少 5 轮、耐心 4–5 轮，按已学任务验证均值，不看测试集）；CLEVR 保留全部 70k 原图与 6/query 协议，不暗中抽样。Speech 最佳第 17 轮、Physical 第 14 轮，不能一刀切只训 5 轮。若进一步降 CLEVR 成本，可单独定义每图 1 正 1 负的**新任务协议**，依然覆盖全部 70k 图，但所有比较必须一起重跑且与旧矩阵分开报告。
4. **设置重跑门槛。**先要求任务级电子-only、相位消融和文本遮挡的结果能证明光学/文本确实承担必要信息，再承诺多天的四阶段正式重训。现有四个任务的数据定义本身与“真正跨模态交互”主张不完全相符，尤其固定文本候选表；优先修任务定义比延长训练轮数更重要。
