# 最终 16 槽 MoE 与 D2NN 的几何和参数公平性

正式终身模型从第一项任务起固定最终 4×4 专家槽几何。每个专家为 224×224，相邻槽间隔 30，
外边框为 20，因此传播画布为 1026×1026，可调全局相位口径为 986×986。任务之间不改变画布、
传播核、全局相位尺寸或 CCD pooling。

## 光学参数

|部分|计算|参数量|
|---|---:|---:|
|MoE 16 个 expert phase|16 × 224 × 224|802,816|
|MoE router phase|224 × 224|50,176|
|MoE global phase|986 × 986|972,196|
|MoE 光学参数合计||1,825,188|
|D2NN input phase|986 × 986|972,196|
|D2NN global phase|986 × 986|972,196|
|D2NN 光学参数合计||1,944,392|

D2NN 比最终 MoE 多 119,204 个光学参数，即约 6.53%。两者使用相同 1026×1026 传播画布、
相同 986×986 有效口径、相同传播距离、相同 OEO、相同 28×28 CCD pooling 和同一个
`Linear(784,C)` 读出合同。这个设置在物理口径一致的前提下略微有利于 baseline。

MoE 在每个新任务阶段只训练新增加的四个 expert phase、router、shared global phase 和当前任务
Linear；旧 expert 与旧任务 Linear 冻结。D2NN 每个阶段重构整块 986×986 input phase 和
986×986 global phase。参数公平性以最终存储容量和固定物理口径报告，同时另外报告每阶段实际
可训练参数量。

正式 D2NN 完整矩阵和无 replay 顺序矩阵必须使用同一个 986×986 EuroSAT checkpoint，保证两张
矩阵第一行第一列逐位一致。完整矩阵不进行逐单元 Linear 重拟合。
