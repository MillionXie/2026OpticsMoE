# 数据集与实验安排（给复现者）

## 1. SEN12MS：图图

每个样本是同一地理 patch 的两种传感器观测：Sentinel-1 双极化 SAR（VV、VH 两个通道）和 Sentinel-2 多光谱图像（13 个波段），另有 MODIS 土地覆盖标签。它不是普通 RGB 数据：SAR 的数值代表后向散射，不能做颜色抖动；光学通道按训练集统计量归一化。主任务将两个传感器各自映射成非负振幅、各占总输入功率 0.5，组合后输入相同的 MoE/D2NN 光学网络，输出 10 类土地覆盖窗口。

官方数据包约 510 GB，因此本轮采用预先登记的季节/ROI 子集。所有 patch 按地理场景划分 train/validation/test；同一 ROI 或相邻 patch 不跨集合。主指标是 accuracy、balanced accuracy 和 macro-F1；正负配对匹配只做辅助 sanity check。

## 2. CLEVR：图文

每个样本由一张合成 RGB 场景图和一个自然语言问题组成。问题从颜色、形状、计数和比较模板生成，答案空间是预先固定的类别集合。图像和文本各占 0.5 输入功率；文本先用训练集词表做定长 one-hot/小型编码，再映射到文本光场。MoE 与 D2NN 使用同一个冻结前端和同一光学预算。这里的结果用于验证图文组合，不把它解释成通用语言理解能力。

## 3. SONYC-UST：音文

每个样本是 10 秒城市环境音及其事件标注，例如 engine、siren、music、dog 等。一个录音可以有多个事件；标注 1 表示确认出现，0 表示在该标注中确认未出现，−1 表示未知，未知项不能当作负样本。文本端把事件名转换成固定查询句，例如 “does this recording contain siren?”；模型输出该查询与音频是否匹配的分数。主指标是 macro-AUPRC，因为事件类别不均衡；AUROC、固定验证阈值下 macro-F1 和 balanced accuracy 作为辅助指标。

第一阶段使用固定词表和 log-mel 音频前端，避免 Qwen 冻结特征把电子模型能力混入光学比较。音频前端和文本编码在 MoE/D2NN 之间完全共享。

## 4. 每个任务的统一训练流程

1. 固定版本、下载 URL、许可证、文件哈希和样本清单。
2. 只用训练集估计归一化统计量和词表；验证集用于 checkpoint/阈值选择；测试集在选择完成后只评估一次。
3. 用同一输入张量、同一 OEO、同一衍射层数、同一优化器和训练轮数分别初始化 MoE 与 D2NN。
4. MoE 额外保存每个样本四个专家的路由功率；D2NN 的四个区域固定均分输入功率。两者的读出窗口、零读出处理和指标计算完全相同。
5. 记录 train/validation/test 指标、预测、读出能量、路由统计、参数量、GPU UUID、软件版本和 manifest 哈希。

当前正式主实验顺序：先完成 SEN12MS 固定子集的图图实验，再完成 SONYC-UST 音文子集，最后用同一 OEO 和训练预算重跑 CLEVR 图文。任何仅有 train/validation 或未取得原始模态文件的结果都标为 smoke/pilot。
