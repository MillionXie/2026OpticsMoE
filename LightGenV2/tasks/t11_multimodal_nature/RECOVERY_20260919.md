# 2026-09-19 实验恢复与更正

## 对旧结论的更正

1. 原 `enlarge_tiles` 对已经组织好的输入的各模态区域分别上采样、拼回整幅光场，**没有复制四份完整输入**。旧 D2NN 已使用一块 478×478 首层相位面；`route()` 返回的四个 0.25 是未参与 D2NN forward 的兼容占位值。此前“四区域空间复用 baseline”的文字判断错误，应撤回，不据此作废 CLEVR 已有结果。
2. `cae9b957` 改动是“模态区域分别最近邻插值”改为“整幅输入双线性插值并归一化”，不是从四专家改成单孔径。新 D2NN 仍是一张组织好的输入光场，只上采样一次，单孔径传播。
3. 旧 SONYC 评估器的 `macro_auprc` 实为所有事件查询合并后的 AP，`macro_f1` 实为二分类正类 F1；旧标注构建还把不同标注者的记录重复计入。旧结果只保留追溯，不能作为标准 SONYC 指标。
4. `sonyc_audio0_standard_d2nn_s17_20260919` 在创建输出目录时退出，未训练。不能把这个目录或启动 PID 当作训练完成证据。

## 本轮已固定协议

- CLEVR 暂停改动，保留原有独立结果。
- SONYC audio-0：714/259/27 段训练/验证/测试录音；每段8个事件查询。优先使用 annotator_id=0 的一致性标注；其他训练/验证录音使用志愿者多数投票，未知和票数相同不猜标签。测试只使用一致性标注。该子集测试只有27段录音，不是全量SONYC基准。
- 声音：48kHz抗混叠重采样到16kHz；完整10秒声谱，64个mel频带，512点FFT、400点窗口、160点步长；80dB动态范围；调整到224×112。文本固定词位置one-hot（32×64）最近邻映射到224×112。左右各0.5入射功率。无CNN、无训练文本前端。
- SONYC 按训练集中每个事件的正负频数构造损失权重；MoE/D2NN共用。验证逐事件AP的平均值选checkpoint；阈值只用验证集选取。保存逐事件AP、AUROC、F1以及各类正例数；无正例类别AP标记为空，并报告纳入平均的类别数。
- SEN12MS：只使用已有春季包，官方简化IGBP单标签；按场景隔离训练、验证和官方hold-out测试。场景和patch按seed17的固定哈希排序抽样，每场景最多128个patch，不按模型结果挑样本。完整名单见selection.json。不得把此子集说成全量SEN12MS。
- SEN12MS输入：SAR双极化裁剪到[-25,0]dB并缩放；S2选B4/B3/B2/B8，固定反射率缩放[0,10000]；无CNN。SAR两通道排列为左半幅，S2四通道排列为右半幅，各0.5功率。10个探测窗口单标签分类，验证macro-F1选checkpoint。
- 两任务均固定：2层主衍射、每层OEO、17µm采样、224专家/478完整孔径/518传播画布/30间隔、phase dropout=0.05、Adam学习率0.01余弦降到0.001、batch32、30epochs、seed17。MoE四专家，批平均功率均衡项系数0.02；D2NN无router参数且路由统计为null。
- OEO明确为：强度/空间均值→无仿射LN→LeakyReLU(0.1)→Softsign→单位L2归一化→下层复振幅。允许负值，对应π相位，不称为非负振幅或纯强度调制。
