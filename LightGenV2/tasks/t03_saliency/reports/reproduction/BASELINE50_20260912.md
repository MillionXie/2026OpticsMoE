epoch80选出的头，不能当成本次50 epoch训练结果。

## 已准备的冻结主干方案

`qwen_aligned_head_50.yaml`：预训练Qwen视觉主干冻结，适配器与读出头从随机初始化训练50 epoch，
不是载入旧100 epoch读出头再额外训练50 epoch，也不是解冻Qwen主干。
已向用户明确该口径后，先开展与历史baseline一致的保守重训。
是否另外解冻主干仍等待用户确认；后者必须另列为主干微调baseline。

读出头与正式光电模型使用同一个 `SaliencyDensityDecoder(192,224)`，85412参数。
Qwen后接适配器197184参数，合计训练282596参数。冻结主干执行原生24层Vision Transformer；
光电模型不因此增加任何Transformer。全网络参数、预训练知识与历史优化预算并不相同。

```bash
python -m LightGenV2.tasks.t03_saliency.aligned_baseline \
  --config LightGenV2/tasks/t03_saliency/configs/qwen_aligned_head_50.yaml \
  --run-dir LightGenV2/tasks/t03_saliency/runs/simulation/qwen_aligned_head_50_20260912_seed42 \
  --seed 42
```

仅在GPU预算允许时运行，不以本冻结方案代替用户尚未确认的主干微调方案。新run不得覆盖历史baseline。
学习率明确使用task_training：adapter 1e-4、decoder 3e-4，前5轮冻结adapter更新，
第6–35轮联合训练，第36–50轮低学习率收敛。原始预处理、标签、指标实现不变，
SALICON train10000/public-test5000，epoch1/每5轮/最后测试选最高CC；披露测试选模偏差。
默认只保存best和last，结束后重载best完整评估。DataLoader使用spawn，避免继承父进程CUDA上下文。

- 光router Top2，alpha下界0.4，冻结前端，不加入attention、Transformer或额外推理分支。
- 478 ROI、17微米、10 cm、原来的专家布局及训练直流扰动不变。
- 完整5000张的身份、CC算法及归一化保持一致；不裁选高分测试图，不据真值拟合后处理。
- 训练时教师监督只能访问train缓存；辅助训练模块如有不得意外出现在推理中。
- 检查非有限损失、相位是否更新、alpha、专家选择分布以及训练/测试分化。

- 新best需记录SHA256并独立完整复评；变化很小的单次测试不直接替换正式交付候选。
