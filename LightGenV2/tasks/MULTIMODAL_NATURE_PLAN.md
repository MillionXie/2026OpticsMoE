# 多模态 MoE/D2NN 主实验规划

本文档定义后续论文主结果的任务、数据、模型、训练和证据保存规则。历史实验只作为 pilot 或故障诊断，不与主表混用。

## 主实验任务

|任务|主数据集|模态|建议任务形式|许可状态|当前状态|
|---|---|---|---|---|---|
|图图|SEN12MS|Sentinel-1 双极化 SAR + Sentinel-2 多光谱|配对跨传感器场景分类/匹配|CC BY 4.0，需保留数据集逐文件归属|待准备|
|图文|CLEVR v1.0|RGB图像 + 自然语言问题|组合式属性/计数问题，固定答案空间|官方 CC BY 4.0|已有 pilot，需统一 OEO 后重训主配置|
|音文|SONYC-UST v2.3|城市环境音 + 事件文本查询|多标签事件查询匹配|官方 CC BY 4.0，缺失标签不当负例|待实现|

Speech Commands 只作为音文 smoke 和小规模复现对照，不作为最终多模态主证据：它是有限关键词匹配，当前 CNN 版已经把识别任务大部分交给冻结电子前端，论文说服力有限。工程中的 EuroSAT RGB/SAR 试验登记为 MIT 许可，也不进入 CC BY 4.0 主表。

数据集来源和许可登记：

- SEN12MS: https://github.com/schmitt-muc/SEN12MS ，论文/发布说明明确为 CC BY 4.0；数据包含约180,662个对应的 Sentinel-1 SAR、Sentinel-2 多光谱和土地覆盖标注三元组。
- CLEVR: https://cs.stanford.edu/people/jcjohns/clevr/ ，官方页面明确所有数据为 CC BY 4.0。
- SONYC-UST v2.3: https://zenodo.org/records/3966543 ，以发布页面的 CC BY 4.0 和 CSV 中的标注字段为准；训练前保存页面、下载文件和 CSV 的 SHA256。

许可审查不是只检查代码仓库许可证。每个数据集必须保存原始页面、LICENSE/README、下载 URL、版本或 DOI、文件 SHA256、作者归属和本项目的处理修改说明。若某一音频或图像文件带有比数据集总许可更严格的单文件许可，排除该文件或单独记录，不能直接继承总许可。

## 统一模型合同

三个任务都使用同一物理模型合同，避免通过任务专用结构制造差距：

```text
模态 A -> 每模态独立归一化到总输入功率0.5
模态 B -> 每模态独立归一化到总输入功率0.5
        -> 224×224 输入场，初始相位为0
        -> MoE: 四个224×224专家，间隔30像素，路由功率q_i，四路相干传播
           D2NN: 同一输入分区分别上采样覆盖478×478全孔径
        -> 两层主衍射层；每层传播后相同OEO
        -> 固定CCD窗口/类别窗口读出
```

仿真采样为17 μm；专家逻辑尺寸224像素、专家间隔30像素；后续部署映射到8 μm相位器件。MoE和D2NN共享层数、传播距离、有效孔径、输入功率、读出窗口、训练划分、优化器和候选超参数范围。MoE额外的路由相位必须单独报告，不能宣称严格参数量相等。

主实验先固定 OEO 为 centered LeakyReLU：

```text
I = |E|²
u = I / mean(I)
z = LayerNorm(u; no affine parameters)
v = LeakyReLU(z, slope=0.1)
s = Softsign(v)
振幅 = s / ||s||₂，输出相位清零
```

该版本保留原来的平方探测和 LayerNorm 结构，同时避免 ReLU 硬死区。所有三个主任务使用同一 OEO。非中心化 intensity Softsign、Softplus 和原始 ReLU 只能作为预先登记的 OEO 消融，不能在看过测试结果后按任务选择。

## 各任务输入和输出

### 图图：SEN12MS

以地理区域为单位划分 train/validation/test，禁止同一地理区域或重叠 patch 跨集合。SAR 使用两个极化通道，光学使用固定选择的多光谱通道；两模态分别做训练集统计的通道归一化，再映射为非负振幅。主任务先做10类土地覆盖分类，使用10个固定读出窗口、交叉熵、macro-F1 和 balanced accuracy；另保留同场景正配对/错配负配对作为二分类 sanity check。二分类结果不能代替10类主结果。

### 图文：CLEVR

不再只使用当前的颜色/形状二分类 pilot 作为主结论。主配置从官方问题中固定一组可复现的属性、计数和比较问题，答案空间在训练集确定并在测试集固定。RGB经过共享冻结 CNN 仅作为一个预注册前端候选；同时保留无 CNN 版本，防止电子前端成为主要性能来源。MoE/D2NN必须使用同一个冻结 CNN checkpoint或同时使用原始RGB，不能一方使用电子预训练而另一方不使用。

### 音文：SONYC-UST

从训练标签构造有限事件查询，例如“是否包含 dog / siren / engine”等。多标签样本中标签为1才构造正例，标签为−1的未知项不构造负例。主指标为 macro-AUPRC、每类 AUROC、balanced accuracy 和验证集固定阈值下的 macro-F1；普通 accuracy只作为辅助指标。音频使用固定 log-mel 前端，文本使用固定词表 one-hot 作为第一版，后续再单独比较小型可训练文本编码器。不能使用 Qwen 冻结输出作为唯一输入证据。

## 训练和公平性

每个任务先做 smoke：输入尺寸、两模态0.5功率、总功率、OEO梯度、路由梯度、读出非零比例、类别窗口不重叠。正式训练使用固定 seed17 完成协议验证，再对预注册代表配置补 seed23/41；每个 seed 都训练一对 MoE/D2NN。

验证 NLL 或验证集主指标只用于选择 checkpoint、阈值和早停；测试集在选择后只评估一次。每个模型保存 best/last checkpoint、完整 train/val history、test prediction、逐样本 route_power、读出能量、零读出比例、参数量、训练命令、GPU UUID、Git commit、Python/PyTorch/CUDA 版本和数据 manifest SHA256。

专家报告同时包括 route_mean、route_std、route_top_frequency、路由熵和单专家屏蔽消融。均衡损失不是默认项；若进入消融，预注册 λ∈{0.05,0.2}，MoE和D2NN仍使用同一数据和优化预算，不能把均衡路由本身当作性能目标。

## 进入论文主表的最低条件

1. 数据许可证和逐文件归属可复核；
2. train/val/test 地理或说话人/录音身份无交集；
3. MoE、D2NN使用同一输入张量、OEO、读出、训练预算和测试 checkpoint 选择规则；
4. 至少一个独立测试集结果，且不是根据测试分数选择的；
5. MoE优势在至少两个 seed 或预注册的代表任务上重复；
6. 优势不能来自D2NN欠拟合、弱正则或不同的电子前端；
7. 同时报告失败配置、专家利用率、零读出和训练—测试差距。

在上述条件全部满足前，任何“MoE在多模态上优于D2NN”的表述都只能称为 pilot 观察，不能写成主结论。
