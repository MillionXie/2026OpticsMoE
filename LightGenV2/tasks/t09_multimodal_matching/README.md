状态：实现与可行性验证中；无正式性能结论。复现入口为
[`reports/reproduction/README.md`](reports/reproduction/README.md)。

只比较两层主光路的 MoE+逐层OEO 与 D2NN+逐层OEO；MoE额外路由相位单列。
首先比较 CLEVR 图文任务中的固定词编码与共享可训练 Embedding+GRU；

## 数据合同

原始图像与场景标注来自官方 CLEVR v1.0 ZIP：
https://dl.fbaipublicfiles.com/clevr/CLEVR_v1.0.zip 。
原始许可为 CC BY 4.0，依据 https://cs.stanford.edu/people/jcjohns/clevr/ 。
HTTP Range 仅下载本轮需要的成员；每个成员校验ZIP CRC32并记录解压内容SHA256。
图像不经第三方模型生成，不输入物体列表或场景标签给网络。

本轮是 **CLEVR 派生的颜色+形状存在性任务**，不是官方全量CLEVR问答成绩。
从官方train图像中按固定ID范围取得1500张，再按seed17划分1000训练、250验证、250保留测试。
每张图像从场景中出现的颜色-形状组合选3个正查询，未出现的组合选3个负查询；
同一图像问题均属于同一划分。自然语言模板固定，不根据模型分数筛选数据。
测试只保存文件身份，本轮不加载测试图像或测试预测。标注用于生成答案，不参与前向。
独立图像数量与问答数量分开报告；问答间共享图像，不能假设为独立样本。

## 输入与比较

RGB三个通道保留；文字按小写词及标点分词，仅用训练集建立词表。
固定编码：带词序的one-hot，补零到32词×64维。
学习编码：32维Embedding+单层32维GRU，保留全部位置，正负分开为32词×64维。
词序和特征单元使用最近邻扩展到112×112，禁止缩小文本格点、混合相邻词值。
两种文本编码使用相同物理槽位。文本与图像各占主路总入射功率的1/2。
相同编码配置下，MoE与D2NN使用逐参数相同的冻结前端。

学习前端预热同时连接两个光学模型，优化二者NLL的平均值；以二者平均验证NLL选前端。
随后冻结同一个前端、重新初始化两种光学网络进行正式预实验。
该前端由任务监督训练，不宣称电子部分没有任务学习。
固定编码不需要前端预热；额外预热成本单独记录。

层数暂固定两层。不根据测试集差距选层数或修改baseline；编码依据两模型验证性能和
泛化情况选择，不保证任何性能排序。仅本预实验通过后再决定正式规模。

## 光学与训练参数（预实验，未硬件验证）

图像统一从原始RGB缩放为64×64（整图拉伸，无裁剪），三个通道各扩展到112×112；
与112×112文本组成[R,G;B,text]，RGB合计0.5功率、文本0.5功率，总主路入射功率1。
MoE四个224×224专家均接收该完整多模态场，入口功率由额外路由相位测量确定。
D2NN将四个编码区分别最近邻扩展到239×239，保留各区功率，覆盖478×478相位面。
两者均为518×518角谱传播画布、17µm像素、532nm波长，两段传播各0.1m。
MoE可训练相位479,364个（含路由50,176个），D2NN456,968个；不是严格等参数比较。

每个主衍射层传播后：截取478×478有效面，强度除空间均值，非仿射LayerNorm(eps1e-5)，
ReLU、Softsign，重新归一化为单位功率振幅并清零相位。该过程需要电子处理和再调制，
不声称被动能量守恒；数值无传感器噪声，路由测量的额外能耗未建模。
最后两个64×64窗口中心(y,x)=(259,179)/(259,339)，归一化能量形成二分类概率。
全程无电子输出旁路、不输入场景标注、无Qwen。

seed17，batch32；学习前端预热8轮，Adam电子lr0.001/光学lr0.01。
冻结后每个模型12轮，Adam光学lr0.01余弦降至0.001，梯度范数裁剪1，无数据增强。
验证NLL最低选模，不访问保留测试图像。预热光学权重丢弃，正式两组重新初始化。
模型与前端原始检查点、每轮同权重完整训练/验证指标、预测、路由统计均保存。
图像/文本输入比与OEO参数当前固定，尚未通过验证调优。

运行入口：`python -m LightGenV2.tasks.t09_multimodal_matching.run --phase smoke|train
--data /path/to/prepared --out LightGenV2/tasks/t09_multimodal_matching/runs/smoke|simulation/UNIQUE_ID`。

## 共享视觉前端诊断（独立run，保留原始RGB结果）

直接RGB输入的首轮验证接近50%，不能据此确定文本编码优劣。
补充一次共享视觉特征实验：CNN包含16/32/64通道的Conv3-BN-ReLU-Pool，
接64→128的1×1卷积、ReLU和全局平均池化。临时128→24分类头预测颜色-形状组合是否存在，
仅在训练问答提供的正负查询上计算BCE；无未标注类别的伪负标签。
60轮AdamW，lr0.001余弦到0.0001，wd0.0001，每批32图像，水平翻转；验证NLL选模。
该电子辅助任务使用结构化查询索引选取24输出之一，仅用于预训练和诊断。
正式光学模型不接收该索引或24个logit，只接收去掉分类头后的同一冻结128维特征。

128维按16×8排布，最近邻扩展成112×112，在三个原图像槽位重复并合计归一到0.5功率；
重复不增加信息，空间布局已被GAP丢弃。本次任务只问全图属性是否存在，不支持空间关系结论。
三槽重复是对当前四区接口的适配，尚未优化排布。文本槽位、主光路与训练预算保持原方案。
全部四个光学对照使用逐位相同的视觉特征；共享CNN与两种文本编码的额外训练成本单列。
两种文本编码仍各自包含同一MoE/D2NN共享的文本前端。

针对稀疏性混杂追加`fixed_dense`：固定32×32 Sylvester Hadamard矩阵，训练词表ID选择一行，
以正负分开得到64维非负码，保留32个词位置。零可训练参数，码字两两正交；
smoke校验词ID精确可恢复。该码不含语义预训练，只调整表示密度。
与GRU相同，每个非补齐词的64维中32维非零。与one-hot使用同一槽位、功率和训练预算。
这用于区分表征学习与光场稀疏性的影响，不能单凭one-hot对比归因于语义能力。

## 已确认的几何、编码和评估协议

输入及传播逻辑采样17 µm；专家224×224，间隔30逻辑像素；有效面478×478，传播画布518×518。后续部署目标为8 µm相位SLM，按物理尺寸映射；当前只做逻辑网格仿真。完整多模态输入224×224匹配单个专家，D2NN分区上采样覆盖478×478并保持各区功率。

one-hot编码完整句子的每个词及问号，不只提取颜色。词表由训练句子建立，共26项（含PAD、UNK）；每词64维，按词序排列并补齐32词。PAD行全零，再最近邻扩展成112×112文本槽。不同句子按词查表即可，不需整句注册。数据仅4种模板、8种颜色和3种形状，不能等同开放域语言理解。

原数据划分为1000训练图像、250验证图像、250保留测试图像；每图6问，正负平衡。训练只使用训练/验证数据。首次测试在按最低验证NLL锁定6个检查点后进行，不按测试成绩选择轮次。测试结果已观察，后续泛化对照不再次访问测试。完整结果与权重SHA见复现入口。

保留原固定one-hot＋共享CNN版本。视觉CNN保留32,128参数，临时24输出头3,096参数，仅预训练时使用；预训练60轮，按验证NLL选权重，随后冻结。输出128维，光学网络训练12轮。原MoE最佳第7轮；D2NN原最佳第12轮，尚有训练不足可能。

## 泛化与训练预算对照

已完成低学习率0.003、特征dropout0.1、水平翻转、翻转加dropout四组12轮对照。两架构使用相同增强及预算；未找到同时明确提高准确率和缩小泛化差距的配置。特征dropout仅作用于训练时128维视觉特征，随后重新功率归一化；水平翻转仅用于颜色/形状存在性图文任务，不能直接用于音频。

追加30轮从头训练对照：lr0.01余弦降至0.001，无phase dropout；相同预算加phase dropout0.05。余弦周期同步改为30轮，因此不是原12轮检查点直接续训。phase dropout为主光路8×8块随机旁路相位，透射率仍为1，不做幅度dropout，不乘1/(1-p)。每批共享掩码、各相位面独立；训练开启，完整训练/验证评估关闭。MoE额外路由板不施加此正则。每个配置均训练MoE与D2NN，以最低验证NLL选模，测试不参与。

## 音文预实验准备

数据为官方mini Speech Commands（8个关键词，CC BY 4.0），来源https://storage.googleapis.com/download.tensorflow.org/data/mini_speech_commands.zip ，许可在压缩包README内再次核验。按文件说话人前缀SHA1分桶为训练/验证/测试，去除重复波形，断言说话人集合互斥。

任务：语音与文字关键词是否匹配，每条音频生成1个正问题和1个固定负问题。完整句子one-hot，非转录模型输出。音频16 kHz单声道，右侧补零到1秒；512点STFT、400点Hann窗、160点步长；64个20–8000 Hz HTK-mel三角滤波器，保留64×101时频图。以每段最大能量为0 dB，截取80 dB动态范围映射到uint8；复制3通道仅兼容现有CNN接口，不增加信息。后续共享小CNN需在音频训练集重新训练并冻结，不复用图像训练权重。该任务为有限词汇匹配，不能表述为一般语音理解。数据准备入口audio_prepare.py，音频分类/光学性能尚待实际训练。

30轮结果已完成：不加phase dropout的D2NN达到72.13%验证准确率，原12轮对照训练不足。5% phase dropout的MoE达到73.13%，但同一设置的D2NN受损，须保留强D2NN作为比较。音频数据与共享前端已准备完成，详细证据见复现入口。
