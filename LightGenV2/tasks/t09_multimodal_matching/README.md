状态：实现与可行性验证中；无正式性能结论。复现入口为

只比较两层主光路的 MoE+逐层OEO 与 D2NN+逐层OEO；MoE额外路由相位单列。
首先比较 CLEVR 图文任务中的固定词编码与共享可训练 Embedding+GRU；

## 数据合同

原始图像与场景标注来自官方 CLEVR v1.0 ZIP：
https://dl.fbaipublicfiles.com/clevr/CLEVR_v1.0.zip 。
原始许可为 CC BY 4.0，依据 https://cs.stanford.edu/people/jcjohns/clevr/ 。
HTTP Range 仅下载本轮需要的成员；每个成员校验ZIP CRC32并记录解压内容SHA256。
图像不经第三方模型生成，不输入物体列表或场景标签给网络。

本轮是 **CLEVR 派生的颜色+形状存在性任务**，不是官方全量CLEVR问答成绩。
从官方train图像中按固定ID范围取得1500张，再按seed17划分1000训练、250验证、250保留测试。
每张图像从场景中出现的颜色-形状组合选3个正查询，未出现的组合选3个负查询；
同一图像问题均属于同一划分。自然语言模板固定，不根据模型分数筛选数据。
测试只保存文件身份，本轮不加载测试图像或测试预测。标注用于生成答案，不参与前向。
独立图像数量与问答数量分开报告；问答间共享图像，不能假设为独立样本。

## 输入与比较

RGB三个通道保留；文字按小写词及标点分词，仅用训练集建立词表。
固定编码：带词序的one-hot，补零到32词×64维。
学习编码：32维Embedding+单层32维GRU，保留全部位置，正负分开为32词×64维。
词序和特征单元使用最近邻扩展到112×112，禁止缩小文本格点、混合相邻词值。
两种文本编码使用相同物理槽位。文本与图像各占主路总入射功率的1/2。
相同编码配置下，MoE与D2NN使用逐参数相同的冻结前端。

学习前端预热同时连接两个光学模型，优化二者NLL的平均值；以二者平均验证NLL选前端。
随后冻结同一个前端、重新初始化两种光学网络进行正式预实验。
该前端由任务监督训练，不宣称电子部分没有任务学习。
固定编码不需要前端预热；额外预热成本单独记录。

层数暂固定两层。不根据测试集差距选层数或修改baseline；编码依据两模型验证性能和
泛化情况选择，不保证任何性能排序。仅本预实验通过后再决定正式规模。

## 光学与训练参数（预实验，未硬件验证）

图像统一从原始RGB缩放为64×64（整图拉伸，无裁剪），三个通道各扩展到112×112；
与112×112文本组成[R,G;B,text]，RGB合计0.5功率、文本0.5功率，总主路入射功率1。
MoE四个224×224专家均接收该完整多模态场，入口功率由额外路由相位测量确定。
D2NN将四个编码区分别最近邻扩展到239×239，保留各区功率，覆盖478×478相位面。
两者均为518×518角谱传播画布、17µm像素、532nm波长，两段传播各0.1m。
MoE可训练相位479,364个（含路由50,176个），D2NN456,968个；不是严格等参数比较。

每个主衍射层传播后：截取478×478有效面，强度除空间均值，非仿射LayerNorm(eps1e-5)，
ReLU、Softsign，重新归一化为单位功率振幅并清零相位。该过程需要电子处理和再调制，
不声称被动能量守恒；数值无传感器噪声，路由测量的额外能耗未建模。
最后两个64×64窗口中心(y,x)=(259,179)/(259,339)，归一化能量形成二分类概率。
全程无电子输出旁路、不输入场景标注、无Qwen。

seed17，batch32；学习前端预热8轮，Adam电子lr0.001/光学lr0.01。
冻结后每个模型12轮，Adam光学lr0.01余弦降至0.001，梯度范数裁剪1，无数据增强。
验证NLL最低选模，不访问保留测试图像。预热光学权重丢弃，正式两组重新初始化。
模型与前端原始检查点、每轮同权重完整训练/验证指标、预测、路由统计均保存。
图像/文本输入比与OEO参数当前固定，尚未通过验证调优。
