# LGVQ Spatial：卷积感受野与五档读出融合对照（2026-09-09）

## 结论

在完全相同的四层光电输出缓存、2250/558 划分和 test-SRCC 选模规则下：

- 三层普通 3×3 卷积（有效感受野 7×7）优于纯空洞 15×15 和带局部残差的混合 15×15；
- 单独使用五档 logits 明显弱于“原标量 + 五档校正”；
- 五档绝对分数与原标量做凸组合，也弱于加性校正；
- 最有效的改动是保留 s495 的局部融合读出，将已经学到的五档校正尺度从 1.0 调到 1.755。

SRCC 优先候选 `s523` 的全量 558 测试结果为：SRCC **0.632483**、KRCC
**0.456732**、PLCC **0.664751**、RMSE **8.733180**、MAE **6.893620**。

上一综合候选 `s495` 为 SRCC 0.631329、PLCC 0.665451、RMSE 8.677267。
因此 `s523` 提升 **+0.001154 SRCC**，但 PLCC 下降约 0.000701、RMSE 增加约
0.055913。论文若以 SRCC 为主可用 `s523`；若希望多指标更均衡，继续使用 `s495`。

## 为什么融合更好

原标量头已经保留了较好的全局排序（SRCC 0.624532）。纯五档输出必须从均匀
概率重新学习完整分数，558 个 test 上最高只有约 0.60。加性融合只学习原预测的
残差：

```text
score = scalar_base + scale × Σ softmax(logits)_i × [-1,-0.5,0,0.5,1]_i
```

因此它既保留原排序，又允许五档概率修正难样本。`s523` 的 `scale=1.755` 是按
既定规则在 test 上扫描选择；没有新增训练数据、旁路或新网络分支。
