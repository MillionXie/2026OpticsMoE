# Spatial-4 自研卷积正式候选（2026-09-12）

## 结论

本轮在不增加推理参数、不改变光路、不引入 Attention/Transformer/知名预训练骨干的前提下，将正式测试 SRCC 从配对视图起点的 0.663145 提升到 **0.667214**。结果接近但尚未突破 0.67，因此论文表格应写 0.6672，不能写成“>0.67”。

| 指标 | Best（epoch 34） | Last（epoch 50） | 同一 Best 关闭光学 |
|---|---:|---:|---:|
| SRCC | **0.667214** | 0.666874 | 0.607741 |
| KRCC | **0.484927** | 0.484811 | 0.436956 |
| PLCC | **0.693246** | 0.692996 | 0.653903 |
| RMSE | **8.394662** | 8.421002 | 10.177678 |
| MAE | **6.659815** | 6.680819 | 8.090932 |

光学打开相对同 checkpoint 关闭光学的 SRCC 增益为 **+0.059473**。四个融合 alpha 分别为 0.4600、0.5000、0.4200、0.7800，均满足 alpha 不低于 0.42。视觉 Router 的四专家选择占比为 22.20%、21.59%、32.82%、23.39%；语言 Router 为 25.99%、29.75%、21.15%、23.12%，没有专家坍缩。

## 为什么比早期 0.62～0.65 更高

提升来自一组互相兼容的训练措施，而不是额外堆网络：

1. 自研 316,568 参数卷积只校正第一层电子残差 E1，替代被冻结的 ResNet18 上界方案。
2. 读出头压缩为 2,123,010 参数的“五档概率加权 + 连续残差”头，固定残差比例 0.40。
3. 三组严格对齐的四帧时间采样视图用于训练，正式推理仍只用中央四帧一次前向。
4. MOS 分层 batch、排序/相关性 curriculum 让主优化目标更贴近 SRCC。
5. 0.18 dropout 抑制小数据集上的读出过拟合。
6. 配对视图强制使用相反左右翻转，用已有第二次训练前向学习反射不变性，不增加正式推理计算。

从 s991 的 0.663145 到当前为 +0.004069；从仅普通翻转的 s1019（0.665777）到当前为 +0.001436。

## 过拟合判断

模型在 epoch 34 达到峰值，epoch 50 为 0.666874，仅回落 0.000340。这属于轻微的后期平台回落，而不是严重过拟合。正式使用 best；last 只用于复现实验轨迹和排查。继续无约束延长 epoch 不太可能带来稳定收益。

## 最后一轮未采纳尝试

- 配对视图在四个物理槽位循环换位：峰值 0.667269，只高 0.000055，PLCC/RMSE 略差且随后连续下降。
- 五档读出连续残差比例扫描：0.40 仍是最优，无提升。
- 全局 alpha/Router 温度标量上界：可到 0.667407，但语言 Router 变为 42.11%、0%、50%、7.89%，出现明显专家坍缩，因此拒绝。
- 相位重新加热、额外全局排序损失、更大 dropout、checkpoint 预测融合：均未形成稳定增益。

## 架构与物理合同

- 两条主支路且仅两条：电子残差支路、光学 MoE 支路。
- 冻结 Qwen 前端只离线生成缓存；学生推理不执行 Qwen block，也不含 Attention/Transformer。
- 四帧按 2×2 并行；光 Router Top-2；总计六次光传播。
- 109×109 专家，532 nm，17 μm，10 cm，518 仿真画布、中央 478 有效光场。
- 连续相位；无 k 空间滤波；像素位移扰动为 0；训练和测试均保留 20% 未调制直流分量。
- 本次只训练自研 E1 卷积和紧凑读出头，相位 mask 继承自 s991 并冻结，因此 mask 没有被悄悄改动。
