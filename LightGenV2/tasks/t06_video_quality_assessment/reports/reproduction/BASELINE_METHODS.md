# 01｜视频质量评价（LGVQ）

**数据处理。** 使用 LGVQ 的 2,808 条视频及对应时间质量、空间质量 MOS。按生成提示词分组，每组包含六种生成器产生的视频；将 468 组排序后以种子 42 打乱，取 375 组用于训练、93 组用于测试，共 2,250/558 条视频。同一提示词的六条视频分配至同一集合。两项质量评价均在视频时长的 10%、37%、63% 和 90% 位置抽取四帧，每帧中心裁取边长为原图短边 65% 的正方形，再以面积插值缩放至 448×448，按时间顺序组成视频输入。

**模型与评分。** 采用 Qwen3-VL-2B-Instruct，冻结完整视觉和语言主干，使用原生多模态对话模板。输入指令为 “Please evaluate the temporal quality of this video and rate it using one of the following five levels: Excellent, Good, Fair, Poor, or Bad.”；空间质量仅将 temporal 替换为 spatial。取最终语言层最后有效 token 的 2,048 维表示，接无偏置的五分类线性评分头。五行权重分别从 Bad、Poor、Fair、Good、Excellent 对应的预训练词表输出行初始化，独立训练，共 10,240 个参数；时间和空间质量各训练一个评分头。

**训练与评价。** 对每项质量，仅用训练集 MOS 的最小值 a 和最大值 b 确定五个等宽分类区间，使用硬标签交叉熵训练。时间质量的 [a,b] 为 [28.62,77.30]，空间质量为 [17.68,77.02]。推理时，令五档分值为 sₖ=a+k(b−a)/4（k=0,…,4），将五路 logits 经 softmax 得到的概率 pₖ 加权求和，得到连续预测分数 Σpₖsₖ。评分头使用 AdamW 训练 50 轮，batch size 512、学习率 0.001、权重衰减 0、余弦学习率衰减，种子 42。每轮按完整测试集 SRCC 选模，时间与空间分别选中第 45、39 轮，未设置独立验证集。最终以 BF16 主干、单视频推理评估全部 558 条视频，预测分数与对应 MOS 的 Spearman 相关系数分别为 **0.7663（时间）和 0.6908（空间）**。
