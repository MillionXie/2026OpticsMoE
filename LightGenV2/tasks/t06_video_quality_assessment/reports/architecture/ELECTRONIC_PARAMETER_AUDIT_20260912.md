# 时间/空间一致性电子参数核对（2026-09-12）

## 先纠正时间版本口径

当前时间一致性正式基线不是旧的“单视频 36 帧”模型，而是：

- 一个物理光场并行放置 16 个视频；
- 每个视频使用 4 帧；
- 六次光学传播，输出 16 个独立 Temporal MOS；
- 光 Router Top-2；
- checkpoint：`multivideo16x4_rank_s163/best_checkpoint.pt`；
- 558 个测试视频上的 SRCC 为 `0.804373`。

旧的 36 帧实验和它的指标不属于这条正式主线，后续表格、压缩和实验部署均不得混用。

## 时间一致性：16 视频 × 4 帧

### 原模型

| 模块 | 参数量 |
|---|---:|
| Qwen 边界适配器 | 674,140 |
| 四层电子残差 | 161,280 |
| 光学特征路径 | 874,233 |
| 光 Router | 107,920 |
| 同尺度融合标量 | 4 |
| 多模态桥接 | 74,688 |
| 位置参数 | 13,056 |
| 最终电子读出头 | 4,898,689 |
| **完整学生** | **6,804,011** |

电子规模过大的主要来源是最终读出头中的 `4096 -> 1024` 全连接矩阵，不是四层电子残差。

### 正式压缩候选

只把上述最大矩阵替换为两个普通 Linear 的 rank-256 分解，输入、光学层、Router、alpha、帧布局和输出语义均不变。

| 项目 | 原模型 | rank-256 |
|---|---:|---:|
| 读出头参数 | 4,898,689 | 2,015,105 |
| 完整学生参数 | 6,804,011 | 3,920,427 |
| SRCC | 0.804373 | **0.803303** |
| KRCC | 0.596799 | 0.595910 |
| PLCC | 0.818032 | 0.817091 |
| RMSE | 7.9911 | 8.0018 |
| MAE | 5.9921 | 5.9893 |

读出头减少 `58.86%`，完整学生减少 `42.38%`；SRCC 绝对下降仅 `0.00107`。因此 rank-256 是当前时间一致性的优选压缩版本。

## 空间一致性：单视频 4 帧

### 压缩链

| 方案 | 读出头参数 | 完整学生参数 | 完整测试 SRCC |
|---|---:|---:|---:|
| 原始 s1201 | 2,123,010 | 4,941,959 | 0.667214 |
| 第一阶段 s1291 | 1,565,570 | 4,384,519 | 0.666072 |
| **第二阶段 s1314** | **967,458** | **3,786,407** | **0.665487** |

s1314 已把读出头压到一百万以内。相对原始 s1201：

- 读出头减少 `54.43%`；
- 完整学生减少 `23.38%`；
- SRCC 只下降 `0.00173`；
- 同 checkpoint 关闭光路时 SRCC 为 `0.613057`，开启光路带来 `+0.052430`。

第二阶段没有平均压缩四个矩阵。实测发现紧凑校正子路径承担了较大的预测变化，因此预算优先保留其高能奇异方向；最终配置为：主输出宽度 144、主帧 rank 160、语言 rank 64、紧凑帧 rank 96、紧凑输出 rank 144。

## 合规边界

- 学生推理不执行 Qwen Transformer block；Qwen tokenizer、冻结 embedding 和冻结视觉前端只用于离线边界缓存。
- 学生只有电子残差和光学 MoE 两条主支路。
- 没有 Attention、Transformer、RNN 或命名预训练骨干。
- 两次压缩都只发生在所有光电层之后的读出头。
- 光学 mask、光 Router、Top-2、同尺度融合、alpha 和硬件 ROI 均继承，不因压缩改变。
- 指标使用 558 个固定测试视频，并按用户要求用周期性 test SRCC 选权重；没有另划 validation。
