# 时间/空间一致性电子参数审计（2026-09-12）

## 结论

- 时间一致性真正偏大的是最终读出头，不是四层电残差：读出头为
  `4,898,689`，占完整学生 `6,702,231` 的 `73.09%`；四层
  `electronic_routes` 仅 `161,280`（`2.41%`）。
- 原空间一致性读出头为 `2,123,010`，占完整学生 `4,941,959` 的
  `42.96%`。正式压缩候选把读出头降到 `1,565,570`（减少
  `557,440 / 26.26%`），完整模型 SRCC 仍为 `0.666072`。
- 压缩没有增加分支、Attention、Transformer 或预训练电子骨干；四层
  光学、光 Router、融合系数与相位 mask 完全继承。变化只发生在四个
  已有的后光学全连接矩阵，用截断 SVD 初始化的两层普通 Linear 表示。

## 时间一致性（36 帧，正式 balanced checkpoint）

参数来自 checkpoint
`temporal36_balanced_calibrated.pt` 的 settings 重建，checkpoint 的
`trainable_scope=all`。旧结果文件中的 `5,914,746` 是最终架构之前的
过时计数，正确的完整学生参数量是 `6,702,231`。

| 模块 | 参数量 | 占完整学生 |
|---|---:|---:|
| Qwen 边界适配（不含 Qwen block） | 671,232 | 10.01% |
| 四层电子残差 `electronic_routes` | 161,280 | 2.41% |
| 后光学读出头 | 4,898,689 | 73.09% |
| 多模态桥接 | 74,688 | 1.11% |
| 位置参数 | 25,344 | 0.38% |
| 14 通道输入适配 | 2,908 | 0.04% |
| 4 个融合标量 | 4 | <0.01% |
| 光学特征路径 + 光 Router | 868,085 | 12.95% |
| **完整学生** | **6,702,231** | **100%** |

时间读出头内部：

| 子模块 | 参数量 |
|---|---:|
| 帧 LayerNorm | 768 |
| 深度卷积 k=3 / k=5 | 1,152 / 1,920 |
| 时序 1x1 投影（768→512） | 393,728 |
| prompt 统计投影（576→512） | 296,576 |
| 最终 MLP（4096→1024→1，含 LN） | 4,204,545 |
| **合计** | **4,898,689** |

因此若以后压缩时间模型，应优先处理 `4096→1024`，不应先砍只有
16 万参数的电子残差。当前时间模型性能为 SRCC `0.845443`，本次只做
审计，未改其正式 checkpoint。

## 结构边界

Qwen 只在离线边界缓存阶段提供 tokenizer、冻结 embedding 与冻结视觉
patch/位置编码；学生推理图不执行 Qwen Transformer block。学生仍只有
电子残差与光学 MoE 两条主支路，最终读出只读取四层融合后的张量。
