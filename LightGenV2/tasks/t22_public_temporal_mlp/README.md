# LightGen2 temporal video quality reference

本目录是作者侧研究、核验与打包入口。独立推理工程位于仓库根目录
[`LightGen2`](../../../LightGen2/README.md)。详细用户说明为该目录的
`README.docx`。公开发行包只包含推理、结果绘图、选定权重和归一化RGB输入。

## 唯一推理流程

在独立工程中运行 `python infer.py`。默认读取 `data/test_rgb.npz`，
对558条不同视频的归一化RGB帧推理，按原顺序组成35幅16视频相干光场。
末组14条真实视频和2条循环填充。558条真实预测及人工标签参与SRCC统计。
同一次推理捕获其中一幅光场，默认第1幅，供绘图导出。`visualize.py`是辅助模块。

输入已完成四帧采样、65%中心裁剪、448×448缩放及RGB归一化。
patch投影、位置编码、固定汇聚和其余网络仍由推理源码执行。
NPZ采用float16容器保存原冻结前端bfloat16精度的归一化RGB。
逐场加载控制内存占用。正式发行目录中的`data`只含该NPZ。

## 打包顺序

1. 准备归一化RGB NPZ并核对558条身份及原视频SHA。
2. 在独立工程中完成一次全量推理，生成编号结果及完整程序时间。
3. 用`tools/build_public_guide.py`生成说明并完成逐页渲染检查。
4. 测试通过、提交并发布源码后运行`tools/build_release.py`。
5. 源码通过Git同步。权重、NPZ、Word及结果通过逐文件SHA核验同步。

公开结果依编号阅读。`01`为全部预测，`02`为指标及总运行时间，
`03`为全量预测散点图，`04`为选定光场四帧输入，`05`为558条专家份额，
`06–08`为完整vision相位及输入输出光场，`09–11`为language对应内容。
完整输入文件没有保存循环填充视频。填充只在推理末组中构建，统计时排除。

## 20261114额外候选与重复计时

按用户要求保留当前发布PT，新增`phase_reset_20261114`候选实验。
`configs/phase_reset_20261114.json`定义三个阶段，依次为80轮光学训练、160轮联合训练和
80轮路由及读出校准。第一阶段将两组raw相位参数置零，物理相位从π开始。
电子层以当前模型为初值，Qwen冻结前端和prompt继续复用。
阶段一固定电子层，后续优化已有光场编码器、language路由偏置与32单元读出头。
相位梯度及参数高斯平滑均设为0，旧相位锚定权重为0，周期曲率权重为0.002。
实际光学传播、图像尺寸和专家结构由现有模型执行。

重复计时使用`tools/benchmark_public_inference.py`。同一GPU UUID、CPU亲和性和四线程环境下，
先完整预热一次，再启动5个独立Python进程，各自读取全部NPZ、完成558条预测并导出相同图形。
逐次保存主程序用时、外部进程墙钟时间、预测SHA和GPU负载。主程序结束计时前显式同步CUDA。
发行ZIP的解压在计时外，输入NPZ内部数组的解压属于程序读取过程。
汇总报告中位数、标准差及最小和最大值，避免以两个单次记录判定稳定运行时间。

已完成同一源码、PT、NPZ和可视化第1场的交替配对测量。源码目录5次完整程序用时中位数
63.119611秒，范围54.770260–67.023171秒；独立解压目录中位数71.532914秒，范围
64.996876–72.778012秒。十次正式记录的558条预测逐字节相同。正式说明采用独立解压包
这组中位数，`results/02_metrics.json`来自其中实际的中位数运行。
两目录完整测量仍存在约13%的差异，采样期间A100由其他任务共享，输入存储使用mergerFS。
现有记录不足以将差异归结到单一因素。旧34.413秒及70.927秒属于单次历史记录，后者
选择可视化第35场，均保留在作者侧。配对测量原记录见`runs/smoke/runtime_paired_20261114`。

## 1%串扰目标与受光面积

后续候选使用`spatial_foreign_threshold=0.01`。逐视频能量比例超过阈值时施加惩罚，
达到阈值后停止该项惩罚。相应选模先检查精度和专家均衡，在两分支均达标后按SRCC选择。
逐视频照明审计仍使用整幅518×518画布传播，正式推理保持16视频相干联合传播。

`tools/analyze_spatial_coupling.py`执行冻结权重的敏感性对照。它逐视频保留传播后落入自身
探测区域的复光场，再核算原558条开发集。当前发布模型的联合传播SRCC为0.798371，
抑制跨视频光场后的SRCC为0.794527，差值为−0.003844，平均绝对MOS变化为0.6063。
这一对照说明整体排序指标变化较小。逐视频变化另保存在对照CSV中。

`tools/audit_mask_illumination.py`以`(sum I)^2 / sum(I^2)`核算入射光的有效面积，
分母为每视频111×111相位区域。当前发布模型的平均有效面积占比为vision 2.7392%、
language 1.0353%。新训练的`phase_reset_20261114/joint`候选分别为2.5681%、1.2200%。
该候选串扰已显著低于1%，相位平移1像素的最低SRCC为0.664698，需要继续改善对准鲁棒性。

`configs/phase_coverage_20261114.json`定义额外候选。它沿用现有输入映射，从raw相位参数0
开始训练，物理相位初始为π。新增训练目标约束现有输入区域内的光能分布，并加入±1像素
相位或CCD配准扰动。阶段依次为70轮光学训练、160轮联合训练和50轮路由及读出校准。
相位梯度和参数高斯平滑均为0。光学、编码器和读出层维度继续沿用当前模型。
该配置属于作者侧开发实验。三个阶段及全量推理、扰动和换位核验均已完成，
当前作为额外候选供审查。电子层从当前发布模型继续优化，相位在第一阶段重新置零。

## 相位图纹理范围的来源核查

旧版与新增候选的输入尺寸、映射位置和111×111相位区域相同。旧版本在本次训练前已
继承大范围相位纹理，其父模型记录了梯度高斯平滑σ=2.5和参数平滑σ=0.15；后续集中度
阶段还使用过梯度σ=2.0和参数σ=0.25。本次raw相位重新置零并关闭上述平滑，显著变化
主要集中在入射区域。未照明位置的相位可受继承和空间正则化影响，调制时该位置复光场为0。

`tools/audit_unilluminated_phase.py`将两支未照明位置的复调制统一改为1。
当前发布PT及新增候选各558条预测均逐值完全一致，最大MOS差为0，SRCC分别仍为
0.798371和0.798597。该核查解释了旧版大范围纹理与固定入射区域的关系。
原始对照见候选`review/phase_support_audit`，完整相位与输入区域对照图见
`review/phase_support/phase_support_comparison.png`。

## 旧版相位方案的1%泄露复核

按用户20261114后续要求，`configs/phase_legacy_leakage_20261114.json`从当前发布模型
`0d46a86e…`继续优化，继承旧相位和输入映射。相位采用旧方案的梯度平滑及弱参数平滑。
网络结构继续沿用当前32单元读出头、线性专家和两支整幅相干传播。

这轮同时核查各视频平均值、物理槽位均值和单视频最大值，最大值需严格低于1%。
训练使用0.6%的惩罚停止阈值，为逐样本核验留出余量。选模时对原558条开发集完成
逐视频照明审计，并分别将vision、language相位替换为常数π及各槽位圆均值相位。
两支学习相位相对各自较好的常相位对照均须有至少0.0005的SRCC差值。
SRCC仍须处于0.790–0.799，专家份额继续按总量及每槽位检查。
梯度仅使用2250条TRAIN，原TEST继续用于开发选模。该配置的结果以实际run记录为准。
