# LightGen2 temporal video quality reference

本目录保存作者侧研究、核验与打包工具。独立推理工程位于仓库根目录
[`LightGen2`](../../../LightGen2/README.md)，可编辑说明为该目录的`README.docx`。
公开发行包包含推理、结果绘图、选定权重和归一化RGB输入。

## 唯一推理流程

在独立工程中运行`python infer.py`。默认读取`data/test_rgb.npz`，对558条不同视频
按原顺序推理，组成35幅16视频相干光场。末组含14条真实视频和2条循环填充。
558条真实预测及人工标签参与SRCC统计。同一次推理捕获一幅光场，默认第1幅，
导出完整相位与输入输出复光场。`visualize.py`提供该入口调用的辅助函数。

输入已完成四帧采样、65%中心裁剪、448×448缩放及RGB归一化。
patch投影、位置编码、固定汇聚和其余网络由推理源码执行。
NPZ采用float16容器保存冻结前端bfloat16精度的归一化RGB，逐场读取。
末组循环填充在内存中构建，预测表、质量指标和专家份额统计均排除填充。

## CCD噪声训练与定义

本轮从受保护父模型继承权重，沿用32单元读出头、线性专家和两支整幅相干传播。
没有增加推理层。先后完成三个独立试验，均从同一父模型启动。

| 试验 | 训练轮数 | 结果 |
| --- | --- | --- |
| `ccd_noise_20261114/readout` | 100 | 仅微调读出头，噪声目标未全部达到 |
| `ccd_noise_20261114/joint` | 160 | 联合光学微调，5%噪声门槛未全部达到 |
| `ccd_noise_20261114/distillation` | 160 | 强化干净教师约束，第75轮冻结候选通过完整核验 |

最终配置为`configs/ccd_noise_distillation_20261114.json`。已有振幅编码器、相位、
读出头及language路由末层偏置参与优化。其他参数逐张量核验与父模型完全相等。
优化同时包含干净监督、带噪监督、干净教师一致性、相位正则、逐视频泄漏和路由均衡约束。
梯度仅使用2250条TRAIN。原始TEST的558条视频用于开发选模，指标按开发结果解释。

两支global的CCD噪声均加在平方律探测强度域，位于现有探测区域均值归一化之前。
训练参考强度固定为父模型的TRAIN平均探测强度，统计覆盖9000个vision帧区域和
2250个language区域。测试过程中参考强度保持固定。

读出噪声使用`max(I + r * I_reference * Normal(0,1), 0)`。
散粒噪声使用`Poisson(I * N / I_reference) * I_reference / N`。
参考强度处的相对标准差为`1/sqrt(N)`，5%和10%分别对应N=400和N=100。
混合条件下，高斯和Poisson在参考强度处各贡献总方差的一半，使总标准差仍为5%或10%。
局部像素的相对散粒噪声随光强变化。

Poisson前向使用实际计数采样，训练反向使用恒等直通梯度估计。该反向为梯度近似。
训练种类包含高斯、Poisson及混合噪声，参考水平覆盖5%、10%和12%。
训练中的带噪输入与干净输入成对计算，并以受保护父模型的干净TRAIN输出作为教师。
保留15%概率的±1像素配准扰动，梯度相位平滑尺度为1像素，相位参数平滑为0。
原有几何映射和掩膜覆盖范围保持原记录。

开发选模使用每条件3个噪声种子40301–40303。核心门槛同时包括干净SRCC
0.790–0.799、两支相位独立收益、专家份额和逐视频最大泄漏小于1%。
通过核心门槛后，按六种噪声条件中最小目标余量保留开发best。
最终冻结第75轮后另用29301–29310十个种子完整核验。
