# LightGen2 temporal video quality reference

本目录保存作者侧研究、核验与打包工具。独立推理工程位于仓库根目录
[`LightGen2`](../../../LightGen2/README.md)，可编辑说明为该目录的`README.docx`。
公开发行包包含推理、结果绘图、选定权重和归一化RGB输入。

## 唯一推理流程

在独立工程中运行`python infer.py`。默认读取`data/test_rgb.npz`，对558条不同视频
按原顺序推理，组成35幅16视频相干光场。末组含14条真实视频和2条循环填充。
558条真实预测及人工标签参与SRCC统计。同一次推理捕获一幅光场，默认第1幅，
导出完整相位与输入输出复光场。`visualize.py`提供该入口调用的辅助函数。

输入已完成四帧采样、65%中心裁剪、448×448缩放及RGB归一化。
patch投影、位置编码、固定汇聚和其余网络由推理源码执行。
NPZ采用float16容器保存冻结前端bfloat16精度的归一化RGB，逐场读取。
末组循环填充在内存中构建，预测表、质量指标和专家份额统计均排除填充。

## 相位收益与跨视频能量

逐视频照明审计使用与推理一致的整幅518×518传播算子。每次保留一个视频的输入，
统计落入其他视频探测区域的能量，再除以全探测面总能量。
完整558条真实视频逐一核验，末场两个填充光源另行检查。

| 分支 | 跨视频能量平均值 | 单视频最大值 |
| --- | --- | --- |
| vision | 0.2397425072% | 0.6743967533% |
| language | 0.2095943283% | 0.4984021187% |

两个分支的558条单视频最大值均严格低于1%。末场两个填充光源的最大值为
vision 0.2503216267%、language 0.2339780331%。两支均未出现暗光源。

以下对照固定其余权重，仅替换指定分支的学习相位。圆均值对照为每个槽位独立计算
常相位，0和π对照为统一常相位。原始逐视频结果和控制条件保存在私有核验目录。

## 本轮优化与选择口径

本轮继承旧版相位及固定输入映射，网络层和维度继续沿用32单元读出头、线性专家及
vision、language整幅相干传播。依次完成旧相位继承优化、逐样本泄露约束和配准扰动微调。
已有振幅编码器、相位、读出头及language路由偏置参与优化，冻结Qwen前端保持一致。
后两个阶段采用0.3%的训练惩罚停止阈值，为1%的逐视频验收目标保留余量。

梯度仅使用2250条TRAIN。原始TEST的558条视频用于开发选模。
选模须同时满足SRCC 0.790–0.799、两支独立相位收益、专家份额和逐视频最大泄露门槛。
最终阶段在这些门槛内，选择相位或CCD平移1像素共8种情况中最低SRCC最高的检查点。
配置记录在`configs/phase_legacy_registration_20261114.json`。

## CCD噪声与鲁棒训练核查

早期父模型`simplification_parent.pt`的训练记录及对应Git源码`6bfcbd925`一致，
实际启用了输入、相位及CCD的±1像素随机平移，以及标准差0.02 rad的相位高斯噪声。
其`phase_dropout`为0。后续`refine_spatial_locality.py`使用带梯度的eval模式，
自动相位噪声和自动随机平移在该阶段关闭。最终阶段通过`registered_optics`显式抽取
干净、相位平移或CCD平移三类条件，并用八种±1像素配准条件参与开发选模。

当前两支global均包含ORM建模及探测区域均值归一化。CCD读出噪声和散粒噪声此前
没有直接注入训练。本次新增`tools/evaluate_detector_noise.py`对固定选定权重进行数值补测。
在两支global的探测强度域同时加噪，位置位于平方律探测之后、现有均值归一化之前。
参考强度由2250条TRAIN视频的探测区域平均值确定，每视频包含4帧。
统计覆盖9000个vision帧区域和2250个language区域，测试期间使用固定参考强度。

读出噪声使用`max(I + r * I_reference * Normal(0,1), 0)`。
散粒噪声使用`Poisson(I * N / I_reference) * I_reference / N`，N为参考强度对应的平均计数。
每种水平运行5个随机种子，每次核算完整558条，循环填充排除在质量指标之外。

| 数值注入条件 | 平均SRCC | 5次最低–最高SRCC |
| --- | --- | --- |
| 干净基准 | 0.792371 | 单次确定性基准 |
| 高斯读出噪声，r=1% | 0.793459 | 0.792138–0.794806 |
| 高斯读出噪声，r=5% | 0.786210 | 0.781388–0.794299 |
| 高斯读出噪声，r=10% | 0.756097 | 0.747415–0.766218 |
| Poisson，N=100 | 0.786520 | 0.784822–0.788305 |
| Poisson，N=1000 | 0.792390 | 0.790658–0.793859 |
| Poisson，N=10000 | 0.792574 | 0.792121–0.792939 |

该表来自服务器RTX 4090上的固定权重推理。31份逐视频预测文件均已独立复算SRCC，
样本身份、标签和558条计数全部匹配。结果位于`runs/smoke/detector_noise_20261114`，
其中`protocol.json`记录定义、参考强度和源码SHA，`validation.json`记录逐表复算。
这些噪声水平尚无实际CCD标定对应关系。曝光、增益、暗场和平场记录可用于建立该映射。

投稿版Methods第559–591行描述的hardware-aware ORM对应相干残余分量建模。
当前训练与数值补测分别记录了配准扰动、相位噪声及CCD强度噪声的适用范围。
较强读出噪声及2像素CCD横向偏移仍会降低性能，后者四方向最低SRCC为0.716570。

打包时先准备输入并完成独立工程全量推理，再生成说明并逐页渲染检查。
测试通过、提交并发布源码后，运行`tools/build_release.py`。
源码通过Git同步，权重、NPZ、Word和结果通过逐文件SHA核验同步。
根目录`LightGen2`为源码维护入口，`releases/current`为生成镜像，
`releases/LightGen2.zip`为发行包。

先前正式版本及本轮试验记录保存在作者侧归档。早期`phase_reset_20261114`和
`phase_coverage_20261114`均为历史候选，其指标须结合各自原记录读取。
公开目录的18个编号结果对应当前选定权重，`01`为全部预测，`02`为指标和完整用时，
`03`为预测散点图，`04`为输入帧，`05`为专家份额，`06–08`为vision相位与光场，
`09–11`为language相位与光场。公开工程中的相位图均展示完整16个槽位。
