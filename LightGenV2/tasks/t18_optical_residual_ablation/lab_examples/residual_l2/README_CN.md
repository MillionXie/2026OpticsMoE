这是原实验室加载器的依赖闭包，不是新架构，也不启动相机或SLM。

## 运行

建议Python3.10/3.11和CPU版PyTorch2.x（参考环境实际版本见validation.json），
安装torch、numpy、Pillow。无需CUDA、SDK、数据集或仓库外的Python模块。

```text
python -m pip install torch numpy pillow
python example.py --self-test
python example.py --image your_image.png --export exported_fields
```

用户图片会转RGB并缩放150×150，只作接口演示，不替代原数据集预处理与划分。
合成图片的类别无语义。模型输出20维类别索引，不附完整数据集与类别映射，
不要用此演示输入计算论文精度。该包是推理/物理编码参考，不含原训练策略或训练数据。

## 最容易写错的地方

1. **光学残差不是电残差，也不是30%光强混合。** 对E/G相位参数phi，复调制为
   `M = 0.7 * exp(i*phi) + 0.3`；Router不加此残差。
   输入振幅SLM需要编码`bounded_amplitude(input) * abs(M)`，相位SLM编码`angle(M)`。
   不能只导出相位、遗漏abs(M)，否则不等价。
2. 输入RGB → R/G/B/均值四块拼图 → 224×224 → RMS0.25；
   振幅`tanh(abs/0.5)`且保零，再round255量化；**不能逐图最大值归一化**。
3. E1四专家各224×224，2×2布局；G1接收完整478×478场，
   **不能把G1输入缩到224再复制四份**。数值补零画布518×518不是器件分辨率。
4. rho与alpha完全不同。此权重alpha约`[0.94442958, 0.94587535]`，
   `fusion_logits.*`保存float64的**直接有效alpha**，融合时转float32，绝不能再sigmoid。
   原电残差为每层9参数3×3卷积，加标量alpha；末端为pool16、非仿射LayerNorm、
   Linear256→20（5140参数），不应额外新增读出网络。
5. 四专家权重由Router响应动态产生，均启用并L2幅度归一化，不是固定比例或top2。
6. 相位逻辑灰阶为floor(phase/2pi*256)，振幅round255；
   `phase_gray`只是逻辑相位码，**不是已套设备LUT的驱动灰阶**。

## 对接当前光路

模型条件为532nm、传播距离0.1m、逻辑采样17µm；active478、expert224、间隔30。
当前8µm器件上的有效区域采用1016像素（478×17/8≈1016），
逻辑场与器件像素不是一一对应；必须沿用经过核验的重采样、定位、保零与LUT流程。
现有接口参考原振幅屏1920×1080、相位屏1920×1200；师弟器件尺寸/像素间距若不同，
应修改物理映射而不是改数值模型的478、224或传播核。

`exported_fields/*.npz`保存每级实际逻辑输入振幅[B,478,478]、相位[478,478]及仿真强度。
这不是可直接显示的native BMP：振幅需经本机振幅响应逆映射，相位需经本机相位LUT，
再按本机会话坐标、方向映射到SLM；不能把本实验室标定直接复制到另一套设备。

模型`forward(amplitude, callback=..., ids=...)`可接采集回调。
回调签名`callback(stage, amplitude, phase_gray, ids)`，返回原始线性非负有限
float32 `[B,478,478]`强度，stage为router/0/1。不得把显示增强图、对数图或错误朝向图
作为原始CCD；相对均值、log1p、LayerNorm等由模型内部统一完成。
`example.py`不含真实硬件回调，也不会自动开设备；要复用现场已核验的采集后端。

当前光路**软件/编码合同兼容**有历史数值桥接证据，不等于另一套设备免标定或保证实拍精度。
曝光、增益、时延、方向、ROI、振幅逆响应和相位LUT仍是本机会话条件。
不附CCD、现场坐标/LUT、连接脚本、凭据、实验微调PT或TEST增强教师。
