# 当前四层Caltech20真实曲线与新优化依据

用户要求展示本轮曲线并继续冲80、保持残差优势，最新允许三张非A100卡。[PNG](training_curves.png)、[SVG](training_curves.svg)、[逐评估点CSV](epoch_metrics.csv)来自两臂原始history；train只E1/每5轮，val每轮，没有补造点/平滑，无test曲线。PNG已实际view_image检查，曲线/坐标/图例清晰。

残差E80到E100：train71.65%到78.06%，val58.30%到62.19%，val balancedNLL1.77368到1.64035。无残差同期val54.06%到55.12%、NLL2.10030到1.99699。末10对前10验证NLL均值继续改善3.23%/2.08%，LR双方一直.002，没有平台触发减半，NLL最低都在E100。

因此尚未充分收敛，但残差train/val差15.87pp且扩大，确实存在泛化差；不能只说没训好或只说过拟合，也不能保证加轮数达到80。双方原20类都完整恢复E100 raw/EMA/Adam/scheduler，新增一次E101-200同预算配对，保持配置观察学习曲线；noearly/每臂3600新增fitsec上限、无retry/无test。新状态和源码准入必须真实通过，独占新科学核prefix100及完整200。此新人工授权覆盖此前不得继续训练，仅这次有界方案。

Caltech原始档案包含比20更多类别；目前有47个按样本量/原角色约束合格的既有候选池，旧20由固定缩略图代理筛得。代理可学性不等于光学精度/残差收益。若进行类别开发，仅使用训练和验证，名单和规则先冻结，原始划分角色保留，不读测试图；小类别任务要明确标注，不能与原20当同任务涨分，挑选几行的平均也不是重新训练结果。旧测试已观察，开发结果不称完全独立泛化。
