## 曲线诊断与限制

四层无残差获选权重训练−验证差4.10个百分点，末轮EMA训练93.21%／验证89.29%，
末轮raw与EMA开发均88.24%，低于获选第99轮raw的88.67%。后期训练/验证NLL下降变慢，
相位梯度有限非零；每相位面最大饱和占比约0.00202%，没有大面积饱和。
相较六层无残差，其训练与验证均低，不能简单把差距解释成六层过拟合。
四层残差组尚未完成，不提前比较四层残差收益。

无残差获选权重训练−验证准确率差6.66个百分点；末轮train99.24%／val92.19%。
30%混合获选权重训练−验证差6.28个百分点；末轮train95.77%／val89.96%，
末轮raw／EMA开发准确率均85.84%，低于获选99轮86.27%。
残差组训练、验证及开发均低于无残差，不能把差距单纯归因于过拟合。
残差训练曲线持续改善到后期，但100轮后仍未达到无残差拟合水平；
当前证据不能区分更慢的优化和有效表达能力改变，也不足以判定已达上限。
此轮继续按原100轮预算完成四／二层，不根据开发差距追加或改变架构。

获选权重验证CCD捕获率无残差62.59%、30%混合46.89%；该指标是探测窗收集功率
相对于输出平面总功率的比例，不是整条光路透过率，也不直接证明性能差距的成因。
两组100轮训练均保持原分类、收光与平滑损失协议。相位sigmoid小于0.01或大于0.99的
饱和比例极低：各相位面最大占比约0.00040%／0.00161%；没有大面积相位饱和的证据。
梯度有限非零只排除了全梯度失效，不能保证每层优化充分。

未调制相干支路会与调制支路发生干涉；此处不是完整网络block的恒等跳连，
不能从ResNet或Transformer的残差结论保证该实现必然提高精度。
rho0.3表示振幅混合系数，不能称为30%功率。
