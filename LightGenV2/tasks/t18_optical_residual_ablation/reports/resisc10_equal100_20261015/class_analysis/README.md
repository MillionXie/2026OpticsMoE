## 尽快扩大差距的类别建议（仅建议，不自动换类）

当前十类中，兼顾较高残差召回与正差距，优先关注交叉路口、港口、湖泊、草地。若未来明确允许缩成四类，它们可作为一份新开发名单；在现有十类模型里这四行召回平均85.71%/82.14%、差+3.57，但这不是新四分类训练成绩。若需六类，可再加网球场和火电站；现有十类这六行平均79.52%/75.95%、差+3.57，也不是新六分类成绩。

不优先采用湿地来拉大差距；沙漠虽然双方都92.86%，能维持总精度却不提供残差差距。桥梁虽在旧20同轮优势大，当前10已反转，不应仅按旧排名直接保留/替换。也不建议为了旧大差距贸然加梯田或田径场，可能拖低总准确率。

最快、不重新定义任务的做法仍是先保持现有10类完成100轮，再看一次残差正则后逐类变化。若决定换类，应先固定名单再重新做有/无残差同100轮配对，明确为按已见验证结果选择的新开发任务；不能只给残差换类、把旧无残差成绩当对照，或用test挑类别。
