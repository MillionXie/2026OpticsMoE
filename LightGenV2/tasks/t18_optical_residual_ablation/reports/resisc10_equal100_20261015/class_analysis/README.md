### 根据统一100轮结果修正类别建议

优先兼顾绝对精度和当前正差的类别为**交叉路口、港口、岛屿**；草地可维持总体精度，但当前差为0。网球场适合观察较大的正差，不过绝对精度和泛化差距仍有风险。湿地当前变为+2.86，湖泊变为-1.43，说明早先E92/E113的逐类排序不稳定；下方接续前建议仅保留作历史，不再作为当前推荐。

若未来另获明确换类训练授权，可考虑交叉路口/港口/岛屿/草地作为兼顾精度的一份四类开发名单；若侧重较大观察差，再讨论加入网球场/湿地。这里只是已见验证结果指导的候选名单，不是新的四/六分类实验成绩，也不保证重新训练后仍有此差距。不把挑选几行的平均召回冒称子任务准确率。原20中桥梁同E58优势较大但在当前10类反转；梯田旧同轮绝对召回42.86%，不为拉大差距就自动加入。

当前不改变任何类别，继续完成既定残差E101-120一次缓解过拟合阶段。该阶段使用MixUp.4和恢复学习率减半，仍按验证NLL选模型；最后冻结一次残差测试，不用测试集挑类别或调参。该统一100轮表为验证结果；随后最终一次残差测试见本文顶部最新结果。

## 尽快扩大差距的类别建议（仅建议，不自动换类）

当前十类中，兼顾较高残差召回与正差距，优先关注交叉路口、港口、湖泊、草地。若未来明确允许缩成四类，它们可作为一份新开发名单；在现有十类模型里这四行召回平均85.71%/82.14%、差+3.57，但这不是新四分类训练成绩。若需六类，可再加网球场和火电站；现有十类这六行平均79.52%/75.95%、差+3.57，也不是新六分类成绩。

不优先采用湿地来拉大差距；沙漠虽然双方都92.86%，能维持总精度却不提供残差差距。桥梁虽在旧20同轮优势大，当前10已反转，不应仅按旧排名直接保留/替换。也不建议为了旧大差距贸然加梯田或田径场，可能拖低总准确率。

最快、不重新定义任务的做法仍是先保持现有10类完成100轮，再看一次残差正则后逐类变化。若决定换类，应先固定名单再重新做有/无残差同100轮配对，明确为按已见验证结果选择的新开发任务；不能只给残差换类、把旧无残差成绩当对照，或用test挑类别。
