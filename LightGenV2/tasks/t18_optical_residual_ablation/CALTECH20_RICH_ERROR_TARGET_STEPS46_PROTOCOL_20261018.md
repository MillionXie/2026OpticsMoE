# 四、六层 TEST 错误知情的 TRAIN 短步微调

人类明确要求分析 TEST 错误，按困难训练样本微调，避免完整训练 epoch。二层定稿、无残差50轮、数据角色、推理图、同一个末端电子头均保持。此次仅四/六层两个候选，恢复各自已审核保留模型；参数平均父模型没有单一历史 epoch，新计数为本次 optimizer step，Adam 新建不冒称恢复原矩。

先读取已有 TEST 预测，按错误数降序、类别序号解同分，取六类；每类选 TRAIN 概率 margin 最低16张共96张。另每类从其余 TRAIN 固定随机选四张共80张。每步八张困难样本、八张全类回放，固定种子17018；64步共1024次 TRAIN 样本呈现，仅176个不同 TRAIN ID。TEST/VALID 样本不进入梯度。不是64轮完整训练，也不重新初始化光学权重。

训练使用同一张 TRAIN 图的原始输入及轻微平移增强（两个轴各±.04）；不额外叠加已无效的强裁剪/蒸馏。两视图平滑CE平均，加 .5 原保留 TRAIN 概率KL防遗忘，以及 .1针对该真实类别主要 TEST 混淆对的 softplus margin。后者同样仅对TRAIN图计算。phase/电子/alpha学习率 .00008/.0002/.00002，AdamW无weight decay，clip1，EMA .9；alpha投影沿用>.4001及<=.95。推理没有新教师、掩码、头或附加网络。

每16步评估完整411张TEST一次，严格按正确张数最大、最早同分选PT。TRAIN/VALID全量评估仅新赢家和最终端点，不再每小段都扫全训练集。保留旧模型作为step0，退化或同分不替换。TEST参与诊断、目标设计及选模，因此属于TEST知情开发，不能声称独立未见泛化或同预算纯残差优势。

CPU先独立重建困难/回放样本和64步序列，证明角色无交集，独立推导CE/KL/混淆margin梯度；不构造模型。实际GPU生产在更新前验证父输出、all20/macro16/tail5的micro1/4梯度及状态不变，再执行64步。每卡一子、总不超过5张非A100，使用GPU0/1共享内存预算2GiB+800MiB，不触碰外国进程。

生产原始退出rc0后独占CPU科学核验来源、父状态、所有TRAIN索引/平移SHA、步数、全部TEST预测算术与最早最大选模、最终Adam与EMA边界、保存选中头概率及ID。科学审核不额外执行模型forward，也不声称独立重新计算整个光学图。失败保留，不自动重试或放宽门槛。原模型、对照、二层和实验室采集均不改。
