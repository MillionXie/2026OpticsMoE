# TEST错图对应TRAIN近邻：冻结光学的同一电子头短步

此前176张难例+回放的64步全网调整仅33/41秒，未胜保留模型，后段退化，原模型不替换。进一步缓存诊断：74/78张TEST错图各取同类TRAIN特征余弦最近三张，去重207/217张；这些近邻TRAIN本身准确率91.30/93.09%。故下一条只调整原5140参数Linear256→20+bias，所有光学、router、中间电子和alpha字节冻结，以免破坏已学到的信息。二层、冻结无残差和实验室版不动。

该方法直接从已有真实干净光路缓存256维特征拟合，不执行任何光学forward，不需要GPU。不是新网络、不是预测ensemble、不是用TEST图片训练。TEST标签/特征参与错误和同类近邻选择、PT选择，因此明确属于TEST知情开发，不能称独立泛化。

每步32次从TRAIN近邻多重集合抽样（同一TRAIN样本可对应多张错图）及32次从全部3141个TRAIN ID无放回抽样。固定seed18046，128步；每32步仅在缓存TEST特征上计算新电子头结果。TRAIN梯度为平滑CE+.1头权重锚定+原TRAIN概率KL（权重1），lr.001/momentum.9/clip1，整体头改变量半径.1。光学权重无更新，没有重新跑完整光学epoch；8192次只是极小缓存矩阵训练呈现。严格按TEST整数正确数、最早同分，保留原父作为step0。

CPU准入独立torch解析核真实缓存特征的头导数/概率与角色身份；训练用NumPy。实际producer退出rc0后独占独立审计重建全部近邻/随机序列、完整128步梯度/momentum/projection轨迹、四个候选TEST保存预测、同分规则和全部非头权重字节，核同一头的TRAIN/VALID/TEST保存概率。没有重新光学推理或调整冻结对照。新固定来源/目录/claims，失败保留不自动重试。
