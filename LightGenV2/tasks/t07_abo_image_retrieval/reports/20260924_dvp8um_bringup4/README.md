## 两项定位实验

1. 固定每层第一个 ABO 输入和本轮选出的相位/CCD 方向，曝光扫 20、40、60、80 ms。p99 随曝光大致线性升高：vision 各层约 21～24→84～91，language 各层约 13～18→50～69；24 帧均未饱和。与仿真的 PCC 基本不变。**单纯加曝光只能提高计数，不能恢复缺失的光场结构。**
2. 固定同一输入、60 ms 曝光，交替加载每层训练相位、平相位、再重复训练相位。训练相位与平相位 PCC 在 0.52～0.82，训练相位重复 PCC 约 0.99～1.00；说明相位 SLM 确实调制光场、SDK 没有一直停在桌面或默认图。但六层中所选第一个 query 的训练相位与仿真 PCC 仅约 0.02～0.31，部分阶段的平相位 PCC 还略高。**能切换相位不等于训练相位在此光路实现了仿真传递函数。**

当前更可能是训练仿真与实测光路的结构性域差，包括零级泄漏、波前/LUT、SLM 像素配准或传播模型偏差；本轮数据不能把这几项单独定量归因。MNIST 实拍保留输入轮廓也与零级泄漏的假设相符，但不能仅凭图像给出“泄漏百分比”。后续应先做能量/相位对照来估计范围，再在 ABO 仿真中对两个 SLM 的未调制分量做范围随机化训练，并同时检查仿真与实测；不要未经验证直接固定为某个百分比。
