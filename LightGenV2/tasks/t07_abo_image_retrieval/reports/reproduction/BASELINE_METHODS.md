# 03｜商品检索：图搜图（ABO）

**数据处理。** 使用 ABO 的 200 商品子集，覆盖十个商品类别，每个商品包含 12 张转台视角图像。对每个商品按固定哈希顺序划分八张登记图像和四张查询图像，形成 1,600 张图像的图库及 800 张测试查询；划分排序键为 SHA256("abo-enrolled42:" + 样本 ID)。图库和查询共享商品身份及拍摄序列，但图像文件不重复。检索正例按完全相同的 SKU 定义，每个查询有八个正例。图像经 EXIF 校正并转换为 RGB，保持原始长宽比，原生处理器的最小、最大像素预算均设为 50,176。

**模型处理。** 采用 Qwen3-VL-Embedding-2B，完整视觉和语言主干均冻结。使用原生对话模板，system 指令固定为 “Represent this catalog product image for category-aware visual similarity retrieval.”，user 内容仅为商品图像。取最终语言层最后有效 token 的隐藏表示，截取前 64 维并作 L2 归一化，作为图像描述子。特征提取采用 BF16、batch size 4；不使用商品监督微调或额外训练的降维映射。

**检索与评价。** 分别提取图库及查询图像的描述子，每张查询与全部 1,600 张图库图像计算余弦相似度，并进行稳定的降序排序；每张图库图像独立作为候选。R@1 定义为最近邻图像与查询具有相同 SKU 的查询比例，即 Top-1 命中率。完整 800 个查询中有 681 个命中，**R@1 为 0.8513**。
