四组使用同一组输入和固定的 `flip_v` 方向/读出框；A/B 是相同曝光条件下的配对方案比较。平相位 3 ms 避免了 12 ms 的饱和，但曝光不同，不能当成严格光子数匹配的因果消融。B 的第 1 张在 40 张拍完后重复拍摄，PCC `0.99885`。这仅验证起止重复，不保证每一帧都无异常。

固定 40 张的 B 仿真为 39/40 = 97.5%；实测 35/40，混淆矩阵（真值 0/1/2/3 为行）`[[10,0,0,0],[0,8,0,2],[2,0,8,0],[0,1,0,9]]`。图中实测仍保留明显的输入数字轮廓，与仿真四个亮区差距大；即使 B 比 A/平相位准确，也**不能**声称完整光场匹配、相位 LUT 或 SLM 共面配准已验收。实测与仿真平均 PCC 仅约 0.37，需要继续解决直透/未调制光和空间配准。

## 方向、时间与相位证据

- 四个不同数字上的 8 种方向试探中，`flip_v` 的平均仿真 PCC `0.3822` 且读出 4/4 正确；未翻转为 0/4。之后 40 张按这个预先固定的方向分析，不重新挑方向。
- B 与平相位在同一输入下 CCD PCC `0.54795`，B 重复加载 PCC `0.99846`：相位 SDK 确实改变了光场。该测试不等于证明相位灰度与弧度的 LUT 标定准确。
- 两个交替数字 × 每档 3 次的等待短测：0/80/120/160 ms 的首帧与第 5 帧 PCC 最低分别为 `0.0091/0.2217/0.2221/0.7444`；200/240/300 ms 分别为 `0.9988/0.9990/0.9986`。选 240 ms 留一定余量；这只是本次设备状态下的经验值，不是面板物理下限。

## A 与 B 究竟差在哪

A 固定旧 `post_robust_best`（epoch 12）的 478×478、17 μm 相位，再按物理坐标重采样到 1016×1016、8 μm；本次没有重新训练 A。B 在同样 8 μm 栅格上从 `raw_phase=0`（物理相位 π）训练 60 epoch，取验证集最好的第 10 epoch。两者都使用 8.13 mm 左右的有效宽、532 nm、10 cm，以及相同的输出 BMP 方向/反灰度规则。完整 4157 张 test 的**仿真**分别为 A 86.5528%、B 88.7659%；这不是本次实测。由于参数量及训练历史都不同（A 228,484，B 1,032,256 个相位像素），不能把提升全部归因于 8 μm 像素间距。更多训练口径见 `ABO_Lab_SHS_8um/MNIST_NATIVE8_COMPARISON.md`。
