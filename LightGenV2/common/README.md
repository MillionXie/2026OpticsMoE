# Common

这里只有“已经被至少两个任务复用、接口稳定”的实现，例如统一光传播算子、相位
编码和论文指标。任务特有的 router、readout、fusion 或网络结构不要提前拆到这里。

当前阶段 T06 仍使用已验证的兼容后端；等第二个任务迁移并证明接口确实共用后，再
提升相应代码，避免形成过度抽象的框架。

`optical_contract.py` 只统一带单位的传播物理参数及设备栅格换算，不包含 Torch，
也不接管任务自己的传播算子。共享的 532 nm / 17 µm / 10 cm profile 不写死孔径；
每个任务必须通过 `with_aperture(...)` 显式绑定自己的 active/canvas 尺寸。
